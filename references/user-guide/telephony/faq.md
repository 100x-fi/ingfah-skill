# คำถามที่พบบ่อย

> คำถามพบบ่อยเกี่ยวกับการเชื่อมต่อโทรศัพท์กับ ingfah
>
> Source: https://docs.ingfah.ai/telephony/faq/

## เลือก codec อะไรดี?

**ฝั่ง ingfah แนะนำ `g722` เป็นค่ามาตรฐาน** เนื่องจากให้คุณภาพเสียงระดับ HD ใช้ bandwidth ใกล้เคียงกับ G.711 และลดการ transcoding ภายในระบบ

**ulaw** (G.711) — มาตรฐาน รองรับทุก PBX เลือกใช้เฉพาะเมื่อฝั่งลูกค้าไม่รองรับ g722 หากไม่แน่ใจ → สอบถามทีมงาน

## ต้องใช้ TLS / SRTP ไหม?

UDP เพียงพอสำหรับการเชื่อมภายในเครือข่ายที่ไว้ใจกัน หากต้องการเข้ารหัส signaling (เช่น เชื่อมข้าม public internet หรือ MS Teams) ให้เลือก `transport=tls` และแจ้งทีมงานเพื่อจัดเตรียม cert

## IP สาธารณะของเราเปลี่ยนบ่อย ใช้ IP Peering ได้ไหม?

ไม่แนะนำ — IP Peering ต้องใช้ IP คงที่ทั้งสองฝั่ง หากฝั่งลูกค้าเป็น dynamic IP ให้ใช้ [SIP Registration](/telephony/sip-registration) แทน

## รองรับโทรออก (outbound) จาก ingfah ออกทางทรังก์ของลูกค้าไหม?

รองรับทั้งสองวิธี ฟิลด์ `number` ทำหน้าที่เป็น routing key (default จาก `sip_user`) ที่ใช้ระบุว่าควร route ปลายทางใดผ่าน trunk นี้

## ใช้ทั้ง 2 วิธีพร้อมกัน (เช่น register inbound + IP peer outbound) ได้ไหม?

ได้ในบางกรณี — กรุณาปรึกษาทีมงานก่อน เพื่อออกแบบ routing ที่เหมาะสม
