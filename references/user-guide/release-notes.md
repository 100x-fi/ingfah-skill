# Release Notes

> สรุปรายการอัปเดต ฟีเจอร์ใหม่ การปรับปรุงประสิทธิภาพ และการแก้ไขข้อบกพร่องของแพลตฟอร์ม ingfah

> Source: https://docs.ingfah.ai/release-notes/

สรุปรายการอัปเดต ฟีเจอร์ใหม่ การปรับปรุงประสิทธิภาพ และการแก้ไขข้อบกพร่องของแพลตฟอร์ม ingfah

## v1.56.0 - 8 ตุลาคม 2026

- การตั้งเวลาโทรออก: Outbound Batch โทรกลับหาลูกค้าตามเวลาที่ลูกค้านัดไว้ได้ ไม่เกิน 7 วัน เปิด โทรกลับตามนัด ในขั้นตอนที่ 1 แล้วเลือกจำนวนครั้งที่โทรซ้ำ [โทรติดตามตามเวลาที่ลูกค้าขอ](/guides/inbound-outbound/follow-up-calls/)
- การจัดการแชทข้อความ: ถ้าข้อความตอบกลับจาก AI ส่งไม่ถึงลูกค้า แชทจะขึ้นว่าส่งไม่สำเร็จพร้อมบอกสาเหตุ [จัดการแชทกับลูกค้า](/guides/text-chat/chat-sessions/)
- การจัดการสายโทร: ทีม AI Agent ตั้ง Automation ให้ทำงานเมื่อเริ่ม ส่งต่อ หรือจบการสนทนาได้ เช่น ส่ง Webhook ไปที่ CRM หรือเพิ่มเบอร์เข้ารายการห้ามโทร [Automation ของทีม](/guides/inbound-outbound/team-automations/)
- จัดการสิทธิ์การใช้งาน: รหัสผ่านใหม่ต้องยาวอย่างน้อย 12 ตัวอักษร จากเดิม 8 [เงื่อนไขการตั้งรหัสผ่าน](/guides/account-login/)
- ปรับปรุง UI: หน้าที่มีแท็บเสียงและแท็บข้อความจะจำแท็บล่าสุดที่คุณเลือกไว้ และประกาศฟีเจอร์ใหม่แสดงเป็นสไลด์บนแดชบอร์ด [สลับแท็บเสียงและข้อความ](/guides/voice-text-tabs/)
- แก้ไขข้อบกพร่อง: ปุ่มย้อนกลับของเบราว์เซอร์ถอยทีละเมนูที่กด และปุ่มย้อนกลับในหน้าตั้งรหัสผ่านครั้งแรกพากลับไปหน้าเข้าสู่ระบบ สรุปแชทไม่ขึ้นตัวแบ่งวันใหม่แยกออกมาในประวัติแชทอีกต่อไป

## v1.55.1 - 6 ตุลาคม 2026

- แก้ไขข้อบกพร่อง: ปุ่มเล่นตัวอย่างเสียงเรียงตรงแนว กล่องคำอธิบายของความยาวสายและสายสั้นกว้างขึ้น และหน้าต่าง เลือกฟัง แสดงหัวข้อถูกต้อง

## v1.55.0 - 6 ตุลาคม 2026

- การตั้งเวลาโทรออก: ในขั้นตอนที่ 3 ของ Outbound Batch ทดสอบฟังได้ทั้งคอลัมน์หรือทุกแถว และเลือกได้ว่าจะให้ AI Agent ตัวไหนพูด ขั้นตอนที่ 1 ชี้ให้เห็นช่องใน CSV ที่ข้อมูลยาวเกิน [ฟังตัวอย่างเสียงจากข้อมูลลูกค้า](/guides/inbound-outbound/speech-preview/)
- การจัดการแชทข้อความ: แชทที่เปิดอยู่แสดงเวลานับถอยหลังก่อนปิดอัตโนมัติ และประวัติแชทบันทึกไว้เมื่อระบบปิดแชทให้ AI Agent แบบข้อความมีรูปโปรไฟล์ของตัวเอง [จัดการแชทกับลูกค้า](/guides/text-chat/chat-sessions/)
- ปรับปรุง UI: การสร้าง API Key และการแก้ไขช่องทางโทรศัพท์เปิดเป็นแถบด้านข้าง ตาราง API Key แสดงว่าใครเป็นคนสร้าง และเมนูด้านซ้ายจำกลุ่มเมนูที่คุณเปิดค้างไว้
- แก้ไขข้อบกพร่อง: สายที่สั้นกว่า 1 วินาทีแสดงเป็น 1 วินาที ไม่ใช่ 0 ปุ่มปิดของข้อความแจ้งเตือนกดได้แม้มีแถบด้านข้างหรือหน้าต่างเปิดอยู่ และช่องคำสั่งของ AI Agent ไม่ยุบขณะพิมพ์

## v1.54.0 - 1 ตุลาคม 2026

- การตั้งเวลาโทรออก: ในขั้นตอนที่ 3 ของ Outbound Batch กดฟังข้อมูลลูกค้าทีละแถว ได้ยินว่า AI Agent จะพูดอย่างไรก่อนเริ่มโทรจริง [ฟังตัวอย่างเสียงจากข้อมูลลูกค้า](/guides/inbound-outbound/speech-preview/)
- ช่องทางติดต่อ: ตั้งได้ต่อช่องทางข้อความว่าแชทที่เงียบไปจะเปิดค้างไว้นานแค่ไหนก่อนปิดเอง หน้าตั้งค่าช่องทางข้อความมีปุ่ม คู่มือการเชื่อมต่อ [เชื่อมต่อ LINE Official Account](/guides/contact-channels/connect-line-oa/)
- แจ้งเตือน License: ถ้า License ไม่รวม Disposition หรือผลลัพธ์แบบ metadata จะมีข้อความแจ้งไว้ ตั้งค่าได้แต่ระบบจะไม่ประมวลผล
- ปรับปรุง UI: เมนูแชทมีป้าย Beta
- แก้ไขข้อบกพร่อง: จำนวน AI Agent และทีมอัปเดตทันทีหลังลบ และปิดแบนเนอร์ช่องทางข้อความแล้วผังบทสนทนาไม่กระตุก

## v1.53.0 - 29 กันยายน 2026

- การเรียกเก็บเงินและโควตา: หน้าบิลแยกค่าบันทึกเสียงออกมาเป็นอีกบรรทัด พร้อมคำอธิบายของค่าบริการแต่ละรายการ [บิลและการใช้งาน](/guides/settings/billing/)
- การจัดการแชทข้อความ: เมนู สายทั้งหมด เปลี่ยนชื่อเป็น สาย/แชททั้งหมด อิโมจิจาก LINE แสดงเป็นอิโมจิ และรายการแชทจำตัวกรองที่คุณเลือกไว้เมื่อกลับมาอีกครั้ง
- ปรับปรุง UI: กล่องคำอธิบายบนกราฟอ่านง่ายขึ้นบนมือถือ
- แก้ไขข้อบกพร่อง: ลบโหนดในผังบทสนทนาด้วยคีย์บอร์ดจะถามยืนยันก่อน ประมาณเวลาต่อสายตั้งต่ำกว่า 1 ไม่ได้ และชื่อยาว ๆ ในบันทึกกิจกรรมไม่ล้นออกนอกตาราง

## v1.52.0 - 24 กันยายน 2026

- การจัดการแชทข้อความ: ตารางแชทมีปุ่ม แสดง Metadata ดูข้อมูลที่เก็บได้จากแต่ละแชท และรายการแชทแสดงรูปโปรไฟล์และชื่อของแต่ละช่องทาง [ผลลัพธ์แบบ metadata](/guides/inbound-outbound/outcome-metadata/)
- การจัดการสายโทร: ชื่อทีมในหน้าสายทั้งหมดกดไปหน้าทีมได้เลย
- หน้าแรกของเว็บไซต์ (Landing Page): เพิ่มตัวอย่าง AI Agent สำหรับงานทวงหนี้และประกันรถยนต์
- แก้ไขข้อบกพร่อง: ยอดตอบกลับแชทรวมทั้ง AI และแอดมิน จำนวนลูกค้านับเป็นคนแทนสาย และกราฟแชทแสดงเป็นจำนวนเต็ม ฟอร์มให้สิทธิ์ Guest ตรวจทีละช่องระหว่างกรอก

## v1.51.1 - 23 กันยายน 2026

- จัดการสิทธิ์การใช้งาน: ให้สิทธิ์ Guest เข้าใช้งานชั่วคราว กำหนดสิทธิ์และระยะเวลาได้ Guest เข้าสู่ระบบผ่านหน้าของตัวเอง และมีแบนเนอร์บอกว่าเซสชันจะหมดอายุเมื่อไร [สิทธิ์ผู้ใช้งาน](/guides/settings/user-roles/)
- การจัดการสายโทร: จำนวนสายที่กำลังใช้งานนับรวมสายที่กำลังโทรออกด้วย
- แก้ไขข้อบกพร่อง: แผนภูมิความร้อนของข้อความมีคำอธิบายชัดขึ้น และพอดีจอมือถือ

## v1.51.0 - 22 กันยายน 2026

- การจัดการแชทข้อความ: รายการแชทแสดงตัวอย่างสติกเกอร์และรูปภาพ พร้อมชื่อผู้ส่งที่ถูกต้อง
- แก้ไขข้อบกพร่อง: คัดลอกเทมเพลตแล้วไม่เด้งไปหน้าข้อผิดพลาดอีกต่อไป แก้กราฟในหน้าวิเคราะห์และข้อความที่ทับซ้อนกันในตารางแชท

- แก้ไขข้อบกพร่อง: แก้ข้อความแจ้งเตือนตอนสร้าง AI Agent และการจัดวางหน้าตอบกลับอัตโนมัติ
