# สำหรับนักพัฒนา

> API ภาษาไทยสำหรับทีมที่ต้องการนำ Voice AI ของ ingfah ไปต่อกับระบบของตัวเอง
>
> Source: https://docs.ingfah.ai/services/developers/

สำหรับองค์กรที่ต้องการนำ Voice AI ของ ingfah ไปอินทิเกรตเข้ากับระบบของตัวเอง เราได้เปิดให้บริการ API ที่ถูกออกแบบมาเพื่อ "ภาษาไทย" โดยเฉพาะ ครอบคลุมตั้งแต่การถอดเสียง, สังเคราะห์เสียง ไปจนถึงโซลูชัน Full-duplex แบบ Real-time

## API ที่เปิดให้บริการ

**Voice Solution ผ่าน WebSocket (WSS):** โซลูชัน Full-duplex Voice AI ที่ให้บริการผ่าน WebSocket ครบจบในช่องทางการเชื่อมต่อเดียว รองรับ Streaming ASR, TTS และ Conversation Management พร้อมระบบ Backchannel Classifier และ Noise Cancellation ในตัว

**TTS API:** เทคโนโลยีสังเคราะห์เสียงภาษาไทยที่ให้ความรู้สึกเป็นธรรมชาติที่สุด รองรับตัวเลือกเสียงและโทนที่หลากหลาย ช่วยยกระดับประสบการณ์ให้การสนทนาฟังดูเหมือนคุยกับคนจริง
