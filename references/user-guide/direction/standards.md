# มาตรฐานและความปลอดภัย

> โครงสร้างพื้นฐาน การปกป้องข้อมูล และมาตรฐานสากลที่ ingfah ดำเนินการและกำลังรับรอง
>
> Source: https://docs.ingfah.ai/direction/standards/

ingfah ถูกออกแบบมาเพื่อตอบสนองการใช้งานระดับองค์กร (Enterprise-grade) โดยให้ความสำคัญสูงสุดกับความปลอดภัยของ Infrastructure, การปกป้องข้อมูลอันละเอียดอ่อนของลูกค้า และการปฏิบัติตามมาตรฐานสากลที่เข้มงวด

## Infrastructure ที่มั่นคงและปลอดภัย

แพลตฟอร์มของเราประมวลผลบน **Amazon Web Services (AWS)** โดยเลือกตั้ง Data Center ใน **กรุงเทพมหานคร** โดยบทถอดความ ข้อมูลประกอบการสนทนา และข้อมูลในฐานข้อมูล จัดเก็บอยู่ภายในประเทศไทย ส่วนไฟล์บันทึกเสียงและไฟล์ข้อมูลที่อัปโหลดเข้าระบบ จัดเก็บในระบบ Object Storage แบบเข้ารหัสที่ **ประเทศมาเลเซีย** ทั้งสองแห่งอยู่ภายใต้สัญญาประมวลผลข้อมูลส่วนบุคคล (DPA) และองค์กรสามารถกำหนดระยะเวลาจัดเก็บข้อมูลได้เอง ตั้งแต่ระดับลบข้อมูลรายวัน

สำหรับการประมวลผลของโมเดล AI (Inference) ingfah ใช้โมเดล Open-source ระดับ Frontier ที่เราติดตั้งและดูแลด้วยตนเอง บน GPU ที่ **สิงคโปร์ (AWS)** เป็นหลัก และมี **ฮ่องกง (BytePlus)** เป็นระบบสำรองอัตโนมัติเมื่อความจุไม่เพียงพอ การประมวลผลนี้เป็นแบบชั่วคราว (Transient) กล่าวคือ เสียงและข้อความจะถูกประมวลผลในหน่วยความจำเฉพาะช่วงเวลาของคำขอนั้น และไม่มีการจัดเก็บไว้นอกประเทศไทย และเนื่องจากไม่มีผู้ให้บริการโมเดลภายนอกรายใดได้รับข้อมูลของท่านในเส้นทางนี้ ข้อมูลของท่านจึงไม่ถูกนำไปใช้ฝึกสอนโมเดลของผู้ให้บริการภายนอก

สถาปัตยกรรมระบบเป็นแบบ Multi-Availability Zone (Multi-AZ) ในทุกระดับบริการ พร้อม SLA มาตรฐานที่ **99.5% ต่อเดือน** (ไม่นับรวมช่วงบำรุงรักษาตามแผน) และมีบริการระดับ Dedicated Tier ที่ **99.95%** สำหรับองค์กรที่ต้องการความพร้อมใช้งานสูงขึ้น โดยกำหนดวิธีการวัด โครงสร้าง Service Credit และรายการยกเว้นไว้ในเอกสารแนบท้ายสัญญา พร้อมระบบ Network Isolation ที่รัดกุมผ่าน AWS Security Groups และ VPC

## การปกป้องข้อมูล (Data Protection)

**Encryption at rest:** เข้ารหัสข้อมูลที่จัดเก็บด้วย AES-256 ตามมาตรฐานความปลอดภัยสูงสุดของ AWS

**Encryption in transit:** เข้ารหัสข้อมูลระหว่างการส่งผ่านเครือข่ายด้วย TLS 1.2 / 1.3

**PDPA Compliance:** ingfah ปฏิบัติตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล (PDPA) ของประเทศไทยอย่างเต็มรูปแบบ

**Data Retention Control:** องค์กรสามารถกำหนดนโยบายระยะเวลาการจัดเก็บข้อมูล (Retention Period) ได้ด้วยตัวเอง หรือแม้แต่เลือกว่าจะไม่ให้ระบบจัดเก็บข้อมูลใด ๆ เลยก็ได้

## มาตรฐานและแผนการรับรองระดับสากล

| มาตรฐาน | สถานะ | อ้างอิง |
|---|---|---|
| PDPA | ✅ Compliant | ใช้งานได้แล้ว |
| ISO/IEC 27001:2022 (Information Security Management) | ✅ **ได้รับการรับรองแล้ว** | Certificate IS 843015, BSI |
| ISO/IEC 20000-1:2018 (IT Service Management) | ✅ **ได้รับการรับรองแล้ว** | BSI |
| ISO 42001 (AI Management System) | 🔄 อยู่ระหว่าง Audit | Q3 2026 |
| SOC 2 Type I | 🔄 อยู่ระหว่าง Audit | Q3 2026 |
| SOC 2 Type II | 🔄 อยู่ระหว่าง Audit | Q3 2026 |

**ISO 42001:** มาตรฐานสากลใหม่ล่าสุดสำหรับระบบบริหารจัดการ AI โดย ingfah อยู่ในระหว่างกระบวนการ Audit เพื่อก้าวเป็นหนึ่งในผู้ให้บริการ AI ลำดับแรก ๆ ของไทยที่ได้รับการรับรองนี้

**ISO 27001:** มาตรฐานสากลที่ยอมรับทั่วโลกในด้านการบริหารจัดการความปลอดภัยของข้อมูล (Information Security Management System) โดย ingfah ได้รับการรับรองมาตรฐาน ISO/IEC 27001:2022 ภายใต้ Certificate IS 843015 จากการตรวจประเมินโดย BSI Group (Thailand)

**ISO 20000-1:** มาตรฐานสากลด้านการบริหารจัดการงานบริการเทคโนโลยีสารสนเทศ (IT Service Management) โดย ingfah ได้รับการรับรองมาตรฐาน ISO/IEC 20000-1:2018 จาก BSI Group (Thailand)

**SOC 2:** มาตรฐานการตรวจสอบความปลอดภัย, ความพร้อมใช้งาน และ Privacy ของระบบ ซึ่งเป็นเครื่องการันตีสำหรับองค์กรขนาดใหญ่ที่ต้องการความน่าเชื่อถือระดับสูงสุด
