# การเพิ่ม Passkey

> Passkey ให้คุณเข้าสู่ระบบด้วยลายนิ้วมือ Face ID หรือ PIN ของอุปกรณ์ แทนการพิมพ์รหัสผ่าน เหมาะกับเครื่องที่ใช้ประจำ เช่น โน้ตบุ๊กที่ทำงาน ...
>
> Source: https://docs.ingfah.ai/guides/account-settings/passkey/

:::tip[ฟีเจอร์ใหม่: การตั้งค่าบัญชี]
ดูแลบัญชีของคุณได้เองจากหน้า **บัญชีของฉัน** ทั้งเปลี่ยนรหัสผ่าน เปิดการยืนยันตัวตนแบบสองขั้นตอน (2FA) และเพิ่ม Passkey เพื่อเข้าสู่ระบบได้ปลอดภัยขึ้น
:::

Passkey ให้คุณเข้าสู่ระบบด้วยลายนิ้วมือ Face ID หรือ PIN ของอุปกรณ์ แทนการพิมพ์รหัสผ่าน เหมาะกับเครื่องที่ใช้ประจำ เช่น โน้ตบุ๊กที่ทำงาน ตั้งชื่อ Passkey ตามอุปกรณ์ไว้ จะได้รู้ว่าอันไหนเป็นของเครื่องไหนเมื่อต้องลบ

## ก่อนเริ่ม {#pk-before}

- ใช้อุปกรณ์ที่ตั้งลายนิ้วมือ Face ID หรือ PIN ไว้แล้ว
- เตรียมรหัสผ่านปัจจุบันของบัญชี
- ถ้าเปิด 2FA ไว้ เตรียมแอปยืนยันตัวตนบนโทรศัพท์

## วิธีการเพิ่ม Passkey {#pk-add}

1. ไปที่ **การตั้งค่า** > **บัญชีของฉัน** ที่แถบเมนูด้านซ้าย
2. ในแถว **Passkey** กด **+ เพิ่ม Passkey**
3. ช่อง **ชื่อ Passkey** ใส่ชื่ออุปกรณ์ เช่น “Touch ID บน MacBook”
4. ช่อง **รหัสผ่านปัจจุบัน** ใส่รหัสผ่านที่ใช้เข้าสู่ระบบ
5. กด **+ เพิ่มพาสคีย์**
6. ถ้าเปิด 2FA ไว้ กรอกรหัส 6 หลักในหน้าต่าง **ยืนยันตัวตนด้วย 2FA** แล้วกด **ยืนยัน**
7. สแกนลายนิ้วมือ ใช้ Face ID หรือใส่ PIN ตามที่อุปกรณ์ถาม

## เข้าสู่ระบบด้วย Passkey {#pk-login}

1. ที่หน้าเข้าสู่ระบบ กรอกอีเมลแล้วกด **เข้าสู่ระบบ**
2. กด **เข้าสู่ระบบด้วย Passkey**
3. เลือก passkey ของ ingfah แล้วสแกนลายนิ้วมือ ใช้ Face ID หรือใส่ PIN

<!-- TODO ภาพ: หน้ายืนยันตัวตนบนอุปกรณ์ — ไอคอนลายนิ้วมือ ข้อความ กำลังรอการยืนยันจากอุปกรณ์ และปุ่ม ยกเลิก -->

:::note[เข้าสู่ระบบด้วย Passkey ไม่สำเร็จ]
เกิดเมื่อไม่พบ passkey ของ ingfah บนอุปกรณ์นี้ หรือยกเลิกการยืนยันกลางทาง กด **ลองอีกครั้ง** หรือกด **เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน** แทน
:::

## ลบ Passkey {#pk-delete}

ลบ Passkey ของเครื่องที่ไม่ได้ใช้แล้ว เช่น เครื่องที่ขายหรือคืนบริษัท

1. ไปที่ **การตั้งค่า** > **บัญชีของฉัน** ที่แถบเมนูด้านซ้าย
2. ในรายการใต้แถว **Passkey** กด **ลบ** ท้าย Passkey ที่ต้องการ
3. กด **ลบ Passkey** เพื่อยืนยัน

ถ้าต้องการใช้ Passkey บนเครื่องนั้นอีก ให้เพิ่มใหม่ตามขั้นตอนด้านบน
:::
