# ภาพรวมการตั้งค่าบัญชี

> หน้า บัญชีของฉัน รวมการตั้งค่าที่เป็นของคุณคนเดียว ได้แก่ ข้อมูลโปรไฟล์ วิธีเข้าสู่ระบบ และอีเมลแจ้งเตือน การเปลี่ยนแปลงในหน้านี้มีผลกับบ...
>
> Source: https://docs.ingfah.ai/guides/account-settings/overview/

:::tip[ฟีเจอร์ใหม่: การตั้งค่าบัญชี]
ดูแลบัญชีของคุณได้เองจากหน้า **บัญชีของฉัน** ทั้งเปลี่ยนรหัสผ่าน เปิดการยืนยันตัวตนแบบสองขั้นตอน (2FA) และเพิ่ม Passkey เพื่อเข้าสู่ระบบได้ปลอดภัยขึ้น
:::

หน้า **บัญชีของฉัน** รวมการตั้งค่าที่เป็นของคุณคนเดียว ได้แก่ ข้อมูลโปรไฟล์ วิธีเข้าสู่ระบบ และอีเมลแจ้งเตือน การเปลี่ยนแปลงในหน้านี้มีผลกับบัญชีของคุณเท่านั้น ไม่กระทบแอดมินคนอื่นในองค์กร

## เปิดหน้าบัญชีของฉัน {#ac-open}

ไปที่ **การตั้งค่า** > **บัญชีของฉัน** ที่แถบเมนูด้านซ้าย

## มีอะไรในหน้านี้ {#ac-what}

| ส่วน | ใช้ทำอะไร |
| --- | --- |
| โปรไฟล์ | แสดงชื่อ อีเมล และสิทธิ์ของคุณ เช่น แอดมินทั่วไป |
| รหัสผ่าน | [เปลี่ยนรหัสผ่าน](/guides/account-settings/change-password/)ที่ใช้เข้าสู่ระบบ |
| การยืนยันตัวตนแบบสองขั้นตอน (2FA) | ขอรหัส 6 หลักจากแอปบนโทรศัพท์เพิ่มจากรหัสผ่าน [ดูวิธีเปิดใช้งาน 2FA](/guides/account-settings/two-factor/) |
| Passkey | เข้าสู่ระบบด้วยลายนิ้วมือ Face ID หรือ PIN ของอุปกรณ์ [ดูวิธีเพิ่ม Passkey](/guides/account-settings/passkey/) |
| การแจ้งเตือน | เลือกว่าจะรับอีเมลทุกครั้งที่มีการเข้าสู่ระบบบัญชีของคุณหรือไม่ |

## เหมาะกับงานแบบไหน {#ac-fit}

ใช้เมื่อต้องการให้บัญชีปลอดภัยขึ้นหรือเข้าสู่ระบบได้สะดวกขึ้น เช่น บัญชีแอดมินที่ดูข้อมูลลูกค้าและสร้าง API Key ได้ ควรเปิด 2FA ไว้เสมอ ส่วนคนที่เข้าสู่ระบบจากเครื่องประจำทุกวัน เพิ่ม Passkey ไว้จะได้ไม่ต้องพิมพ์รหัสผ่านทุกครั้ง

## วิธีเข้าสู่ระบบที่เลือกได้ {#ac-methods}

| วิธี | ใช้อะไรยืนยันตัวตน | เหมาะกับ |
| --- | --- | --- |
| อีเมลและรหัสผ่าน | รหัสผ่านที่คุณตั้งเอง | ทุกบัญชี เป็นวิธีพื้นฐาน |
| รหัสผ่าน + 2FA | รหัสผ่าน และรหัส 6 หลักจากแอปยืนยันตัวตน | บัญชีที่ต้องการความปลอดภัยสูง |
| Passkey | ลายนิ้วมือ Face ID หรือ PIN ของอุปกรณ์ | เข้าสู่ระบบจากเครื่องประจำโดยไม่ต้องพิมพ์รหัสผ่าน |
| SSO | บัญชีขององค์กร | องค์กรที่ตั้งค่า SSO ไว้แล้ว ดู[เข้าสู่ระบบและจัดการรหัสผ่าน](/guides/account-login/) |

## อีเมลแจ้งเตือน {#ac-email}

ระบบส่งอีเมลแจ้งทุกครั้งที่มีการเปลี่ยนรหัสผ่าน เปิดหรือปิด 2FA และเพิ่มหรือลบ Passkey อีเมลกลุ่มนี้ปิดไม่ได้ ส่วนสวิตช์ **ส่งอีเมลแจ้งเตือนเมื่อมีการเข้าสู่ระบบบัญชีของฉัน** ใช้เลือกว่าจะรับอีเมลทุกครั้งที่มีคนเข้าสู่ระบบบัญชีของคุณด้วยหรือไม่

:::caution[ได้อีเมลแจ้งเตือนที่คุณไม่ได้ทำเอง]
ให้[เปลี่ยนรหัสผ่าน](/guides/account-settings/change-password/)ทันที แล้วติดต่อ support@ingfah.ai
:::

## ขั้นตอนถัดไป {#ac-next}

1. [เปิดใช้งาน 2FA](/guides/account-settings/two-factor/) เพื่อป้องกันบัญชีเมื่อรหัสผ่านรั่ว
2. [เพิ่ม Passkey](/guides/account-settings/passkey/) ในเครื่องที่ใช้ประจำ
