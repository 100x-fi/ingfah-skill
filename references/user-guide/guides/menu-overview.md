# ทำความรู้จักเมนูหลักของเรา

> Source: https://docs.ingfah.ai/guides/menu-overview/

| เมนู | ใช้ทำอะไรได้บ้าง |
|------|-----------------|
| แดชบอร์ด | ดูข้อมูลสายโทรและ[สถิติแชทข้อความ](/guides/reports/text-analytics/) รวมถึงช่วงเวลาที่มี[สายโทรมาก](/guides/reports/voice-heatmap/) |
| สายเข้า (inbound) | บทสนทนาที่เราคุยกับคู่สาย สามารถแปลงเป็นรูปแบบข้อความได้แบบ real-time<br>หลังจบบทสนทนาสามารถดู”สรุปบทสนทนา” และ “ผลลัพท์” ได้<br>ตรวจสอบประวัติการโทรเข้า<br>ฟังบันทึกเสียงการสนทนาย้อนหลัง |
| สายออก (outbound) | ดูประวัติการโทรออก (รายละเอียดข้อมูลของเเต่ละสายที่เคยโทรออก) |
| สร้าง Batch | ตั้งค่าการโทรออกของสายที่ต้องการโทรออก เช่น ชื่อ ประเภทงาน วันเวลา |
| แชท | [ดูและตอบบทสนทนากับลูกค้า](/guides/text-chat/chat-sessions/) |
| สาย/แชททั้งหมด | [ค้นหาและส่งออกประวัติสายและแชท](/guides/inbound-outbound/all-calls/) |
| AI Agent | สร้าง AI Agent แบบเสียงหรือ[แบบข้อความ](/guides/ai-agent/create-text-agent/) และสร้างทีม |
| คลังความรู้ | อัปโหลดไฟล์ข้อมูลที่ต้องการให้ AI เรียนรู้ เช่น Policy, KB, Manual, SOP |
| เบอร์โทรศัพท์ | ผูกเบอร์กับทีม AI Agent |
| API Keys | สร้าง API key เพื่อเชื่อมต่อกับระบบ Ingfah |
