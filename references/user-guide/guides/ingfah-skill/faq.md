# คำถามที่พบบ่อยและแก้ไขปัญหา

> คำถามที่พบบ่อยเกี่ยวกับ Skill ingfah และวิธีแก้ปัญหาการติดตั้ง การเชื่อมต่อ และการใช้งาน
>
> Source: https://docs.ingfah.ai/guides/ingfah-skill/faq/

## คำถามที่พบบ่อย

### ต้องเขียนโค้ดหรือเขียน Prompt เป็นไหม?

ไม่จำเป็น เล่าสิ่งที่ต้องการเป็นภาษาพูดธรรมดาได้เลย สั่งเป็นภาษาไทยหรือภาษาอังกฤษก็ได้ AI จะถามกลับเองหากข้อมูลไม่ครบ

### ใช้ Skill ingfah มีค่าใช้จ่ายไหม?

Skill ingfah ใช้ได้ฟรี ส่วนค่าบริการของแอป AI (ChatGPT หรือ Claude) เป็นไปตามแพ็กเกจของผู้ให้บริการนั้น การทดลองคุยกับ AI Agent ไม่มีค่าใช้จ่าย ส่วนสายที่โทรจริงคิดค่าบริการตามแพ็กเกจอิงฟ้าตามปกติ หากใช้ [ชุดทดสอบอัตโนมัติ](/guides/ingfah-skill/automated-testing/) จะมีค่าใช้จ่ายของผู้ให้บริการโมเดลเพิ่ม

### AI จะโทรหาลูกค้า หรือแก้ Agent ที่ใช้งานอยู่โดยไม่ถามไหม?

ไม่ AI จะแสดงรายละเอียดและขอให้คุณยืนยันก่อนทุกครั้ง ทั้งการเผยแพร่ Agent การสร้าง หยุด หรือยกเลิก Batch การลบข้อมูล และการส่งข้อมูลไปยังระบบอื่น หากยังไม่แน่ใจ ตอบปฏิเสธได้เลย

### ข้อมูลของเราปลอดภัยไหม?

API Key มีสิทธิ์เข้าถึงบัญชีของคุณเต็มรูปแบบ Skill ingfah ใช้ Key เฉพาะในแชทนั้น ไม่บันทึกลงไฟล์ และไม่แสดงค่า Key ในคำตอบ อย่างไรก็ตาม เมื่อ AI อ่านบทสนทนาของสายจริง ข้อมูลลูกค้าในสายนั้นจะถูกส่งไปประมวลผลที่ผู้ให้บริการ AI ที่คุณใช้ ควรตรวจสอบให้สอดคล้องกับนโยบายข้อมูลขององค์กรคุณ

### แก้ไขแล้วไม่พอใจ ย้อนกลับได้ไหม?

ได้ ทุกครั้งที่เผยแพร่ ระบบจะเก็บเวอร์ชันเดิมไว้ บอก AI ได้เลย เช่น "ช่วยนำ Agent มะลิกลับไปใช้เวอร์ชันก่อนที่แก้เมื่อเช้า" AI จะแสดงให้ดูก่อนเผยแพร่

### ทำไม AI มองไม่เห็น AI Agent บางตัว?

AI เห็นเฉพาะ AI Agent ที่เจ้าของ API Key มองเห็นได้ AI Agent แบบ **ส่วนตัว** จะเห็นเฉพาะผู้สร้างและ Owner ดูเพิ่มเติมที่ [การมองเห็น AI Agent](/guides/ai-agent/ai-agent-visibility/)

## แก้ไขปัญหาเบื้องต้น

### AI ไม่รู้จัก Skill ingfah หรือตอบแบบทั่วไป

- ตรวจสอบว่า**เริ่มแชทใหม่**หลังติดตั้ง Skill แล้ว
- สำหรับ Claude Desktop app ตรวจสอบว่าเปิดใช้งาน Skill **ingfah** และเปิด **Code execution and file creation** ไว้ใน **Settings → Capabilities**
- ระบุในข้อความว่า "ใช้ Skill ingfah" เพื่อให้ AI เลือกใช้ Skill นี้

### อัปโหลดไฟล์ .zip ใน Claude Desktop app ไม่ผ่าน

อัปโหลดไฟล์ .zip ที่ดาวน์โหลดมาโดยตรง **ไม่ต้องแตกไฟล์** และไม่ต้องบีบอัดใหม่ หากยังไม่ผ่าน ให้ดาวน์โหลดไฟล์ใหม่จากลิงก์ในหน้า [ติดตั้งและเชื่อมต่อ](/guides/ingfah-skill/install/)

### AI แจ้งว่าเชื่อมต่อไม่ได้ หรือ API Key ไม่ถูกต้อง

- API Key อาจคัดลอกมาไม่ครบ หรือถูกลบไปแล้ว ให้ [สร้าง API Key ใหม่](/guides/settings/api-keys/) แล้ววางให้ AI อีกครั้ง
- หาก AI แจ้งข้อผิดพลาด **403** พร้อมรหัส **1010** แปลว่า AI เรียกระบบด้วยวิธีอื่นแทนเครื่องมือของ Skill ให้พิมพ์บอก AI ว่า "ใช้สคริปต์ของ Skill ingfah ในการเรียก API"

### AI แจ้งว่าไม่มีสิทธิ์เปลี่ยนเป็นส่วนตัว / สาธารณะ

การเปลี่ยนการมองเห็นของ AI Agent หรือทีม ทำได้เฉพาะผู้ที่สร้างรายการนั้น หาก API Key เป็นของผู้ใช้คนอื่น ให้ผู้สร้างเป็นผู้เปลี่ยน หรือใช้ API Key ของผู้สร้าง

### แก้ไขแล้ว แต่สายจริงยังทำงานแบบเดิม

- ตรวจสอบว่า AI **เผยแพร่**การแก้ไขแล้ว ไม่ใช่เพียงบันทึกเป็นแบบร่าง
- การแก้ไขมีผลกับ**สายใหม่**เท่านั้น
- หากมีคนอื่นแก้ Agent ตัวเดียวกันในหน้าเว็บ อาจเผยแพร่ทับการแก้ไขของคุณ ให้ AI ตรวจสอบเวอร์ชันล่าสุดที่เผยแพร่อยู่

### Agent พูดชื่อเครื่องมือออกมา หรือบอกว่าจะโอนสายแต่ไม่โอน

เช่น Agent พูดว่า "transfer_to_human_agent" ให้ลูกค้าได้ยิน หรือวางสายไม่ได้หลังกล่าวลา มักเกิดจาก Tool หลุดออกจาก Agent หลังการแก้ไข ให้พิมพ์บอก AI ว่า "ช่วยตรวจสอบว่า Agent มะลิยังมี Tool โอนสายและ Tool วางสายครบไหม" และ [อัปเดต Skill](/guides/ingfah-skill/install/#อัปเดต-skill-เป็นเวอร์ชันล่าสุด) เป็นเวอร์ชัน 1.3.0 ขึ้นไป ซึ่งป้องกันไม่ให้ Tool หลุดตอนแก้ไข

### ผลลัพธ์ที่ AI สร้างไม่ตรงกับที่ต้องการ

บอก AI ต่อในแชทเดิมได้เลยว่าส่วนไหนไม่ตรง พร้อมตัวอย่างสิ่งที่ต้องการ หากปัญหายังไม่หาย แจ้งทีมงานอิงฟ้าได้ทันที
