# (Beta) ภาพรวม Skill ingfah

> ใช้ ChatGPT หรือ Claude ช่วยสร้าง แก้ไข และดูแล AI Agent บนอิงฟ้า ด้วยภาษาพูดธรรมดา
>
> Source: https://docs.ingfah.ai/guides/ingfah-skill/overview/

:::caution[ฟีเจอร์นี้ยังอยู่ในช่วง Beta]
ฟีเจอร์นี้ยังอยู่ระหว่างการพัฒนา อาจมีการเปลี่ยนแปลงหรือข้อผิดพลาดเกิดขึ้นได้ หากพบปัญหาการใช้งาน สามารถแจ้งทีมงานอิงฟ้าได้ทันที
:::

**Skill ingfah** ทำให้ผู้ช่วย AI อย่าง **ChatGPT Desktop app** หรือ **Claude Desktop app** รู้จักระบบอิงฟ้า และทำงานบนบัญชีของคุณได้โดยตรง คุณเพียงเล่าสิ่งที่ต้องการเป็นภาษาพูดธรรมดา โดยไม่ต้องเขียนโค้ดหรือเขียน Prompt เอง

## Skill ingfah ช่วยอะไรได้บ้าง

- **สร้าง AI Agent ใหม่** ทั้ง Flow บทสนทนา และทีม AI Agent ที่พร้อมรับสายหรือโทรออก
- **แก้ไข AI Agent ที่มีอยู่แล้ว** ทั้งที่ AI สร้าง และที่คุณสร้างเองในหน้าเว็บ
- **หาสาเหตุเมื่อ AI Agent ทำงานผิดพลาด** จากบทสนทนาของสายจริง
- **ตั้งค่าผลลัพธ์หลังวางสาย** เช่น สรุปบทสนทนา ผลลัพธ์แบบสถานะ และผลลัพธ์แบบ Metadata
- **เตรียมเอกสารสำหรับคลังความรู้** จากไฟล์คำถามที่พบบ่อยที่คุณมี
- **เพิ่ม Tool ให้ AI Agent** เช่น Tool แปลงวันที่ หรือ Tool เรียกข้อมูลจากระบบของคุณ
- **จัดการสายโทรออก** ทั้งเทมเพลตข้อมูลลูกค้าและ Batch โทรออก
- **ดูรายงานและสถิติ** และส่งผลการโทรไปยังระบบอื่นผ่าน webhook
- **ตอบคำถามวิธีใช้งานอิงฟ้า** จากคู่มือนี้ โดยไม่ต้องเชื่อมต่อ API Key
- **ตั้งชุดทดสอบอัตโนมัติ** สำหรับทีมที่แก้ไข AI Agent บ่อย

ดูตัวอย่างข้อความสั่งงานของแต่ละเรื่องได้ที่ [ตัวอย่างการใช้งาน](/guides/ingfah-skill/examples/)

## ใช้ได้กับแอปไหนบ้าง

- **Claude Desktop app** และ claude.ai บนเว็บ
- **Claude Code**
- **ChatGPT Desktop app**

Skill ingfah ใช้ได้ฟรี ส่วนค่าบริการของแอป AI เป็นไปตามแพ็กเกจของผู้ให้บริการนั้น

## AI ถามก่อนทำสิ่งที่มีผลกับลูกค้าจริงเสมอ

AI จะแสดงรายละเอียดและขอให้คุณยืนยันก่อนทุกครั้ง ทั้งการเผยแพร่ AI Agent การสร้าง หยุด หรือยกเลิก Batch โทรออก การลบข้อมูล และการส่งข้อมูลไปยังระบบอื่น หากยังไม่แน่ใจ ตอบปฏิเสธได้เลย

## สิ่งที่ต้องทำเองในหน้าเว็บ

งานบางอย่าง AI ทำแทนไม่ได้ ต้องทำในหน้าเว็บอิงฟ้าเท่านั้น หาก AI แจ้งว่าทำไม่ได้ ให้ทำตามเมนูด้านล่าง

| งาน | ทำที่ |
|-----|------|
| สร้างหรือลบ API Key | การตั้งค่า → API Keys |
| ผูกเบอร์โทรศัพท์กับทีมรับสายเข้า | เบอร์โทรศัพท์ → ⋮ → แก้ไข → ทีมรับสายเข้า |
| อัปโหลดไฟล์เข้าคลังความรู้ และเชื่อมกับ AI Agent | คลังความรู้ → อัปโหลด |
| ทดลองคุยกับ AI Agent | AI Agent → ทดลอง → ตั้งค่าและทดลอง |
| สร้าง Batch จากไฟล์ CSV | สายออก → สร้าง Batch |
| บิล การเก็บรักษาข้อมูล และประวัติการใช้งาน | การตั้งค่า (เฉพาะ Owner) |
