# ชุดทดสอบอัตโนมัติ

> ให้ AI ตั้งชุดทดสอบที่จำลองบทสนทนาหลายสิบแบบกับ AI Agent และตรวจผลให้อัตโนมัติทุกครั้งที่แก้ไข
>
> Source: https://docs.ingfah.ai/guides/ingfah-skill/automated-testing/

การทดลองคุยกับ AI Agent ในหน้า [ทดลอง](/guides/ai-agent/try-call/) ตรวจได้ทีละบทสนทนา ส่วน**ชุดทดสอบอัตโนมัติ**จะจำลองบทสนทนาหลายสิบแบบพร้อมกัน และตรวจคำตอบของ AI Agent ให้ทุกครั้งที่แก้ไข ช่วยให้รู้ทันทีหากการแก้ไขครั้งใหม่ทำให้ส่วนอื่นผิดพลาด เช่น Agent เลิกโอนสาย หรือกลับไปถามคำถามซ้ำ

เหมาะสำหรับทีมที่แก้ไข AI Agent บ่อย หรือมี Agent ที่ใช้งานกับลูกค้าจำนวนมาก

## สิ่งที่ต้องมี

:::caution[ต้องใช้ API Key ของผู้ให้บริการโมเดล AI และมีค่าใช้จ่าย]
ชุดทดสอบเรียกใช้โมเดล AI จริงทุกครั้งที่รัน คุณต้องมี API Key ของผู้ให้บริการโมเดล เช่น [OpenRouter](https://openrouter.ai) ซึ่งคิดค่าบริการตามการใช้งาน ทีมงานอิงฟ้าไม่ได้จัดเตรียม Key นี้ให้
:::

- **API Key ของผู้ให้บริการโมเดล** แนะนำ OpenRouter หรือผู้ให้บริการอื่นที่รองรับรูปแบบเดียวกับ OpenAI
- **API Key ของอิงฟ้า** ที่เชื่อมต่อไว้แล้ว (ดู [ติดตั้งและเชื่อมต่อ](/guides/ingfah-skill/install/))
- **แอป AI ที่รันคำสั่งบนเครื่องได้** เช่น Claude Code หรือ Claude Desktop app ที่เปิด Code execution ไว้

## ค่าใช้จ่ายโดยประมาณ

ชุดทดสอบใช้โมเดลเดียวกับที่ AI Agent บนอิงฟ้าใช้งานจริง โดยทั่วไปการทดสอบหนึ่งรอบ (ประมาณ 40 บทสนทนา รัน 3 ครั้ง) มีค่าใช้จ่ายประมาณไม่เกิน 1 ดอลลาร์ ขึ้นอยู่กับขนาดของ Prompt และจำนวนบทสนทนา การทดสอบผลลัพธ์หลังวางสายมีค่าใช้จ่ายเพียงไม่กี่เซนต์ AI จะแจ้งจำนวนการใช้งานหลังรันทุกครั้ง

## วิธีเริ่มต้น

บอก AI ว่าต้องการทดสอบ Agent ตัวไหน และสถานการณ์ที่สำคัญกับธุรกิจของคุณ

:::tip[ตัวอย่างการสั่งงาน]
ช่วยตั้งชุดทดสอบอัตโนมัติให้ Agent "มะลิ" ให้ครอบคลุมกรณีลูกค้ายืนยันออเดอร์ ขอเลื่อนวันส่ง ขอคุยกับพนักงาน และลูกค้าไม่สะดวกคุย ผมมี OpenRouter API Key แล้ว
:::

AI จะดึงการตั้งค่าของ Agent และ Tool ที่ใช้อยู่ ตั้งชุดทดสอบในโฟลเดอร์บนเครื่องของคุณ แล้วรันให้ดูผล

:::note
โฟลเดอร์ชุดทดสอบมีข้อมูล Prompt ของ Agent ทั้งหมด ควรเก็บไว้ในที่ส่วนตัว และหากนำบทสนทนาของสายจริงมาใช้เป็นตัวอย่าง ให้ AI ลบชื่อ เบอร์โทร และข้อมูลส่วนตัวของลูกค้าออกก่อน
:::

## ควรทดสอบอะไรบ้าง

- **เส้นทางการสนทนาหลัก** ตั้งแต่ต้นจนจบสาย และทุกรูปแบบการจบสาย
- **กรณีลูกค้าไม่สะดวกคุย** หรือไม่ใช่ลูกค้าที่ต้องการติดต่อ
- **การใช้ Tool** เช่น โอนสายเมื่อลูกค้าขอคุยกับพนักงาน และไม่พูดชื่อเครื่องมือออกมา
- **ข้อห้ามสำคัญ** เช่น ไม่ขอเลขบัตรประชาชนหรือ OTP ไม่รับปากสิ่งที่ให้สัญญาไม่ได้ และตอบตามจริงเมื่อถูกถามว่าเป็น AI
- **ข้อร้องเรียน** เช่น ลูกค้าบอกว่าโทรมาบ่อยเกินไป หรือแจ้งว่าชำระเงินแล้ว
- **สายจริงที่เคยผิดพลาด** เพื่อให้แน่ใจว่าจะไม่เกิดซ้ำ
- **ผลลัพธ์หลังวางสาย** ว่าแต่ละสายได้ผลลัพธ์ที่ถูกต้อง โดยเฉพาะกรณีก้ำกึ่ง

## ขั้นตอนการแก้ไขที่แนะนำ

1. เพิ่มกรณีทดสอบที่จำลองปัญหาที่เจอ แล้วรันให้เห็นว่าผิดจริง
2. ให้ AI แก้ไข Agent
3. รันกรณีนั้นซ้ำ 2-3 ครั้ง แล้วรันชุดทดสอบทั้งหมด เพราะการแก้จุดหนึ่งอาจกระทบส่วนอื่น
4. เผยแพร่ แล้วทดลองคุยในหน้าทดลองอีกครั้งก่อนใช้งานจริง

:::note
ชุดทดสอบตรวจการตั้งค่าของ Agent ได้ใกล้เคียงการใช้งานจริงมาก แต่ไม่ได้จำลองเสียงพูด การได้ยินผิด หรือจังหวะการพูดแทรก การทดลองคุยในหน้าทดลองจึงยังเป็นการตรวจสอบขั้นสุดท้าย
:::
