# สร้าง AI Agent ตัวแรกด้วย AI

> บอก AI ว่าต้องการ AI Agent แบบไหน ให้ AI สร้างบนอิงฟ้าให้ แล้วตรวจสอบและทดลองก่อนใช้งานจริง
>
> Source: https://docs.ingfah.ai/guides/ingfah-skill/create-agent/

ก่อนเริ่ม ต้อง[ติดตั้งและเชื่อมต่อ Skill ingfah](/guides/ingfah-skill/install/)ให้เรียบร้อยก่อน

## ขั้นตอนที่ 1: บอก AI ว่าต้องการสร้าง AI Agent แบบไหน

คุณสามารถบอก AI เป็นภาษาพูดธรรมดาได้เลยว่าต้องการ AI Agent ที่ทำหน้าที่อะไร ยิ่งให้รายละเอียดครบถ้วน AI Agent ที่ได้ก็จะยิ่งทำงานได้ตรงตามที่ต้องการมากขึ้น

ข้อมูลที่ควรระบุให้ AI ทราบ:

- **บทบาทของ Agent** เช่น เพศ บุคลิก น้ำเสียง (สุภาพ ดุ เป็นกันเอง ฯลฯ)
- **ชื่อบริษัท / แบรนด์** ที่ Agent เป็นตัวแทน
- **กลุ่มลูกค้าที่ Agent จะติดต่อด้วย** เช่น ลูกค้าที่ค้างชำระ ลูกค้าที่เพิ่งสั่งซื้อสินค้า
- **สิ่งที่ต้องแจ้งลูกค้าทุกครั้ง** เช่น การขอ consent บันทึกเสียง ข้อมูลที่ต้องแจ้ง
- **เป้าหมายของการสนทนา** เช่น ต้องการให้ลูกค้ารับปากอะไร หรือให้ข้อมูลอะไรกลับมา
- **กฎที่ Agent ห้ามทำ หรือต้องทำเสมอ** เช่น ห้ามลดราคา ห้ามวางสายก่อนลูกค้า
- **ข้อมูลที่ต้องสรุปหลังจบการสนทนา** เช่น ผลลัพธ์การสนทนา วันเวลาที่ลูกค้านัดหมาย

:::tip[ตัวอย่างการสั่งงาน]
ช่วยสร้าง AI Agent เพศหญิง บุคลิกจริงจังและน่าเชื่อถือ สำหรับทวงถามหนี้ค้างชำระ

บริษัทชื่อ "อิงฟ้าไฟแนนซ์"

ลูกค้าที่ Agent จะติดต่อคือลูกค้าที่ค้างชำระเกินกำหนดวันที่ต้องจ่ายแล้ว

ทุกครั้งที่โทร Agent ต้องแจ้งข้อมูลต่อไปนี้กับลูกค้า:
1. ขอ consent การบันทึกเสียงสนทนา
2. วันครบกำหนดชำระที่ผ่านมาแล้ว
3. ยอดค้างชำระทั้งหมด

เป้าหมายหลักคือให้ลูกค้ารับปากว่าจะชำระเงินภายในวันนี้ หากลูกค้าปฏิเสธ ให้ Agent โน้มน้าวอย่างจริงจังและหนักแน่นเพื่อให้ลูกค้าตระหนักถึงความสำคัญของการชำระโดยเร็ว โดยยึดหลักว่าต้องชำระเต็มจำนวนเท่านั้น ห้ามลดยอดหรือแบ่งผ่อนชำระ

ห้าม Agent วางสายก่อน ต้องให้ลูกค้าเป็นฝ่ายวางสายเท่านั้น และต้องพยายามทวงถามให้ได้ผลลัพธ์ที่ชัดเจนก่อนจบการสนทนา

เมื่อจบการสนทนาทุกครั้ง ให้สรุปผลลัพธ์ว่าลูกค้ารับปากจะจ่ายหรือไม่ หากรับปากให้ระบุวันและเวลาที่จะชำระ หากปฏิเสธหรือมีอาการงอแง/โวยวาย ให้บันทึกไว้ในสรุปด้วย

ถ้าข้อมูลตรงไหนไม่เพียงพอ ให้ถามผมเพิ่มเติมได้
:::

หลังจากนั้น AI จะช่วยตั้งค่า Flow บทสนทนา และสร้าง AI Agent ให้บนระบบอิงฟ้าโดยอัตโนมัติ คุณสามารถเข้าไปตรวจสอบและปรับแต่งเพิ่มเติมได้ที่หน้า [ปรับแต่ง AI Agent](/guides/ai-agent/manage-ai-agent/)

## ขั้นตอนที่ 2: ตรวจสอบและทดลองก่อนใช้งานจริง

AI จะ**ขอให้คุณยืนยันทุกครั้ง**ก่อนทำสิ่งที่มีผลกับลูกค้าจริง เช่น เผยแพร่ AI Agent สร้าง Batch โทรออก หรือลบข้อมูล คุณสามารถให้ AI แสดงสิ่งที่จะเปลี่ยนก่อน แล้วค่อยตัดสินใจได้เสมอ

ก่อนเปิดใช้งานกับลูกค้าจริง แนะนำให้ทดลองคุยกับ AI Agent ในหน้า [ทดลองคุยกับ AI Agent](/guides/ai-agent/try-call/) ซึ่ง**ไม่มีค่าใช้จ่าย**และไม่ได้โทรออกจริง

:::tip[พิมพ์ข้อความนี้ให้ AI]
ก่อนเผยแพร่ ช่วยสรุปให้ดูหน่อยว่าเปลี่ยนอะไรไปบ้าง และแนะนำว่าควรทดลองคุยกับ Agent ด้วยสถานการณ์ไหนบ้าง
:::

:::note
AI Agent ตอบไม่เหมือนกันทุกครั้ง ควรทดลองสถานการณ์เดิมซ้ำ 2-3 รอบ และทดลองทั้งเรื่องที่แก้ไขและเส้นทางการสนทนาหลักอื่นๆ ด้วย เพราะการแก้ไขจุดหนึ่งอาจกระทบส่วนอื่นได้
:::

## ขั้นตอนที่ 3: นำ AI Agent ไปใช้งาน

AI Agent ต้องอยู่ใน [ทีม AI Agent](/guides/inbound-outbound/create-ai-agent-team/) จึงจะรับสายหรือโทรออกได้ ซึ่ง AI จะสร้างทีมให้พร้อมกับ Agent สิ่งที่คุณทำต่อได้:

- **รับสายเข้า** ผูกเบอร์โทรศัพท์กับทีมในหน้าเว็บ ตาม [ตั้งค่า AI Agent ให้รับสายโทรเข้า](/guides/inbound-outbound/inbound-set-up/)
- **โทรออก** ให้ AI สร้างเทมเพลตข้อมูลลูกค้าและ Batch โทรออก ดูตัวอย่างที่ [ตัวอย่างการใช้งาน](/guides/ingfah-skill/examples/#จัดการสายโทรออก)

## เคล็ดลับให้ได้ผลดี

- **ให้ข้อมูลจริงประกอบ** เช่น ลิงก์สายที่มีปัญหา สิ่งที่ลูกค้าพูด หรือสิ่งที่ Agent ควรตอบ AI จะหาสาเหตุได้แม่นยำกว่าการเล่าคร่าวๆ
- **แก้ทีละเรื่อง** แล้วทดลองก่อนแก้เรื่องถัดไป จะรู้ได้ชัดว่าการแก้ไขแต่ละครั้งได้ผลหรือไม่
- **ให้ AI แสดงก่อนเผยแพร่เสมอ** โดยเฉพาะเมื่อ Agent ใช้งานกับลูกค้าจริงอยู่แล้ว
- **การเปลี่ยนแปลงมีผลกับสายใหม่เท่านั้น** สายที่จบไปแล้วจะไม่ถูกประมวลผลใหม่
- **เริ่มแชทใหม่เมื่อเปลี่ยนงาน** เช่น เปลี่ยนจากแก้ Agent ตัวหนึ่งไปทำอีกตัว จะช่วยไม่ให้ AI สับสนข้อมูลเก่า
