# ตัวอย่างการใช้งาน Skill ingfah

> ตัวอย่างข้อความสั่งงาน AI สำหรับแก้ไข AI Agent หาสาเหตุปัญหา ตั้งค่าผลลัพธ์หลังวางสาย คลังความรู้ Tool สายโทรออก รายงาน และ webhook
>
> Source: https://docs.ingfah.ai/guides/ingfah-skill/examples/

นอกจากสร้าง AI Agent ใหม่แล้ว Skill ingfah ยังช่วยงานอื่นๆ ได้อีกมาก เพียงเล่าให้ AI ฟังด้วยภาษาพูดธรรมดา ตัวอย่างด้านล่างนำไปปรับใช้ได้ทันที โดยเปลี่ยนชื่อ Agent ชื่อทีม หรือรายละเอียดให้ตรงกับของคุณ

## แก้ไข AI Agent ที่มีอยู่แล้ว

ใช้ได้ทั้ง AI Agent ที่ AI สร้างให้ และที่คุณสร้างเองในหน้าเว็บ

:::tip[ตัวอย่างการสั่งงาน]
AI Agent ชื่อ "มะลิ" พูดยาวเกินไป และชอบถามลูกค้าซ้ำว่าสะดวกคุยไหม ช่วยปรับให้พูดกระชับขึ้นและไม่ถามซ้ำ แล้วสรุปสิ่งที่จะเปลี่ยนให้ดูก่อนเผยแพร่
:::

## หาสาเหตุเมื่อ AI Agent ทำงานผิดพลาด

AI สามารถเปิดอ่านบทสนทนาของสายจริง แล้วบอกได้ว่าปัญหาเกิดจากการตั้งค่าส่วนไหน

:::tip[ตัวอย่างการสั่งงาน]
ช่วยดูสายนี้หน่อย https://ingfah.ai/dashboard/inbound/xxxx ลูกค้าขอคุยกับพนักงาน แต่ Agent บอกว่าจะโอนสายแล้วไม่โอน เกิดจากอะไร และควรแก้ตรงไหน
:::

:::tip[ตัวอย่างการสั่งงาน]
ช่วยดู 20 สายล่าสุดของทีม "ฝ่ายบริการลูกค้า" แล้วสรุปว่า Agent ตอบผิดหรือทำให้ลูกค้าไม่พอใจตรงไหนบ้าง เรียงจากปัญหาที่เจอบ่อยที่สุด
:::

## ตั้งค่าผลลัพธ์หลังวางสาย

ใช้ตั้งค่าหัวข้อและสรุปบทสนทนา ผลลัพธ์แบบสถานะ และข้อมูลที่ต้องการเก็บจากแต่ละสาย ดูรายละเอียดเพิ่มเติมที่ [ตั้งค่าผลลัพธ์หลังวางสาย](/guides/inbound-outbound/call-outcome-setup/) และ [ผลลัพธ์แบบ Metadata](/guides/inbound-outbound/outcome-metadata/)

:::tip[ตัวอย่างการสั่งงาน]
สรุปบทสนทนาของทีม "ยืนยันออเดอร์" ชอบเข้าใจผิดว่าเราเป็นร้านซักรีด ทั้งที่เราเป็นร้านขนม และอยากให้หัวข้อสนทนาระบุเลขออเดอร์ทุกครั้ง ช่วยแก้ให้หน่อย
:::

:::tip[ตัวอย่างการสั่งงาน]
ช่วยตั้งผลลัพธ์แบบสถานะให้ทีมทวงหนี้ 4 แบบ คือ รับปากชำระ ขอผ่อนผัน ปฏิเสธ และติดต่อไม่ได้ และเก็บวันที่ลูกค้ารับปากว่าจะชำระไว้ในผลลัพธ์แบบ Metadata ด้วย
:::

## เตรียมเอกสารสำหรับคลังความรู้

AI ช่วยแปลงข้อมูลที่คุณมี เช่น ไฟล์ Excel หรือเอกสารคำถามที่พบบ่อย ให้เป็นไฟล์ที่ AI Agent ค้นหาคำตอบได้แม่นยำ จากนั้นคุณนำไฟล์ไป [อัปโหลดเข้าคลังความรู้](/guides/knowledge-base/upload-documents/) เอง

:::tip[ตัวอย่างการสั่งงาน]
ช่วยแปลงไฟล์คำถามที่พบบ่อยที่แนบมานี้ ให้เป็นไฟล์สำหรับคลังความรู้ของอิงฟ้า ลูกค้าส่วนใหญ่ถามเรื่องค่าส่งและเวลาจัดส่ง
:::

## เพิ่ม Tool ให้ AI Agent

:::tip[ตัวอย่างการสั่งงาน]
ช่วยเปิดให้ Agent "มะลิ" ใช้ Tool แปลงวันที่ได้ เพราะลูกค้าชอบนัดเป็นคำพูด เช่น "วันพุธหน้า" หรือ "สิ้นเดือนนี้" แล้ว Agent บอกวันที่ผิด
:::

:::tip[ตัวอย่างการสั่งงาน]
ช่วยสร้าง Tool ให้ Agent เช็คสถานะออเดอร์จากระบบของเรา เรียก API ที่ https://api.example.com/orders/{เลขออเดอร์} แล้วให้ Agent แจ้งสถานะกับลูกค้า
:::

ดูเพิ่มเติมเรื่อง Tool ได้ที่ [การใช้ Tools ใน AI Agent](/guides/ai-agent/ai-agent-tools/)

## จัดการสายโทรออก

:::tip[ตัวอย่างการสั่งงาน]
ช่วยสร้างเทมเพลตข้อมูลลูกค้าสำหรับทีม "ยืนยันออเดอร์" ให้มีคอลัมน์ ชื่อลูกค้า เบอร์โทร รายการสินค้า และยอดรวม
:::

:::tip[ตัวอย่างการสั่งงาน]
Batch ที่โทรเมื่อวานมีสายที่ไม่ได้รับเยอะมาก ช่วยดูหน่อยว่าเพราะอะไร แล้วแนะนำช่วงเวลาที่ควรโทรใหม่
:::

:::caution
การสร้าง Batch คือการ**โทรหาลูกค้าจริง** AI จะแสดงรายละเอียดและขอให้คุณยืนยันก่อนทุกครั้ง ตรวจสอบรายชื่อ เวลา และทีมที่ใช้โทรให้ถูกต้องก่อนตอบยืนยัน
:::

## ดูรายงานและสถิติ

:::tip[ตัวอย่างการสั่งงาน]
สรุปผลการโทรของสัปดาห์นี้ให้หน่อย มีกี่สาย รับสายกี่เปอร์เซ็นต์ ผลลัพธ์แต่ละแบบมีเท่าไหร่ และช่วงเวลาไหนลูกค้ารับสายมากที่สุด
:::

## ส่งผลการโทรไปยังระบบอื่น

:::tip[ตัวอย่างการสั่งงาน]
ทุกครั้งที่จบสายของทีม "ยืนยันออเดอร์" ช่วยส่งผลลัพธ์และสรุปบทสนทนาไปที่ webhook ของเรา https://example.com/ingfah-webhook
:::

## สอบถามวิธีใช้งานอิงฟ้า

AI ตอบคำถามจากคู่มือการใช้งานอิงฟ้าได้ โดยไม่ต้องเชื่อมต่อ API Key

:::tip[ตัวอย่างคำถาม]
การเชื่อมต่อเบอร์โทรแบบ IP Peering กับ SIP Registration ต่างกันอย่างไร บริษัทเราควรใช้แบบไหน
:::

## ตั้งชุดทดสอบอัตโนมัติ

สำหรับทีมที่แก้ไข AI Agent บ่อย ดูรายละเอียดที่ [ชุดทดสอบอัตโนมัติ](/guides/ingfah-skill/automated-testing/)

:::tip[ตัวอย่างการสั่งงาน]
ช่วยตั้งชุดทดสอบอัตโนมัติให้ Agent "มะลิ" ให้ครอบคลุมกรณีลูกค้ายืนยันออเดอร์ ขอเลื่อนวันส่ง ขอคุยกับพนักงาน และลูกค้าไม่สะดวกคุย ผมมี OpenRouter API Key แล้ว
:::
