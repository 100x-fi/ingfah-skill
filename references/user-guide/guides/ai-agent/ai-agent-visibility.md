# การตั้งค่าการมองเห็น AI Agent

> การกำหนดสิทธิ์การมองเห็นและการเข้าถึง AI Agent
>
> Source: https://docs.ingfah.ai/guides/ai-agent/ai-agent-visibility/

AI Agent สามารถกำหนดการมองเห็นได้ 2 รูปแบบ คือ **สาธารณะ** และ **ส่วนตัว**

---

## วิธีตั้งค่าการมองเห็น

1. เปิด AI Agent ที่ต้องการตั้งค่า

2. คลิกเมนู **⋮** บริเวณมุมขวาบน แล้วเลือก **ตั้งค่า**

3. เลือกรูปแบบการเข้าถึงที่ต้องการระหว่าง **สาธารณะ** และ **ส่วนตัว**

4. คลิก **บันทึกการตั้งค่า**

---

## รูปแบบการมองเห็น

### สาธารณะ

AI Agent ที่ตั้งค่าเป็น **สาธารณะ** สามารถมองเห็นและใช้งานได้โดย Operator คนอื่นภายในองค์กร

เหมาะสำหรับ AI Agent ที่ต้องการให้สมาชิกในทีมใช้งานร่วมกัน

---

### ส่วนตัว

AI Agent ที่ตั้งค่าเป็น **ส่วนตัว** จะมองเห็นได้เฉพาะผู้สร้าง AI Agent และ Owner

Operator คนอื่นจะไม่สามารถมองเห็น AI Agent นี้ได้ บนหน้ารายการ AI Agent จะแสดงป้าย **ส่วนตัว**

---

## การมองเห็นตามสิทธิ์ผู้ใช้งาน

- **Operator**

  > มองเห็น AI Agent ที่เป็น **สาธารณะ** และ AI Agent ที่ตนเองสร้าง

- **Owner**

  > มองเห็น AI Agent ทั้งหมดภายในองค์กร

การเปลี่ยนการตั้งค่าการมองเห็นสามารถทำได้เฉพาะ **ผู้สร้าง AI Agent**
