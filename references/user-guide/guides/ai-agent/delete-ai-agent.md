# การลบ AI Agent

> วิธีลบแบบร่างและลบ AI Agent ออกจากระบบ
>
> Source: https://docs.ingfah.ai/guides/ai-agent/delete-ai-agent/

**การลบ AI Agent** สามารถลบได้ 2 แบบ ได้แก่ **ลบแบบร่าง** และ **ลบ AI Agent**

---

### ลบแบบร่าง

ใช้สำหรับลบการแก้ไขที่อยู่ในสถานะ **แบบร่าง** โดยไม่ลบ AI Agent ออกจากระบบ

1. เปิด AI Agent ที่ต้องการ

2. เลือกแท็บ **แบบร่าง** แล้วคลิกเมนู **⋮** บริเวณมุมขวาบน

3. เลือก **ลบแบบร่าง**

4. ยืนยันการลบแบบร่าง

---

### ลบ AI Agent

ใช้สำหรับลบ AI Agent ออกจากระบบ

แม้ AI Agent จะยังไม่เคยเผยแพร่ หากต้องการลบ AI Agent ให้ดำเนินการจากแท็บ **เผยแพร่**

1. เปิด AI Agent ที่ต้องการลบ

2. เลือกแท็บ **เผยแพร่** แล้วคลิกเมนู **⋮** บริเวณมุมขวาบน

3. เลือก **ลบ AI Agent**

4. ยืนยันการลบ AI Agent
