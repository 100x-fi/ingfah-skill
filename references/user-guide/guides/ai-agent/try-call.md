# ทดลองคุยกับ AI Agent ก่อนใช้งานจริง

> ทดลองคุยกับ AI Agent ก่อนใช้งานจริง
>
> Source: https://docs.ingfah.ai/guides/ai-agent/try-call/

คุณสามารถทดลองคุยกับ AI Agent ที่ตั้งค่าเรียบร้อยแล้วได้โดยไม่เสียค่าใช้จ่าย และไม่ต้องโทรออกจากระบบโทรศัพท์จริง

:::note[AI Agent แบบข้อความ]
หาก AI Agent ของคุณเป็นแบบข้อความ ปุ่ม **ทดลอง** จะเปิดหน้าต่างแชทแทนการโทร และเมนูจะเปลี่ยนเป็น **ประวัติการทดลองแชท**
:::

## วิธีการทดลองคุยกับ AI Agent

1. ไปที่หน้าของ AI Agent แล้วเลือกว่าจะทดลองคุยในเวอร์ชัน **เผยแพร่** หรือ **แบบร่าง**

2. กดที่ลูกศรด้านขวามือของปุ่ม **"ทดลอง"** แล้วเลือก **"ตั้งค่าและทดลอง"**

3. เลือก **เทมเพลต** ที่ต้องการทดลอง เทมเพลตจะกำหนดว่าตัวแปรใดบ้างที่สามารถปรับค่าได้ระหว่างการทดลองโทร

   :::tip[เคล็ดลับ]
   เลือกเทมเพลต **"รับสาย"** เพื่อดูและแก้ไขตัวแปรทั้งหมดที่มีในระบบ
   :::

4. ใส่ข้อมูลในตัวแปรที่ต้องการให้ AI Agent ใช้ระหว่างการทดลองโทร เพื่อให้การทดลองใกล้เคียงกับสถานการณ์จริงมากที่สุด

:::note[ข้อมูลถูกบันทึกอัตโนมัติ]
ค่าที่คุณกรอกในตัวแปรจะถูกบันทึกไว้ ครั้งต่อไปที่กด **"ทดลอง"** AI Agent จะใช้ข้อมูลชุดเดิมโดยอัตโนมัติ
:::

## ดูประวัติการทดลอง

ทุกครั้งที่ทดลองโทรหรือทดลองแชท ระบบจะเก็บบทสนทนาไว้ให้ย้อนดูได้ เหมาะกับการเปรียบเทียบว่าหลังแก้ Prompt แล้ว AI Agent ตอบต่างจากเดิมอย่างไร

1. ไปที่หน้าของ AI Agent ตัวนั้น
2. กดลูกศรด้านขวามือของปุ่ม **ทดลอง**
3. เลือก **ประวัติการทดลอง**

หน้าประวัติแบ่งเป็นสองฝั่ง ฝั่งซ้ายคือรายการการทดลองทั้งหมด ฝั่งขวาคือรายละเอียดของรายการที่เลือก

### รายการการทดลอง (ฝั่งซ้าย)

- แต่ละรายการตั้งชื่ออัตโนมัติตามรูปแบบ *โทรจาก [อีเมลผู้ทดลอง] ถึง [ชื่อ AI Agent]*
- ค้นหาได้จากช่องค้นหาด้านบน
- รายการที่มีการบันทึก Note ไว้จะมีสัญลักษณ์กำกับ ทำให้หาสายที่เคยตั้งข้อสังเกตไว้ได้เร็วขึ้น
- เลื่อนลงเพื่อโหลดรายการเก่าเพิ่มเติม

### รายละเอียดการทดลอง (ฝั่งขวา)

| ส่วน | รายละเอียด |
|------|-----------|
| **บทสนทนา** | ข้อความการสนทนาทั้งหมดระหว่างคุณกับ AI Agent |
| **สรุปการสนทนา** | สรุปใจความสำคัญที่ระบบทำให้อัตโนมัติ |
| **ไฟล์เสียง** | เล่นฟังย้อนหลังและดาวน์โหลดได้ พร้อมแสดงระยะเวลาของสาย |
| **Note** | บันทึกข้อสังเกตของการทดลองครั้งนั้น |

:::note[บางสายอาจไม่มีไฟล์เสียง]
หากระบบไม่ได้บันทึกเสียงของการทดลองครั้งนั้นไว้ จะแสดงป้าย **ไม่มีไฟล์เสียง** แทนตัวเล่นเสียง ส่วนการทดลองแบบแชทจะไม่มีไฟล์เสียงเสมอ เพราะไม่มีการสนทนาด้วยเสียง
:::

## บันทึก Note ของการทดลองแต่ละครั้ง

ในหน้ารายละเอียด กดที่ช่อง **เพิ่ม Note ของการทดลองโทรครั้งนี้** แล้วพิมพ์ข้อสังเกตได้เลย เช่น "รอบนี้ AI ยังพูดยาวเกินไปตอนอธิบายโปรโมชัน" ระบบจะบันทึกให้อัตโนมัติ

- Note ที่ถูกแก้ไขจะมีป้าย **edited** กำกับ พร้อมบอกว่าใครแก้และแก้เมื่อไหร่
- Note ยาวๆ จะถูกย่อไว้ กด **แสดงทั้งหมด** เพื่ออ่านต่อ

:::tip[ใช้ Note เป็นบันทึกการปรับจูน]
ทีมที่ปรับ Prompt หลายรอบมักใช้ Note จดว่ารอบนั้นแก้อะไรไป และผลลัพธ์ดีขึ้นหรือแย่ลงตรงไหน ทำให้ย้อนกลับมาเทียบกันได้โดยไม่ต้องฟังไฟล์เสียงซ้ำทั้งสาย
:::
