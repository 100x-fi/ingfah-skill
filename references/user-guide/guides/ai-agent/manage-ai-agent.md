# ปรับแต่ง AI Agent

> เรียนรู้ระบบแบบร่างและเผยแพร่ของ AI Agent เพื่อแก้ไขและทดสอบโดยไม่กระทบการใช้งานจริง
>
> Source: https://docs.ingfah.ai/guides/ai-agent/manage-ai-agent/

## ทำความเข้าใจ "เผยแพร่" และ "แบบร่าง"

AI Agent ของ ingfah มีระบบ **แบบร่าง (Draft)** และ **เผยแพร่ (Published)** แยกจากกัน เพื่อให้คุณแก้ไขและทดสอบได้อย่างอิสระ โดยไม่กระทบกับ AI Agent ที่กำลังใช้งานจริง

:::note[หลักการสำคัญ]
- **แบบร่าง** - แก้ไขได้อิสระ ยังไม่ส่งผลต่อผู้ใช้งานจริง
- **เผยแพร่** - ใช้งานจริงอยู่ ไม่สามารถแก้ไขโดยตรงได้
- เมื่อ **เผยแพร่แบบร่าง** แล้ว แบบร่างจะถูกแทนที่เวอร์ชันที่เผยแพร่อยู่และหายไป
:::

## วิธีแก้ไขแบบร่าง AI Agent

### กรณีที่ยังไม่มีแบบร่าง

1. คลิกที่ **"แบบร่าง"** ที่ด้านบนของ AI Agent

2. คลิกที่ **"ร่างใหม่จากเผยแพร่"**

   ระบบจะคัดลอกข้อมูลจากเวอร์ชันที่เผยแพร่อยู่มาเป็นแบบร่างใหม่ พร้อมให้แก้ไขทันที

### กรณีที่มีแบบร่างอยู่แล้ว

กดปุ่ม **"แก้ไขแบบร่าง"** เพื่อเปิดแบบร่างที่มีอยู่

## การแก้ไขข้อมูลเบื้องต้นของ AI Agent

ในแถบด้านซ้ายของ AI Agent มีช่องข้อมูลที่แก้ไขได้ดังนี้

---

**ชื่อ AI Agent**

ชื่อที่แสดงตัวตนของ AI Agent เมื่อตั้งชื่อแล้ว ชื่อนี้จะถูกเรียกใช้ผ่านตัวแปร `{{agentName}}` ในช่องอื่นๆ ของหน้านี้ได้ และเป็นชื่อที่ AI Agent จะใช้เรียกแทนตัวเองระหว่างสนทนา

---

**Agent Vocal Name**

ชื่อตำแหน่งของ AI Agent ใช้ในกรณีที่ทีมมี AI Agent หลายตัว เพื่อให้ Agent รู้ว่าจะเรียก Agent อื่นว่าอะไรเมื่อต้องโอนสาย

:::tip[ตัวอย่าง]
Agent ตัวแรกมี Vocal Name ว่า **"เจ้าหน้าที่คัดกรองภาษา"** มีหน้าที่ระบุภาษาที่ลูกค้าต้องการ เมื่อลูกค้าแจ้งว่าต้องการบริการภาษาไทย Agent จะโอนสายต่อไปยัง Agent ที่มี Vocal Name ว่า **"เจ้าหน้าที่บริการภาษาไทย"** โดยอัตโนมัติ
:::

---

**ข้อความทักทายเริ่มต้น**

ข้อความที่ AI Agent จะพูดเป็นลำดับแรกเมื่อเริ่มสาย ผู้โทรไม่สามารถขัดจังหวะได้ - AI Agent จะพูดจนจบก่อน แล้วจึงเริ่มรับฟังการสนทนาต่อไป

---

**ตัวตน**

บุคลิกและโทนการสนทนาของ AI Agent เช่น สุภาพ น่าเชื่อถือ พูดกระชับ ระบบจะใช้ข้อมูลนี้ควบคุมรูปแบบประโยคและการบริการลูกค้าตลอดการสนทนา

---

**เป้าหมาย / หน้าที่**

Prompt หลักของ AI Agent - คำสั่งและข้อมูลที่บอกให้ AI Agent ปฏิบัติตาม ช่องนี้รองรับข้อมูลหลากหลาย เช่น

- เป้าหมายการทำงานของ AI Agent
- ขอบเขตว่าสิ่งใดทำได้ ทำไม่ได้ ตอบได้ และตอบไม่ได้
- ข้อบังคับการออกเสียงหรือการสะกดชื่อสินค้า
- ข้อมูล Knowledge Base เบื้องต้นที่ AI Agent นำไปตอบลูกค้าได้

:::note[ความปลอดภัยจากระบบ ingfah]
ระบบของ ingfah จะมีการเพิ่ม System Prompt หรือชุดคำสั่งพื้นฐานให้กับ AI Agent ทุกตัวในเบื้องหลังเสมอ สำหรับ System Prompt นี้จะเป็นการเสริมความปลอดภัย และป้องกันปัญหาที่อาจจะเกิดขึ้นกับ AI Agent ได้ โดยจะประกอบไปด้วยหัวข้อต่อไปนี้

- ขอบเขตความรู้ - ถ้า AI Agent ไม่มีข้อมูลในเรื่องที่ถูกถาม จะต้องบอกว่าไม่ทราบ หรือไม่รู้ ห้ามคิดคำตอบขึ้นมาเองด้วยข้อมูลที่ผิด
- ป้องกันการหลอกให้ AI Agent เปลี่ยนตัวตนเพื่อขโมยข้อมูลหรือทำสิ่งที่ไม่ควรทำ
- ป้องกันเรื่องการละเมิดลิขสิทธิ์ และการให้ข้อมูลที่ผิดกฎหมาย
- เปิดเผยตัวตนว่าเป็นระบบ AI เมื่อถูกถาม
- พูดอย่างเป็นธรรมชาติเหมือนมนุษย์พูด ไม่สร้างคำพูดแบบหุ่นยนต์
:::

---

**เสียง**

เลือกเสียงพูดของ AI Agent จากเสียงที่ ingfah มีให้ โดยจะมีเสียงตั้งต้นทั้งเสียงผู้ชายและเสียงผู้หญิงอย่างละหนึ่งเสียง หากต้องการเสียงเพิ่มเติม สามารถใช้บริการ **Voice Clone** ของ ingfah เพื่อเพิ่มเสียงที่ต้องการได้

---

**ความเร็วในการพูด**

กำหนดความเร็วในการพูดตลอดทั้งการสนทนา ปรับให้ AI Agent พูดช้าหรือเร็วได้ตามความเหมาะสม
