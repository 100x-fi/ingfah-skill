# ควบคุมทิศทางการสนทนา

> กำหนดจำนวนครั้งการโน้มน้าว จำกัดการถามวน และป้องกันไม่ให้ AI Agent คำนวณวันที่เอง
>
> Source: https://docs.ingfah.ai/guides/ai-agent/conversation-control/

AI Agent ที่ไม่มีขอบเขตชัดเจนจะโน้มน้าวไม่หยุด ถามวนไปมา หรือเดาข้อมูลที่ไม่ควรเดา หน้านี้รวมกฎที่ช่วยคุมทิศทางการสนทนาให้จบตามเป้าหมาย

---

## กำหนดจำนวนครั้งของการโน้มน้าว

ถ้าไม่ระบุงบการโน้มน้าวไว้ AI Agent จะโน้มน้าวต่อไปเรื่อยๆ จนลูกค้ารำคาญ หรือในทางกลับกัน จะยอมแพ้ตั้งแต่ลูกค้าปฏิเสธครั้งแรก เลือกรูปแบบที่เหมาะกับแคมเปญของคุณ

### แบบที่ 1 — โน้มน้าวได้ครั้งเดียว

เหมาะกับแคมเปญที่เน้นประสบการณ์ลูกค้ามากกว่ายอดปิด

```
- ห้ามยัดเยียดหรือเสนอซ้ำเกิน 1 ครั้งหลังลูกค้าปฏิเสธแล้ว
```

### แบบที่ 2 — โน้มน้าว 3 จังหวะ จังหวะละหนึ่งเทิร์น

เหมาะกับงานขายหรือแคมเปญที่ต้องการให้พยายามจนครบ

```
**โน้มน้าวเมื่อลูกค้ายังไม่สนใจ**
- ถามเหตุผลที่ยังไม่สนใจอย่างเข้าใจ ไม่กดดัน
- **ต้องโน้มน้าวให้ครบทั้ง 3 จังหวะ** — เสนอทีละจังหวะ (1 จังหวะต่อ 1 เทิร์น) รอลูกค้าตอบ
  ถ้ายังปฏิเสธให้ขึ้นจังหวะถัดไปทันที ห้ามยัดรวดเดียว
  และห้ามหยุดหรือข้ามไปนัดโทรกลับก่อนใช้ครบทั้ง 3 จังหวะ
  - จังหวะ 1 — ตอบข้อโต้แย้งตามเหตุผล
  - จังหวะ 2 — โปรโมชันจำกัด/ข้อเสนอพิเศษ
  - จังหวะ 3 — ข้อเสนอสุดท้าย
  - **หลังจังหวะ 3 แล้วลูกค้ายังปฏิเสธเท่านั้น** → ค่อยไปขั้นตอนถัดไป
- **กรณีที่แก้ให้ไม่ได้จริงๆ (เช่น ไม่เข้าเงื่อนไข ไม่มีพื้นที่ให้บริการ):
  โน้มน้าวแค่ครั้งเดียวพอ ไม่ต้องครบ 3 จังหวะ**
```

:::caution[นับจากจำนวนครั้งที่ AI พูดโน้มน้าว ไม่ใช่จำนวนครั้งที่ลูกค้าปฏิเสธ]
เป็นจุดที่เขียนผิดกันบ่อยที่สุด ถ้าเขียนว่า "หลังลูกค้าปฏิเสธ 3 ครั้ง" AI Agent จะนับคำพูดของลูกค้าที่ไม่ได้เป็นการปฏิเสธจริงเข้าไปด้วย ให้ระบุให้ชัดว่า

```
นับจากจำนวนครั้งที่ AI Agent ใช้คำพูดโน้มน้าวจริงๆ ไม่ใช่จำนวนครั้งที่ลูกค้าปฏิเสธ
```
:::

## จำกัดจำนวนครั้งของการถามคำถามเดิม

ถ้าลูกค้าตอบไม่ตรงคำถาม AI Agent จะถามซ้ำไปเรื่อยๆ จนสายยืดเยื้อ ให้กำหนดโควตาและค่าที่จะใช้เมื่อถามครบแล้วยังไม่ได้คำตอบ

```
กติกาของขั้นตอนนี้:
- ถ้าลูกค้ายังไม่ตอบตามที่ถาม ให้ถามได้อีกครั้งเดียว แต่ต้องเปลี่ยนคำพูด ห้ามพูดประโยคเดิมซ้ำ
- ถ้าถามครั้งที่สองแล้วยังไม่ได้คำตอบ ให้ใช้ค่าเริ่มต้นที่กำหนดไว้ แล้วทวนยืนยัน
  ห้ามถามเป็นครั้งที่สาม
- ถ้าลูกค้าถามกลับว่าไม่เข้าใจคำถาม ให้อธิบายสั้นๆ พร้อมถามใหม่ได้หนึ่งครั้ง
  โดยนับรวมเป็นการถามครั้งที่สอง
```

### ระวังลูปคำถามวินิจฉัย

คำสั่งประเภท "ถามให้เข้าใจปัญหาก่อนค่อยอธิบาย" ทำให้ AI Agent ถามต่อเนื่องหลายเทิร์นโดยไม่ยอมตอบสักที ให้จำกัดเป็นคำถามเดียว

```
ถามคำถามวินิจฉัยเพียง 1 คำถาม เมื่อลูกค้าตอบแล้ว ให้ตอบทันที ห้ามถามเพิ่ม
```

## ห้าม AI Agent คำนวณวันที่เอง

AI คำนวณวันในสัปดาห์ หรือแปลงคำว่า "พรุ่งนี้" เป็นวันที่ปฏิทินได้ไม่แม่นยำ และมักตอบวันผิดอย่างมั่นใจ

วิธีที่ถูกต้องมี 3 ทาง เรียงตามลำดับที่แนะนำ

1. **เปิด Tool [`resolve_date`](/guides/ai-agent/ai-agent-tools/#resolve_date)** ให้ AI Agent แปลงคำพูดอย่าง "พรุ่งนี้" หรือ "วันพุธหน้า" เป็นวันที่ปฏิทินให้ — เป็นวิธีที่แม่นยำที่สุดและใช้ได้กับทุกแคมเปญ
2. ใช้ [{{ตัวแปร}}](/guides/ai-agent/flow-variables/) วันที่ที่ระบบเตรียมไว้ให้
3. ทวนตามคำที่ลูกค้าพูดเป๊ะๆ โดยไม่แปลงเป็นวันที่

:::tip[เปิด Tool แล้วลบกฎแก้ขัดออกได้]
เมื่อเปิด `resolve_date` ให้ AI Agent แล้ว ไม่จำเป็นต้องเขียนกฎซับซ้อนเพื่อเลี่ยงการคำนวณวันที่อีก เหลือเพียงสั่งให้เรียก Tool นี้ทุกครั้งที่ลูกค้าพูดถึงวันแบบสัมพัทธ์ และห้ามเดาเอง
:::

```
### กฎการจัดการวันที่ (ห้ามคำนวณเอง)

- ถ้าลูกค้าตอบว่า "พรุ่งนี้" ให้ใช้ค่าวันที่จากตัวแปรที่ระบบคำนวณมาให้เท่านั้น
  หรือเรียก Tool resolve_date ห้ามคำนวณวันที่หรือชื่อวันในสัปดาห์เอง
- ถ้าลูกค้าระบุวันอื่น ให้ทวนคำพูดของลูกค้ากลับไปตามที่ลูกค้าพูดเป๊ะๆ เท่านั้น
  ห้ามคำนวณ แปลง หรือเติมวันที่ปฏิทิน/วันในสัปดาห์ที่ลูกค้าไม่ได้พูดเอง
- ตรวจสอบวันที่ที่เป็นไปไม่ได้ เช่น 31 เมษายน ให้ถามลูกค้าใหม่
```

### ตารางแปลงเลขเดือนใช้ได้

การเปิดตารางไม่ใช่การคำนวณ จึงไม่ขัดกับกฎด้านบน และช่วยให้ AI อ่านวันที่ได้เป็นธรรมชาติ

```
ค่าวันที่จากระบบอยู่ในรูปแบบ วัน/เดือน/ปี เช่น "30/06/2569"
ห้ามอ่านเป็นตัวเลขติดกัน และห้ามอ่านเครื่องหมาย "/" เป็น "ทับ" เด็ดขาด
ให้แปลงเป็นคำพูดวันที่ธรรมชาติเสมอ โดยใช้ตารางแปลงเลขเดือนนี้

| เลขเดือน | ชื่อเดือน | เลขเดือน | ชื่อเดือน |
|---|---|---|---|
| 01 | มกราคม | 07 | กรกฎาคม |
| 02 | กุมภาพันธ์ | 08 | สิงหาคม |
| 03 | มีนาคม | 09 | กันยายน |
| 04 | เมษายน | 10 | ตุลาคม |
| 05 | พฤษภาคม | 11 | พฤศจิกายน |
| 06 | มิถุนายน | 12 | ธันวาคม |

รูปแบบการอ่าน: [วันที่สะกดเป็นคำ] + [ชื่อเดือนภาษาไทย] + [ปีสะกดเป็นคำ]

- ❌ ผิด: "สามศูนย์ศูนย์หกสองห้าหกเก้า"
- ❌ ผิด: "สามสิบ ทับ ศูนย์หก ทับ สองห้าหกเก้า"
- ✅ ถูก: "สามสิบมิถุนายน สองพันห้าร้อยหกสิบเก้า"
```
