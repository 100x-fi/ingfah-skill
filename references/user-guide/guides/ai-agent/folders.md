# จัดกลุ่ม AI Agent ด้วยโฟลเดอร์

> โฟลเดอร์ช่วยจัด AI Agent ในหน้า AI Agents เป็นกลุ่มตามทีมหรืองาน เมื่อมี AI Agent หลายสิบตัว คุณจะหาตัวที่ต้องการได้เร็วขึ้น
>
> Source: https://docs.ingfah.ai/guides/ai-agent/folders/

:::tip[ฟีเจอร์ใหม่: โฟลเดอร์ AI Agent]
จัด AI Agent เป็นกลุ่มตามทีมหรืองานด้วยโฟลเดอร์และโฟลเดอร์ย่อย แล้วเปิดดูได้ทั้งแบบตารางและแบบรายการ
:::

โฟลเดอร์ช่วยจัด AI Agent ในหน้า **AI Agents** เป็นกลุ่มตามทีมหรืองาน เช่น “ฝ่ายขาย” “การเงิน” และ “การตลาด” เมื่อมี AI Agent หลายสิบตัว คุณจะหาตัวที่ต้องการได้เร็วขึ้น ในโฟลเดอร์สามารถสร้างโฟลเดอร์ย่อยได้

ทุกคนในองค์กรเห็นโฟลเดอร์ชุดเดียวกัน และโฟลเดอร์ใช้จัดหน้าเท่านั้น การย้าย AI Agent เข้าหรือออกจากโฟลเดอร์ไม่กระทบการทำงานของ AI Agent

### มุมมองตารางและมุมมองรายการ {#fd-views}

เลือกมุมมองได้จากไอคอน 2 ปุ่มข้าง **สร้าง AI Agent** ที่มุมขวาบน

| มุมมอง | แสดงอะไร |
| --- | --- |
| แบบตาราง (ไอคอนสี่ช่อง) | โฟลเดอร์ทั้งหมดอยู่ด้านบน พร้อมจำนวน AI Agent ในแต่ละโฟลเดอร์ และการ์ด AI Agent อยู่ด้านล่าง |
| แบบรายการ (ไอคอนคอลัมน์) | โฟลเดอร์เรียงเป็นคอลัมน์ทางซ้าย กดโฟลเดอร์เพื่อดูโฟลเดอร์ย่อยและ AI Agent ข้างในที่คอลัมน์ถัดไป และกด AI Agent เพื่อดูตัวอย่างทางขวา |

## วิธีทำ {#fd-how}

### สร้างโฟลเดอร์ {#fd-create}

1. ไปที่ **AI Agents** > **Agents** ที่แถบเมนูด้านซ้าย
2. กด **+ เพิ่มโฟลเดอร์** ใต้รายการโฟลเดอร์
3. ตั้งชื่อโฟลเดอร์ตามทีมหรืองาน เช่น `ฝ่ายขาย` แล้วบันทึก

โฟลเดอร์ใหม่แสดงในส่วน **โฟลเดอร์** พร้อมจำนวน AI Agent ข้างใน ถ้าต้องการโฟลเดอร์ย่อย ให้เปิดโฟลเดอร์ที่ต้องการก่อน แล้วกด **+ เพิ่มโฟลเดอร์**

### ย้าย AI Agent เข้าโฟลเดอร์ {#fd-move}

ลาก AI Agent ไปวางบนโฟลเดอร์ที่ต้องการ จำนวนข้างชื่อโฟลเดอร์จะเพิ่มขึ้นทันที AI Agent หนึ่งตัวอยู่ได้ในโฟลเดอร์เดียว ถ้าลากไปวางในโฟลเดอร์อื่น AI Agent จะย้ายออกจากโฟลเดอร์เดิม

### เปิดดู AI Agent ในโฟลเดอร์ {#fd-browse}

1. กดไอคอน **แสดงแบบรายการ** ข้างปุ่ม **สร้าง AI Agent**
2. กดโฟลเดอร์ในคอลัมน์ซ้าย คอลัมน์ถัดไปจะแสดงโฟลเดอร์ย่อยและ AI Agent ในโฟลเดอร์นั้น
3. กด AI Agent เพื่อดูตัวอย่างทางขวา แล้วกด **เปิด AI Agent** เพื่อแก้ไข

แถบด้านบนตารางบอกว่าคุณอยู่ที่ไหน เช่น AI Agents › ไอทีและเทคโนโลยี › น้ำฝน กดชื่อในแถบนี้เพื่อย้อนกลับไปชั้นก่อนหน้า

### ค้นหาด้วยชื่อโฟลเดอร์ {#fd-search}

พิมพ์ชื่อโฟลเดอร์ในช่อง **ค้นหาด้วยชื่อ AI Agent โฟลเดอร์ หรือคำอธิบาย** ใช้ร่วมกับตัวกรอง **สถานะ** **ทีม AI Agent** และ **สร้างโดย** ได้ กด **รีเซ็ต** เพื่อล้างตัวกรองทั้งหมด

### เปลี่ยนชื่อและลบโฟลเดอร์ {#fd-edit}

เปลี่ยนชื่อโฟลเดอร์ได้เมื่อทีมหรืองานเปลี่ยน และลบโฟลเดอร์ที่ไม่ใช้แล้วได้

:::caution[ข้อควรระวัง]
- ทุกคนในองค์กรเห็นโฟลเดอร์ชุดเดียวกัน การเปลี่ยนชื่อ ย้าย หรือลบโฟลเดอร์จึงมีผลกับทุกคน
- AI Agent ที่ตั้งเป็น **ส่วนตัว** คนอื่นจะไม่เห็นในโฟลเดอร์ แต่ยังเห็นตัวโฟลเดอร์ และจำนวนจะไม่นับ AI Agent ที่มองไม่เห็น เช่น โฟลเดอร์ที่มีแต่ AI Agent ส่วนตัวของคนอื่นจะแสดงจำนวน 0
- โฟลเดอร์ไม่ได้เชื่อม AI Agent เข้าด้วยกัน ถ้าต้องการให้ AI Agent หลายตัวทำงานร่วมกันในสาย ให้ใช้[ทีม AI Agent](/guides/inbound-outbound/create-ai-agent-team/)
:::
