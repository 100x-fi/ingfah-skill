# การสร้าง Flow บทสนทนา

> การสร้าง Flow บทสนทนา
>
> Source: https://docs.ingfah.ai/guides/ai-agent/how-to-create-agent-flow/

## สร้าง Flow บทสนทนาอย่างไร?

### 1. เพิ่ม Node และกรอกข้อมูล

กดปุ่ม **"เพิ่ม Node"** เพื่อเพิ่มขั้นตอนใหม่ใน Flow

:::note[Node คืออะไร]
Node หรือกล่องแต่ละกล่องใน Flow ทำหน้าที่เป็นขั้นตอนหรือเป้าหมายที่ AI Agent จะอ่านและดำเนินการตาม คุณสามารถระบุตัวอย่างประโยคเพื่อให้ AI Agent พูดตามสคริปต์ที่กำหนดไว้ หรือปล่อยให้ AI Agent คิดบทสนทนาด้วยตัวเองตามสถานการณ์ก็ได้
:::

---

### 2. กำหนดชื่อและคำอธิบายของ Node

ชื่อและคำอธิบายช่วยให้ผู้ที่เข้ามาแก้ไข Flow เข้าใจได้อย่างรวดเร็วว่า Node แต่ละกล่องมีหน้าที่ทำอะไร และข้อมูลนี้ยังถูกส่งให้ AI Agent ด้วย จึงช่วยให้ AI Agent ทำงานกับ Node นี้ได้แม่นยำขึ้น

---

### 3. กำหนดหน้าที่ของ AI Agent

คำสั่งในช่องนี้บอกให้ AI Agent ทราบว่าต้องทำอะไรในขั้นตอนนี้โดยเฉพาะ คล้ายกับ "เป้าหมาย/หน้าที่" แต่ใช้ได้เฉพาะใน Node นั้น

คุณสามารถใช้[ตัวแปร](./flow-variables)ในหน้าที่ Agent ได้เช่นกัน เช่น `{{agentName}}` หรือ `{{customerContext.customer_name}}` เพื่อให้ AI Agent รับรู้ข้อมูลจริงในขณะที่สนทนา

:::tip[ตัวอย่าง]
**สอบถามความพึงพอใจจากลูกค้า**

หน้าที่ Agent: คุณจะต้องสอบถามความพึงพอใจของลูกค้าหลังการได้รับบริการ คุณจะต้องถามทีละคำถามแล้วรอให้ลูกค้าตอบ
คำถาม คือ 1. คุณภาพบริการของลูกค้าเป็นอย่างไร 2. คุณชอบส่วนไหนของบริการเป็นพิเศษ 3. คุณมีข้อเสนอแนะอะไรเพื่อปรับปรุงบริการของเราหรือไม่

**แจ้งข้อมูลลูกค้าตามสคริปต์**

หน้าที่ Agent: แจ้งข้อมูลลูกค้าตามสคริปต์

**ปิดการสนทนากับลูกค้า**

หน้าที่ Agent: สอบถามลูกค้าว่ามีคำถามเพิ่มเติมหรือไม่ แล้วรอให้ลูกค้าตอบ ถ้าลูกค้าไม่มีคำถามเพิ่มเติม ให้ขอบคุณลูกค้า อวยพร และขออนุญาตวางสายอย่างสุภาพ
:::

---

### 4. กำหนดตัวอย่างประโยค

ตัวอย่างประโยคช่วยให้ AI Agent พูดตามสคริปต์ที่กำหนดไว้ใน Node นั้น หากไม่ได้ระบุ AI Agent จะใช้ข้อมูลจาก **หน้าที่ Agent** ในการคิดบทสนทนาที่เหมาะสมขึ้นมาเอง

กด **"+ เพิ่ม"** เพื่อเพิ่มตัวอย่างประโยคหลายอันให้ครอบคลุมสถานการณ์ต่างๆ

คุณสามารถใช้[ตัวแปร](./flow-variables)ในตัวอย่างประโยคได้ โดยเขียนในรูปแบบ `{{ชื่อตัวแปร}}` เพื่อให้ AI Agent แทนที่ด้วยข้อมูลจริงขณะสนทนา เช่น `{{agentName}}` หรือ `{{customerContext.customer_name}}`

:::tip[ตัวอย่าง]
- {{agentName}} ขอสอบถาม ช่วงวันและเวลาที่สะดวก ในการติดต่ออีกครั้งค่ะ
- ขออภัยที่รบกวนค่ะ ขออนุญาตวางสายค่ะ
- {{agentName}} ขออภัยที่รบกวน {{suffixSoftener}} ขอบคุณ {{suffix}}
- \<speed ratio="0.6" /> คุณ{{customerContext.customer_first_name}}สั่งซื้อ {{customerContext.order_sumamry}} ราคา {{customerContext.order_price}} บาท จัดส่งไปที่ {{customerContext.customer_address_short}} ถูกต้องนะคะ
:::

---

### 5. ตรวจสอบและยืนยัน

ตรวจสอบข้อมูลที่กรอกให้ถูกต้อง แล้วกดปุ่ม **"ยืนยัน"** เพื่อสร้างหรือบันทึกการแก้ไข Node

---

### 6. เชื่อมต่อ Node ด้วยการลากเส้น

ลากจาก Node ที่มีอยู่เพื่อสร้างเส้นทางไปยัง Node ใหม่ หลังจากลากแล้ว คุณสามารถใส่**เงื่อนไข**บนเส้นทางนั้น เพื่อให้ AI Agent จัดการกับคำตอบและสถานการณ์ต่างๆ ของลูกค้าได้

ไม่จำเป็นต้องมีหลายเส้นทางออกจากทุก Node - บาง Node อาจมีเส้นทางเดียวได้ เช่น Node ที่ต้องถามลูกค้า 5 ข้อ สามารถลากเส้นทางเดียวที่มีเงื่อนไขว่า **"ได้คำตอบครบ 5 ข้อ"** เพื่อบอกให้ AI Agent ทำให้เงื่อนไขนี้สำเร็จก่อนไปต่อ

:::tip[ตัวอย่างเงื่อนไข]
- สอบถามว่าลูกค้าสนใจข้อเสนอหรือไม่ - **"สนใจ"** / **"ไม่สนใจ"**
- ลูกค้ารับปากว่าจะชำระหนี้ - **"รับปาก"** / **"ปฏิเสธ"** / **"ขอเลื่อนวันชำระ"**
- แจ้งข้อมูลลูกค้าอย่างเดียว - **"ลูกค้ารับทราบ"**
:::
