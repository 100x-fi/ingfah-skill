# Phone Tools

> เปิดเครื่องมือบนสายโทรศัพท์ และสร้างงาน Goal Troubleshoot หรือ Form ให้ AI Agent ใช้ระหว่างคุย
>
> Source: https://docs.ingfah.ai/guides/ai-agent/phone-tools/

พอรับสายจริง AI Agent ก็ต้องทำได้ทั้งงานบนสาย เช่น โอนสาย รับเลขจากแป้นโทรศัพท์ วางสาย และงานที่ช่วยคุยจนได้คำตอบ เช่น ถามวันนัดชำระ พาแก้ปัญหาตามคลังความรู้ หรือเก็บข้อมูลติดต่อ

งานพวกนี้ก็ใช้ **Phone Tools** ในแผง **Tools** หมวด **เกี่ยวกับการโทรฯ**

รายการนี้รวมทั้งเครื่องมือของแพลตฟอร์มและเครื่องมือของบริษัทคุณ ค้นจากช่องค้นหาบนแผงก็ได้

Tool แบบเรียกระบบภายนอกด้วย http หรือเขียนโค้ดเอง (wasm) อยู่หมวดอื่น ดูที่ [สร้างและจัดการ Tools](/guides/ai-agent/manage-tools/)

## เหมาะกับงานแบบไหน

ตอนสายกำลังคุยอยู่ ใช้กับ AI Agent แบบโทรศัพท์

| ชนิด | ใช้เมื่อ |
|------|---------|
| **โอนสาย / รับเลข / วางสาย** | ต้องจัดการสายเอง เช่น โอนให้เจ้าหน้าที่ รับเลขบัตรผ่านแป้นโทรศัพท์ หรือพอคุยจบก็วางสาย |
| **Goal** | อยากให้ Agent คุยจนได้ค่าหนึ่งค่าแล้วกลับมาคุยเรื่องหลักต่อ เช่น ถามวันที่จะจ่าย |
| **Troubleshoot** | อยากให้ Agent พาลูกค้าทำตามขั้นตอนในคลังความรู้ ทีละขั้น |
| **Form** | อยากเก็บข้อมูลหลายช่องเป็นชุด เช่น ชื่อกับเบอร์ติดต่อ ทางเสียงหรือแป้นโทรศัพท์ |

ถ้ายังมีคนที่ต้องรับต่อ ก็เลือกโอนสาย
พอจบงานแล้ว และไม่มีคนรับช่วง ก็ใช้วางสาย

AI Agent แบบข้อความไม่มีสาย ก็เลยไม่ใช้ชุด Phone Tools นี้ พอเปิดแผง **Tools** ของ Agent แบบแชท ก็จะไม่เห็นหมวด **เกี่ยวกับการโทรฯ**

วิธีสร้าง Agent แบบข้อความดูที่ [สร้าง AI Agent สำหรับแชทข้อความ](/guides/ai-agent/create-text-agent/)

รายละเอียดเครื่องมือโอนสาย รับเลข และวางสาย ดูที่ [การใช้ Tools ใน AI Agent](/guides/ai-agent/ai-agent-tools/)

## สร้าง Goal Troubleshoot หรือ Form

บริษัทคุณสร้างงานสามชนิดนี้ได้เอง รวมกันได้ไม่เกิน **50** งาน

ชื่อต้องไม่ซ้ำกับ Phone Tool หรือ Tool อื่นของบริษัท และใช้ได้เฉพาะตัวอักษร ตัวเลข หรือ `_` ยาว 1–64 ตัว

สร้าง แก้ และลบผ่าน **API Key** ได้ ใช้สิทธิ์ `ai_agents:write` หรือสั่งผ่าน [Skill ingfah](/guides/ingfah-skill/overview/)

เอกสารเส้นทางและฟิลด์อยู่ที่ [developers.ingfah.ai](https://developers.ingfah.ai) หัวข้อ Phone tools

| ชนิด | `implementation_name` | สิ่งที่ต้องใส่หลัก ๆ |
|------|------------------------|---------------------|
| Goal | `agent_task` | `goal` คือเป้าหมายที่ต้องได้จากปลายสาย และ `output_fields` คือชื่อค่าที่อยากได้กลับมา |
| Troubleshoot | `troubleshoot_task` | ใส่คำสั่งเสริมได้ และต้องมี Tool `rag_knowledge_search` บน Agent เดียวกัน |
| Form | `form_task` | `fields` 1–30 ช่อง แต่ละช่องมีชื่อ ประเภท และคำถาม |

พอสร้างแล้ว งานก็จะโผล่ในแผง **เกี่ยวกับการโทรฯ** ของ Agent แบบโทรศัพท์ เปิดสวิตช์แล้วค่อยผูกกับ Flow ตามขั้นตอนด้านล่าง

:::note[โอนสายยังตั้งเองไม่ได้ทั้งหมด]
Goal Troubleshoot และ Form สร้างเองได้ ส่วนเบอร์โอนสาย ระยะเวลาดัง และข้อความตอนรอสาย ยังให้ทีมอิงฟ้าตั้งค่าอยู่ ชุด warm transfer ที่มีอยู่แล้วก็แก้ได้บางส่วนผ่าน API
:::

### ตัวอย่าง Goal ถามวันชำระ

เหมาะกับสายทวงหนี้หรือยืนยันนัดชำระ ที่อยากได้วันที่ชัดก่อนคุยเรื่องยอดต่อ

สั่งผ่าน Skill หรือส่ง API ประมาณนี้

```json
{
  "name": "confirm_pay_date",
  "description": "ใช้เมื่อต้องถามวันที่ลูกค้าจะจ่าย",
  "implementation_name": "agent_task",
  "params": {
    "goal": "ถามว่าลูกค้าจะจ่ายยอดค้างวันไหน",
    "output_fields": {
      "pay_date": "วันที่ลูกค้าบอกว่าจะจ่าย"
    }
  }
}
```

พอ Agent เรียกงานนี้ ระบบก็จะคุยกับลูกค้าจนกว่าจะได้ `pay_date` แล้วส่งค่ากลับให้ Agent ไปใช้ในขั้นตอนถัดไป

### ตัวอย่าง Troubleshoot พาเข้าแอปไม่ได้

เหมาะกับสายซัพพอร์ตที่ลูกค้าบอกว่าเข้าแอปหรือล็อกอินไม่ได้ และคุณมีขั้นตอนแก้ในคลังความรู้แล้ว

```json
{
  "name": "fix_app_login",
  "description": "ใช้เมื่อลูกค้าบอกว่าเข้าแอปไม่ได้",
  "implementation_name": "troubleshoot_task",
  "params": {
    "extra_instruction": "พูดช้าๆ รอให้ลูกค้าทำเสร็จทีละขั้น",
    "on_result": {
      "not_resolved": "เสนอโอนสายให้เจ้าหน้าที่"
    }
  }
}
```

ก่อนเปิดบน Agent ให้เปิด Tool ค้นคลังความรู้ (`rag_knowledge_search`) ด้วย ถ้าไม่มี ระบบก็จะไม่ให้เผยแพร่ Agent ที่ผูกงานนี้

### ตัวอย่าง Form เก็บชื่อกับเบอร์ติดต่อ

เหมาะกับสายที่ต้องอัปเดตข้อมูลติดต่อ หรือเก็บเบอร์สำรองก่อนปิดเคส

```json
{
  "name": "collect_contact",
  "description": "ใช้เมื่อต้องเก็บชื่อและเบอร์ติดต่อใหม่",
  "implementation_name": "form_task",
  "params": {
    "intro": "ขอเก็บข้อมูลติดต่อใหม่นะคะ",
    "fields": [
      {
        "name": "contact_name",
        "type": "text",
        "required": true,
        "ask": "ขอชื่อผู้ติดต่อค่ะ"
      },
      {
        "name": "contact_phone",
        "type": "phone_th",
        "required": true,
        "ask": "ขอเบอร์โทรที่ติดต่อได้ค่ะ",
        "say_as": "thai_number_as_digit"
      }
    ],
    "confirm": {
      "fields": ["contact_phone"]
    },
    "on_result": {
      "success": "ขอบคุณลูกค้า แล้วคุยเรื่องยอดค้างต่อ"
    }
  }
}
```

ประเภทช่องที่ใช้บ่อย เช่น `text` `int` `enum` `phone_th` `digits` `email`

ช่องที่พูดออกเสียงทวนกลับได้ก็ใส่ใน `confirm` ส่วนช่องเลขอาจเก็บผ่านแป้นโทรศัพท์ได้ตามชนิดที่ตั้งไว้

:::tip[ตัวอย่างการสั่ง Skill]
ช่วยสร้าง Phone Tool แบบ Goal ชื่อ confirm_pay_date ให้ทีมทวงหนี้ เป้าหมายคือถามวันที่จะจ่าย แล้วส่งค่า pay_date กลับมา หลังสร้างแล้วช่วยเปิดบน Agent "มะลิ" ด้วย
:::

## เปิดบน AI Agent แบบโทรศัพท์

ทำบนแบบร่างของ AI Agent แบบโทรศัพท์

1. เปิด AI Agent ที่ต้องการ แล้วกด **แก้ไขแบบร่าง**
2. กดไอคอน **Tools** ทางขวาของหน้า AI Agent
3. เลื่อนไปหมวด **เกี่ยวกับการโทรฯ** ถ้ามีรายการยาว ก็พิมพ์ชื่อในช่องค้นหา
4. เปิดสวิตช์ด้านขวาของเครื่องมือที่ต้องการใช้

พอเปิดแล้ว Agent ก็จะเรียกเครื่องมือนั้นได้ระหว่างสาย ตามคำสั่งใน Flow

ถ้าแผงว่าง หรือค้นแล้วไม่เจอ ก็ให้ติดต่อ **support@ingfah.ai** หรือตรวจว่าสร้างงานด้วย API Key ของบริษัทนี้แล้วหรือยัง

## ใส่บน Node ใน Flow

นอกจากเปิดบน Agent ทั้งตัว ก็ยังผูก Phone Tools เข้ากับ Node ของบทสนทนาได้ทีละขั้นด้วย

บน Node ให้เปิด **Tools ที่เกี่ยวข้อง** เลือกหมวด **การโทร** แล้วใส่ **คำอธิบายการทำงาน** เพื่อบอก Agent ว่าในขั้นนี้ควรใช้เครื่องมือเมื่อไหร่

ตัวอย่างเช่น

- Node ปิดงาน ให้ผูกเครื่องมือวางสาย แล้วเขียนว่า ถ้าลูกค้าไม่มีเรื่องอื่น ก็ให้กล่าวลาแล้ววางสาย
- Node ยืนยันตัวตน ให้ผูกเครื่องมือรับเลขบัตรผ่านแป้นโทรศัพท์
- Node นัดชำระ ให้ผูก Goal `confirm_pay_date` แล้วเขียนว่า ถ้าลูกค้ายังไม่บอกวันจ่าย ก็ให้เรียกเครื่องมือนี้ก่อนคุยเรื่องยอดต่อ

วิธีสร้าง Node ดูที่ [การสร้าง Flow บทสนทนา](/guides/ai-agent/how-to-create-agent-flow/)

## ปิดการใช้งาน

ก่อนปิดสวิตช์ ระบบก็จะถามยืนยันด้วยข้อความ **ยืนยันการปิดใช้งาน Tool**

ถ้าปิด ระบบก็จะลบข้อมูล **Tools ที่เกี่ยวข้อง** ของเครื่องมือนั้นบนทุก Node ทิ้งถาวร กู้คืนไม่ได้

ถ้ายังต้องการคำอธิบายบน Node ก็กด **ยกเลิก**

:::caution[Agent แบบข้อความไม่มี Phone Tools]
ชุดนี้ผูกกับสายโทรศัพท์ AI Agent แบบแชทก็เปิด Tool หมวดอื่นได้ แต่เรียกโอนสาย วางสาย รับเลขจากแป้นโทรศัพท์ หรืองาน Goal Troubleshoot Form บนสายไม่ได้
:::
