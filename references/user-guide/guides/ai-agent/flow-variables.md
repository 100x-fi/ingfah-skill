# การใช้งาน{{ตัวแปร}}

> การใช้งานตัวแปรใน Flow บทสนทนา
>
> Source: https://docs.ingfah.ai/guides/ai-agent/flow-variables/

## ตัวแปรใน Flow คืออะไร?

ตัวแปร (Variable) ใน Flow คือข้อมูลที่สามารถเปลี่ยนแปลงได้ตามบริบทของการสนทนา เขียนในรูปแบบ `{{ชื่อตัวแปร}}` เพื่อให้ AI Agent นำค่าจริงมาแทนที่โดยอัตโนมัติ

ตัวแปรมี 2 ประเภท ได้แก่

---

## 1. ตัวแปรจาก AI Agent

ตัวแปรประเภทนี้ตั้งค่าในระดับ AI Agent สามารถเข้าถึงได้โดยกดที่ไอคอน **{}** ทางด้านขวาสุดของหน้าแก้ไข AI Agent

เหมาะสำหรับข้อมูลที่อาจมีการแก้ไขเป็นครั้งคราว หรือข้อมูลที่ใช้ซ้ำบ่อยใน AI Agent เช่น

- ชื่อแบรนด์หรือบริษัท
- คำลงท้าย เช่น ครับ / ค่ะ
- โค้ดส่วนลด

---

## 2. ตัวแปรจากข้อมูลลูกค้า (Customer Context)

ในระบบ ingfah ข้อมูลลูกค้าเรียกว่า **Customer Context** เข้าถึงได้ด้วยรูปแบบ `{{customerContext.XXXX}}` โดยแทนที่ `XXXX` ด้วยชื่อตัวแปรที่ต้องการ

:::note[ตัวแปรพื้นฐานที่ทุก AI Agent รู้จัก]
- `{{customerContext.customer_name}}` - ชื่อลูกค้า
- `{{customerContext.phone_number}}` - เบอร์โทรศัพท์ของลูกค้า

ข้อมูลเหล่านี้จะถูกโหลดเข้าระบบพร้อมกับการอัพโหลดไฟล์ CSV เพื่อโทรออกหาลูกค้า
:::

นอกจากนี้ คุณยังสามารถเพิ่มตัวแปรเองได้ตามต้องการ เช่น

:::tip[ตัวอย่างตัวแปรเพิ่มเติม]
- `{{customerContext.address}}` - ที่อยู่จัดส่งสินค้า
- `{{customerContext.due_date}}` - วันครบกำหนดชำระหนี้
:::

คุณสามารถตั้งชื่อตัวแปรได้อย่างอิสระตามข้อมูลที่ต้องการใช้
