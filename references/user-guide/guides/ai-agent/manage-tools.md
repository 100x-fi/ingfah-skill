# สร้างและจัดการ Tools

> สร้าง Tool เพื่อให้ AI Agent เรียกใช้ระบบภายนอกระหว่างสนทนา พร้อมทดสอบการทำงาน
>
> Source: https://docs.ingfah.ai/guides/ai-agent/manage-tools/

หน้า **Tools** ใช้สร้างและจัดการ Tool ที่ AI Agent เรียกใช้ระหว่างสนทนา เช่น ดึงยอดค้างชำระจากระบบหลังบ้าน หรือบันทึกนัดหมายกลับเข้าระบบของคุณ

หน้านี้เป็นการ **สร้าง Tool** ส่วนวิธีนำ Tool ไปผูกกับ AI Agent ดูที่ [การใช้ Tools ใน AI Agent](/guides/ai-agent/ai-agent-tools/)

## รายการ Tools

| คอลัมน์ | ความหมาย |
|---------|----------|
| Signature | ชื่อทางเทคนิคที่ AI Agent ใช้เรียก Tool |
| ประเภท Integration | ระบบปลายทางที่ Tool นี้เชื่อมต่อ |
| Method | รูปแบบการเรียกใช้งาน |
| คำอธิบายสำหรับ AI Agent | คำอธิบายที่ AI ใช้ตัดสินใจว่าจะเรียก Tool นี้เมื่อใด |
| แก้ไขล่าสุด | วันที่แก้ไขล่าสุด |

กรองได้ตามประเภท Tool (**ของระบบ** หรือ **สร้างเอง**) ตาม Integration และตาม Method รวมถึงค้นหาจาก signature พารามิเตอร์ หรือคำอธิบายได้

## สร้าง Tool ใหม่

กด **สร้าง Tool** แล้วกรอกข้อมูล

### ข้อมูลหลัก

| ช่อง | รายละเอียด |
|------|-----------|
| **Signature** | ชื่อฟังก์ชันที่ AI เรียกใช้ ใช้ได้เฉพาะ a-z, A-Z, 0-9 และ `_` และห้ามซ้ำกับ Tool อื่น |
| **ชื่อ** | ชื่อที่ใช้แสดงในระบบ |
| **คำอธิบายสำหรับ AI Agent** | อธิบายว่า Tool นี้ทำอะไรและควรใช้เมื่อไหร่ |

:::tip[ตั้งชื่อ Signature ให้ตรงหน้าที่]
การตั้งชื่อ signature ให้ตรงตามจุดประสงค์ของฟังก์ชัน เช่น `get_outstanding_balance` จะช่วยให้ AI Agent เรียก Tool ได้แม่นยำขึ้น
:::

### Function Parameters

คือค่าที่ **AI Agent จะเป็นผู้ใส่ให้เอง** ขณะสนทนากับลูกค้า เช่น เลขที่สัญญาที่ลูกค้าเพิ่งแจ้งมา

แต่ละพารามิเตอร์ประกอบด้วย

- **ชื่อพารามิเตอร์** — ต้องขึ้นต้นด้วยตัวอักษร ใช้ a-z, A-Z, 0-9 และ `_` และห้ามซ้ำ
- **คำอธิบาย** — บอก AI ว่าค่านี้คืออะไร
- **ประเภท** — String, Number, Boolean, Object หรือ Array
- **จำเป็น** — ระบุว่าต้องมีค่านี้เสมอหรือไม่

### Integration Parameters

คือค่าที่ **คุณกำหนดไว้ล่วงหน้า** สำหรับเชื่อมต่อระบบปลายทาง เช่น URL ปลายทาง หรือค่า Token โดยเลือก **ประเภท Integration** และ **Method** พร้อมกรอกคู่ Key/Value

ค่าที่เป็นความลับจะถูกซ่อนไว้และแสดงเป็นจุดไข่ปลาเสมอ

## ทดสอบการใช้งาน

ที่หน้ารายละเอียด Tool กด **ทดสอบการใช้งาน** ใส่ค่าพารามิเตอร์ที่ต้องการทดสอบ แล้วกด **ทดสอบ** ระบบจะแสดงผลลัพธ์การเรียกใช้งานกลับมา

:::danger[การทดสอบเป็นการเรียกใช้งานจริง]
ระบบจะเรียกไปยังปลายทางจริง ไม่ใช่การจำลอง (Dry Run) หาก Tool นั้นสร้างหรือเปลี่ยนแปลงข้อมูลในระบบของคุณ การกดทดสอบจะทำให้เกิดผลจริง
:::

## แก้ไข ทำสำเนา และลบ

- **แก้ไข** — แก้ไขได้เฉพาะ Tool ที่สร้างเอง
- **ทำสำเนา** — คัดลอกเนื้อหาและพารามิเตอร์ทั้งหมด **แต่ไม่รวมการเชื่อมต่อกับ AI Agents** และต้องตั้ง signature ใหม่ที่ไม่ซ้ำ
- **ลบ** — ลบแล้วไม่สามารถกู้คืนได้ และหากมี AI Agent ใช้ Tool นี้อยู่ ระบบจะไม่ยอมให้ลบพร้อมแสดงรายชื่อ Agent ที่ใช้งานอยู่

:::caution[การแก้ไขกระทบ Agent ที่ใช้อยู่]
การแก้ไข Tool อาจส่งผลต่อการทำงานของ AI Agent ที่กำลังใช้ Tool นี้ ตรวจสอบรายชื่อที่หัวข้อ **AI Agent ที่ใช้งาน** ในหน้ารายละเอียด Tool ก่อนแก้ไขทุกครั้ง
:::
