# สร้าง AI Agent สำหรับแชทข้อความ

> เลือกประเภทข้อความ สร้างแบบร่าง และเตรียม Agent สำหรับตอบแชท
>
> Source: https://docs.ingfah.ai/guides/ai-agent/create-text-agent/

AI Agent ประเภท **ข้อความ** ใช้ตอบลูกค้าผ่านช่องทางแชท เช่น LINE OA ประเภทของ Agent เลือกตอนสร้างและใช้คัดกรองเทมเพลตที่แสดง

## เหมาะกับงานแบบไหน

เหมาะกับงานที่ลูกค้าทักเข้ามาซ้ำๆ ผ่านช่องทางข้อความ เช่น ถามเวลาเปิดร้าน วิธีจัดส่ง หรือสถานะบริการ ตัวอย่างเช่น ร้านค้าที่ใช้ LINE OA สามารถสร้าง Agent แบบข้อความให้ตอบคำถามทั่วไปก่อน แล้วให้เจ้าหน้าที่รับช่วงเมื่อคำถามต้องตรวจข้อมูลเฉพาะลูกค้า

1. เปิดเมนู **AI Agent** แล้วเลือกแท็บ **ข้อความ**
2. กด **สร้าง AI Agent**
3. เลือก **เริ่มสร้างใหม่ตั้งแต่ต้น** เพื่อเริ่มจากหน้าว่าง หรือเลือกเทมเพลตสำหรับ Agent แบบข้อความ แล้วกด **ดำเนินการต่อ**
4. ตั้งชื่อ Agent และกรอกคำสั่งให้ AI Agent ตอบลูกค้า ตรวจสอบรายละเอียดที่เทมเพลตเติมให้หากใช้เทมเพลต
5. กด **บันทึกแบบร่าง** ระบบจะเปิดหน้าแบบร่างของ Agent ที่สร้าง

แบบร่างยังไม่ใช่เวอร์ชันที่ใช้งานจริง ทดลองแชทและ[เผยแพร่ Agent](/guides/ai-agent/manage-ai-agent/) เมื่อพร้อม จากนั้นสร้างทีมแบบข้อความและ[เชื่อมช่องทาง LINE OA](/guides/contact-channels/connect-line-oa/) เข้ากับทีม

ดูวิธี[ทดลองแชทและดูประวัติการทดลอง](/guides/ai-agent/try-call/) ก่อนเชื่อมช่องทางจริง
