# AI Agent

> สร้าง AI Agent ที่ทำงานได้ด้วยตนเองและมุ่งเน้นเป้าหมาย ซึ่งใช้การคิดหาเหตุผลคล้ายมนุษย์และเครื่องมือต่างๆ เพื่อส่งมอบผลลัพธ์ที่เหนือกว่า

## AI Agent คืออะไร?

AI Agent ของ ingfah คือเจ้าหน้าที่ AI อัตโนมัติที่สามารถโทรออกและรับสายแทนทีมของคุณได้ตลอด 24 ชั่วโมง Agent แต่ละตัวมีบุคลิก เสียง และขั้นตอนการสนทนาที่คุณกำหนดเองได้ทั้งหมด

## ความสามารถหลัก

**สนทนาอัตโนมัติตาม Flow**

กำหนดขั้นตอนการสนทนาด้วย Flow ที่ประกอบด้วย Node หลายกล่องเชื่อมต่อกัน Agent จะดำเนินการตาม Flow และตัดสินใจเลือกเส้นทางที่เหมาะสมตามคำตอบของลูกค้า

**บุคลิกและเสียงที่ปรับแต่งได้**

ตั้งชื่อ กำหนดตัวตน และเลือกเสียงพูดให้ Agent แต่ละตัว รองรับการใช้ Voice Clone เพื่อให้ Agent พูดด้วยเสียงที่ต้องการ

**ตัวแปรข้อมูลลูกค้า**

ดึงข้อมูลลูกค้าแบบเรียลไทม์มาใช้ในการสนทนา เช่น ชื่อ ที่อยู่ หรือข้อมูลคำสั่งซื้อ ผ่านระบบตัวแปร `{{customerContext}}`

**Knowledge Base**

เพิ่มฐานความรู้ให้ Agent เพื่อให้ตอบคำถามเฉพาะทางได้อย่างแม่นยำ โดยไม่ต้องใส่ข้อมูลทั้งหมดในช่องเป้าหมาย

**ระบบแบบร่างและเผยแพร่**

แก้ไขและทดสอบการเปลี่ยนแปลงใน Draft ก่อนเผยแพร่ไปยัง Agent ที่ใช้งานจริง โดยไม่กระทบกับการสนทนาที่กำลังเกิดขึ้น

**โอนสายระหว่าง Agent**

ทีมที่มี Agent หลายตัวสามารถตั้งค่าให้โอนสายระหว่างกันได้อัตโนมัติ เช่น Agent คัดกรองภาษาโอนสายต่อให้ Agent ที่เชี่ยวชาญภาษานั้น
