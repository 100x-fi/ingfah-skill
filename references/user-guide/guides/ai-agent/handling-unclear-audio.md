# รับมือเสียงไม่ชัดและการพูดซ้ำ

> เทคนิคเขียน Prompt ให้ AI Agent รับมือกับเสียงที่ระบบฟังผิด ลูกค้าเงียบ และการพูดประโยคเดิมซ้ำ
>
> Source: https://docs.ingfah.ai/guides/ai-agent/handling-unclear-audio/

การสนทนาทางโทรศัพท์มีสัญญาณรบกวนเสมอ ระบบแปลงเสียงเป็นข้อความ (Speech-to-Text) อาจฟังคำของลูกค้าผิดได้ ซึ่งเป็นสาเหตุอันดับต้นๆ ที่ทำให้สายจบก่อนเวลาอันควร หน้านี้รวบรวมกฎที่ควรใส่ไว้ใน Prompt เพื่อให้ AI Agent รับมือสถานการณ์เหล่านี้ได้

---

## อย่าเชื่อคำปฏิเสธคำแรกทันที

ปัญหาที่พบบ่อยที่สุด: ลูกค้าพูดว่า "คุยได้ค่ะ" แต่ระบบได้ยินเป็น "ไม่ได้ค่ะ" แล้ว AI Agent ก็วางสายไปทั้งที่ลูกค้าพร้อมคุย

วิธีแก้คือ ถ้าคำตอบแรกหลัง Greeting เป็นคำปฏิเสธ ห้ามวางสายทันที ให้ถามยืนยันหนึ่งครั้งก่อนเสมอ

```
**การรับมือคำตอบปฏิเสธหลัง Greeting (กันการฟังผิดจากสัญญาณเสียง):**
ถ้าคำตอบแรกของลูกค้าเป็นคำปฏิเสธ (เช่น 'ไม่' 'ไม่ได้ค่ะ' 'ไม่ครับ')
ที่จะทำให้ตีความว่าลูกค้าไม่สะดวกคุย **ห้ามเชื่อทันที ห้ามข้ามไปถามช่วงเวลาติดต่อกลับ
และห้ามวางสายเด็ดขาด** เพราะระบบรับเสียงอาจฟังผิด
ให้ทำเหมือนสัญญาณไม่ชัดและถามยืนยันสิ่งที่ได้ยินหนึ่งครั้งก่อนเสมอ

- ❌ ผิด: ลูกค้า: 'ไม่ได้ค่ะ' → 'เข้าใจเลยค่ะ ไม่ทราบว่าสะดวกให้ติดต่อกลับช่วงไหนดีคะ'
- ✅ ถูก: ลูกค้า: 'ไม่ได้ค่ะ' → 'ขออภัยนะคะ สัญญาณอาจไม่ค่อยชัด คุณลูกค้าไม่สะดวกคุยตอนนี้ใช่ไหมคะ'

**ขอบเขตของกฎนี้:** ใช้เฉพาะเมื่อคำตอบเป็นคำปฏิเสธจริงๆ เท่านั้น
ถ้าลูกค้าตอบกำกวมแบบไม่ใช่คำปฏิเสธ เช่น 'เหรอ' 'หา' 'อะไรนะ' 'ครับ?'
ไม่ต้องถามยืนยัน ให้ถือเป็นการตอบรับและดำเนินการต่อตามปกติ
```

## บันไดนับครั้ง เมื่อลูกค้าเงียบหรือเสียงไม่ชัด

อย่าปล่อยให้ AI Agent ถามวนไปเรื่อยๆ ให้กำหนดเป็นลำดับขั้นที่ชัดเจนว่าครั้งที่เท่าไหร่ต้องทำอะไร และ **เปลี่ยนคำพูดทุกครั้ง**

```
# การรับมือสถานการณ์พิเศษ

- **ลูกค้าเงียบไม่ตอบ:**
  ครั้งที่ 1 ถาม "สวัสดีค่ะ ลูกค้ายังอยู่ในสายหรือเปล่าคะ"
  ครั้งที่ 2 ถาม "สวัสดีค่ะ ลูกค้าได้ยินเสียงชัดเจนหรือไม่คะ"
  ครั้งที่ 3 กล่าว "ขออภัยในความไม่สะดวก ขออนุญาตวางสายและติดต่อกลับใหม่ในภายหลังค่ะ" แล้วจบสาย

- **เสียงไม่ชัดเจน:**
  ครั้งที่ 1 พูดว่า "ขอโทษค่ะ ทางเราได้ยินเสียงไม่ชัดเจนเลยค่ะ กรุณาพูดซ้ำอีกครั้งนะคะ"
  ครั้งที่ 2 พูดว่า "ขอโทษค่ะ สัญญาณอาจจะขัดข้อง ขออนุญาตวางสายและติดต่อกลับใหม่นะคะ" แล้วจบสาย

- **ลูกค้าพูดแทรก:** ตอบสั้นๆ ว่า "ค่ะ พูดได้เลยค่ะ" แล้วฟังต่อ
- **ลูกค้าขอเวลาคิด/รอ:** ตอบว่า "ได้เลยค่ะ"
```

:::tip[รีเซ็ตตัวนับเมื่อได้ยินชัด]
ระบุใน Prompt ด้วยว่า เมื่อลูกค้าตอบกลับมาชัดเจนแล้ว ให้เริ่มนับใหม่จากครั้งที่ 1 ไม่เช่นนั้น AI Agent จะวางสายเร็วเกินไปในสายที่มีสัญญาณขาดๆ หายๆ เป็นช่วง
:::

## ลูกค้าพูดแต่ "ฮัลโหล" วนไปมา

ถ้าลูกค้าพูดแต่คำทักทายซ้ำๆ โดยไม่ตอบคำถามเลย แปลว่าลูกค้าอาจไม่ได้ยินเสียงเรา **ห้ามตีความว่าลูกค้าปฏิเสธ**

```
**กรณีลูกค้าทักทายซ้ำวนลูป (สัญญาณเสียงมีปัญหา):**
ถ้าลูกค้าพูดแต่คำทักทาย (เช่น 'สวัสดีค่ะ' 'ฮัลโหล') ซ้ำหลายครั้งติดกันโดยไม่ตอบคำถามของเราเลย
**ห้ามตีความว่าเป็นการปฏิเสธหรือไม่สะดวกคุยเด็ดขาด — ลูกค้าไม่ได้พูดปฏิเสธ
ห้ามถามว่า 'ไม่สะดวกคุยใช่ไหม'** ให้ทำตามลำดับนี้

- ทักทายซ้ำครั้งที่ 2: แจ้งจุดประสงค์ของสายอีกครั้งด้วยถ้อยคำใหม่ (ห้ามซ้ำคำต่อคำ)
- ทักทายซ้ำครั้งที่ 3: ถามว่าได้ยินเสียงเราไหม เช่น 'ขออภัยค่ะ สัญญาณอาจไม่ค่อยชัด คุณลูกค้าได้ยินไหมคะ'
- ทักทายซ้ำครั้งที่ 4 ขึ้นไป: ยุติสายอย่างสุภาพ ต้องแจ้งก่อนว่าสัญญาณขัดข้องและจะให้เจ้าหน้าที่ติดต่อกลับ
  - ❌ ผิด: 'ขออนุญาตวางสายค่ะ' (วางสายโดยไม่บอกว่าจะเกิดอะไรขึ้นต่อ)
  - ✅ ถูก: 'เนื่องจากสัญญาณขัดข้อง เดี๋ยวให้เจ้าหน้าที่ติดต่อกลับไปใหม่นะคะ ขออนุญาตวางสายค่ะ'
```

## ตารางเสียงใกล้เคียง สำหรับคำถามที่คำตอบมีรูปแบบตายตัว

ถ้ามีขั้นตอนที่ลูกค้าต้องตอบเป็นตัวเลขหรือตัวเลือกจำกัด เช่น การให้คะแนนความพึงพอใจ ให้ทำตารางแปลงเสียงที่ระบบมักฟังผิดไว้ล่วงหน้า

```
ตารางการตีความคำใกล้เคียง:
- ค่ะ / ครับ / ค่า / อ่า / เออ → ตีความเป็น 5
- ไซ / ไส / สี่ / ไส่ → ตีความเป็น 4
- สาม / ซาม / ซ้าม → ตีความเป็น 3
- สอง / ซอง → ตีความเป็น 2
- หนึ่ง / นึ่ง / นิ่ง → ตีความเป็น 1
- คำชมเชิงบวกโดยไม่บอกเลข เช่น ดีมาก / เยี่ยม → ตีความเป็น 5

(ขั้นตอนนี้เท่านั้นที่รับคะแนนตัวเลข ห้ามนำตารางนี้ไปใช้ในขั้นตอนอื่น)
```

:::caution[ต้องกำกับขอบเขตเสมอ]
วงเล็บบรรทัดสุดท้ายสำคัญมาก ถ้าไม่กำกับว่าใช้เฉพาะขั้นตอนไหน AI Agent จะเอาตารางนี้ไปตีความคำตอบในขั้นตอนอื่นด้วย เช่น ตีความคำว่า "ค่ะ" ธรรมดาเป็นเลข 5
:::

## ห้ามพูดประโยคเดิมซ้ำคำต่อคำ

เมื่อ AI Agent ไม่แน่ใจว่าลูกค้าได้ยินหรือไม่ มันมักจะพูดประโยคเดิมซ้ำทั้งประโยค ซึ่งฟังดูเหมือนหุ่นยนต์ทันที

```
**กฎห้ามพูดประโยคซ้ำ (HARD RULE):**
ห้ามพูดประโยคเดิมซ้ำคำต่อคำกับประโยคที่ตัวเองเพิ่งพูดใน turn ก่อนหน้าเด็ดขาด
ถ้าสิ่งที่กำลังจะพูดเหมือนประโยคเดิมทุกคำ ให้เรียบเรียงใหม่ให้ความหมายเดิมด้วยถ้อยคำที่ต่างออกไป
หรือถ้าสาเหตุคือไม่แน่ใจว่าได้ยินลูกค้าถูกต้องไหม ให้ทำเหมือนสัญญาณไม่ชัดและขอให้ลูกค้าพูดอีกครั้ง

- ❌ ผิด: พูดว่า 'ขออภัยค่ะ สัญญาณไม่ค่อยชัด คุณลูกค้าไม่สะดวกคุยใช่ไหมคะ'
  แล้ว turn ถัดไปพูดประโยคเดียวกันซ้ำทุกคำอีกครั้ง
- ✅ ถูก: เรียบเรียงใหม่ เช่น 'รบกวนยืนยันอีกครั้งนะคะ ตอนนี้คุณลูกค้าไม่สะดวกคุยใช่ไหมคะ'
- กฎนี้ห้ามเฉพาะการทวนถ้อยคำเดิมคำต่อคำเท่านั้น ไม่ได้ห้ามพูดถึงข้อมูลเดิมด้วยถ้อยคำใหม่
```

### ใส่ตัวอย่างหมุนเวียนในขั้นตอนที่ถูกถามซ้ำบ่อย

สำหรับคำถามที่เกิดซ้ำหลายครั้งในสายเดียว เช่น "มีคำถามเพิ่มเติมไหมคะ" ให้ใส่ตัวอย่างประโยคไว้อย่างน้อย 3 แบบในช่อง **ตัวอย่าง** ของ Conversation State นั้น แล้วสั่งให้สลับใช้

```
ตัวอย่าง:
- ไม่ทราบว่าคุณลูกค้ามีคำถามเพิ่มเติมในส่วนไหนอีกไหมคะ
- คุณลูกค้ามีอะไรอยากให้ช่วยสอบถามเพิ่มอีกไหมคะ
- มีจุดไหนที่คุณลูกค้าอยากให้อธิบายเพิ่มเติมอีกไหมคะ

คำสั่ง: สอบถามลูกค้าว่ามีคำถามเพิ่มเติมหรือไม่ โดยสลับใช้ประโยคที่หลากหลาย
(ดูตัวอย่างด้านบน หรือแต่งประโยคใหม่ที่ความหมายเดียวกัน)
ห้ามพูดประโยคเดิมซ้ำคำต่อคำหากต้องถามคำถามนี้ซ้ำมากกว่าหนึ่งครั้งในสายเดียวกัน
```

## ตั้ง Greeting Message แล้วอย่าให้ทักทายซ้ำ

หากคุณตั้งข้อความเปิดสายไว้ ระบบจะส่งข้อความนั้นให้ลูกค้าไปแล้วก่อนที่ AI Agent จะเริ่มทำงาน ต้องบอก AI Agent ให้ชัดใน State แรก ไม่อย่างนั้นมันจะทักทายและแนะนำตัวซ้ำอีกรอบ

```
รอฟังคำตอบของลูกค้าหลังจากระบบส่งข้อความเปิดสายไปแล้ว

**ข้อความเปิดสายถูกส่งให้ลูกค้าไปแล้วโดยระบบ — ห้ามทักทาย แนะนำตัว หรือพูดข้อความเปิดสายซ้ำอีกเด็ดขาด
และห้ามถามว่า 'สะดวกคุยไหม' ซ้ำ** ลูกค้าได้ยินการแนะนำตัวและชื่อแล้ว

เมื่อลูกค้าตอบรับใดๆ ก็ตาม (เช่น 'ครับ' 'ค่ะ' 'ว่าไง' 'อือ')
ให้ดำเนินการต่อไปยังขั้นตอนถัดไปทันที ยกเว้นกรณีลูกค้าแจ้งว่าโทรผิดเท่านั้น
```

หลักการเดียวกันใช้กับการถามข้อมูลที่ลูกค้าบอกไปแล้ว — ถ้าลูกค้าเล่าข้อมูลมาเองก่อนที่จะถูกถาม ให้ข้ามคำถามนั้นไป และเมื่อยืนยันตัวตนสำเร็จแล้ว ห้ามยืนยันซ้ำอีก
