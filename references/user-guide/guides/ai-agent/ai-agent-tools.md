# การใช้ Tools ใน AI Agent

> การใช้งาน Tools เพื่อเพิ่มความสามารถให้ AI Agent ระหว่างการสนทนา
>
> Source: https://docs.ingfah.ai/guides/ai-agent/ai-agent-tools/

## วิธีเปิดใช้งาน Tools

1. เปิด AI Agent ที่ต้องการใช้งาน และกดปุ่ม **แก้ไขแบบร่าง**

2. คลิกไอคอน **Tools** ทางด้านขวาของหน้า AI Agent

3. ระบบจะแสดงรายการ Tools ที่สามารถใช้งานได้ โดยแบ่งเป็น **Tools ทั่วไป** และ **Tools เกี่ยวกับการโทร**

4. เลือก Tool ที่ต้องการ แล้วเปิดสวิตช์ด้านขวาเพื่อเปิดใช้งาน

:::note
หลังเปิดใช้งานแล้ว AI Agent จะสามารถเรียกใช้ Tool ระหว่างการสนทนาตามคำสั่งและเงื่อนไขที่กำหนดไว้ใน Flow
:::

## Tools ทั่วไป

Tools ในกลุ่มนี้ช่วยให้ AI Agent จัดการและประมวลผลข้อมูลระหว่างการสนทนา เช่น ตรวจสอบข้อมูล คำนวณข้อมูล หรือแปลงวันที่ เพื่อนำผลลัพธ์ไปใช้ในขั้นตอนถัดไปของ Flow

### `validate_id_card`

ใช้สำหรับตรวจสอบความถูกต้องของเลขบัตรประชาชนไทยตามรูปแบบและเลขตรวจสอบ ก่อนนำข้อมูลไปใช้ในขั้นตอนถัดไป

**ตัวอย่างการทำงาน**

1. ลูกค้าแจ้งเลขบัตรประชาชน
2. AI Agent เรียก `validate_id_card`
3. Tool ตรวจสอบความถูกต้องของเลขบัตรประชาชน
4. หากถูกต้อง AI Agent สามารถดำเนินการขั้นตอนถัดไป
5. หากไม่ถูกต้อง AI Agent สามารถขอให้ลูกค้าแจ้งข้อมูลใหม่

---

### `calculate_product_cart`

ใช้สำหรับคำนวณยอดรวมของรายการสินค้า โดยนำข้อมูลสินค้า ราคา และจำนวนมาคำนวณ

**เหมาะสำหรับงาน เช่น**

- สั่งซื้อสินค้าหลายรายการ
- เลือกแพ็กเกจหรือบริการเสริม
- สรุปยอดรวมก่อนยืนยันรายการ

**ตัวอย่าง**

> ลูกค้าต้องการสินค้า A จำนวน 2 ชิ้น และสินค้า B จำนวน 3 ชิ้น

AI Agent จะรับข้อมูลสินค้า ราคา และจำนวน แล้วเรียก `calculate_product_cart` เพื่อคำนวณยอดรวม ก่อนนำผลลัพธ์ไปแจ้งลูกค้าหรือใช้ในขั้นตอนถัดไปของ Flow

---

### `calculate_remaining`

ใช้สำหรับคำนวณค่าคงเหลือจากข้อมูล 2 ค่า โดยนำค่า A ลบด้วยค่า B

**เหมาะสำหรับงาน เช่น**

- คำนวณยอดคงเหลือหลังหักยอดที่ชำระแล้ว
- คำนวณจำนวนที่เหลือจากจำนวนทั้งหมด
- คำนวณสิทธิ์หรือโควตาคงเหลือ

**ตัวอย่าง**

กำหนดให้

- ยอดทั้งหมด = 1,500 บาท
- ยอดที่ชำระแล้ว = 500 บาท

AI Agent เรียก `calculate_remaining` เพื่อคำนวณ `1,500 - 500` และได้ผลลัพธ์เป็น `1,000` ก่อนนำค่าที่ได้ไปใช้ในขั้นตอนถัดไปของ Flow

---

### `resolve_date`

ใช้สำหรับแปลงคำหรือข้อความเกี่ยวกับวันที่ในภาษาพูดให้เป็นวันที่ในปฏิทิน เพื่อให้ AI Agent สามารถนำวันที่ไปใช้ในขั้นตอนถัดไปของ Flow ได้

**ตัวอย่างคำที่สามารถใช้ได้ เช่น**

- วันนี้ / พรุ่งนี้ / มะรืน
- วันพุธนี้ / วันพุธหน้า
- สัปดาห์หน้า / อีกสองวัน

**ตัวอย่าง**

> ต้องการจองโต๊ะพรุ่งนี้ตอนสองทุ่มค่ะ

AI Agent จะดำเนินการดังนี้

1. รับคำว่า `พรุ่งนี้`
2. เรียก `resolve_date`
3. แปลงเป็นวันที่ในปฏิทิน เช่น `2026-09-04`
4. นำผลลัพธ์ไปใช้ในขั้นตอนถัดไปของ Flow

## Tools เกี่ยวกับการโทร

Tools ในกลุ่มนี้ช่วยให้ AI Agent จัดการการทำงานที่เกี่ยวข้องกับสายโทรศัพท์ เช่น รับข้อมูลผ่านปุ่มตัวเลขบนโทรศัพท์ หรือจบสายตามเงื่อนไขที่กำหนด

### `end_call_keyword`

ใช้สำหรับให้ AI Agent จบสายเมื่อการสนทนาเสร็จสิ้น โดยทำงานได้ 2 วิธี

- **AI Agent เรียก Tool เอง** เมื่อลูกค้าแสดงชัดเจนว่าไม่มีอะไรเพิ่มเติมแล้ว AI Agent จะกล่าวลาและวางสาย
- **AI Agent พูด Keyword จบสาย** เมื่อ **AI Agent เอง** (ไม่ใช่ลูกค้า) พูดประโยคที่มี Keyword ที่กำหนด ระบบจะวางสายทันทีโดยไม่กล่าวลาซ้ำ

เมื่อเปิดใช้งานการจบสายในขั้นตอนของ Flow ระบบจะเพิ่มคำสั่งให้ AI Agent พูดว่า “ขออนุญาตวางสาย” ก่อนวางสายเสมอ

**ตัวอย่าง**

> ลูกค้า: “ไม่มีอะไรแล้วค่ะ ขอบคุณค่ะ”
>
> AI Agent: “ขอบคุณที่ใช้บริการค่ะ ขออนุญาตวางสายนะคะ”

หากประโยคของ AI Agent มี Keyword ที่ตั้งไว้ในการตั้งค่า Tool `end_call_keyword` จะจบสายอัตโนมัติ

:::note
Tool นี้ใช้ได้กับ AI Agent แบบโทรศัพท์ (Voice) เท่านั้น AI Agent แบบแชทไม่มีสายให้จบ
:::

### `collect_id_card`

ใช้รับเลขบัตรประชาชน 13 หลักจากลูกค้า โดยให้ลูกค้ากรอกผ่านปุ่มตัวเลขบนโทรศัพท์แทนการพูดออกเสียง

**ตัวอย่างการทำงาน**

1. AI Agent แจ้งให้ลูกค้ากรอกเลขบัตรประชาชนผ่านปุ่มตัวเลขบนโทรศัพท์
2. ลูกค้ากรอกเลขบัตรประชาชน 13 หลัก
3. `collect_id_card` รับข้อมูลที่ลูกค้ากรอก
