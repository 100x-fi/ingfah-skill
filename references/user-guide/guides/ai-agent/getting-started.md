# สร้าง AI Agent ตัวแรก

> สร้าง AI Agent ตัวแรก
>
> Source: https://docs.ingfah.ai/guides/ai-agent/getting-started/

1. ล็อกอินเข้าสู่ระบบ ได้ที่ https://ingfah.ai/login ด้วย อีเมล และ รหัสผ่านของคุณ

2. หลังจาก Login เข้าสู่ระบบ คุณจะเห็นเมนูหลักด้านซ้ายมือ

   2.1 คลิกที่เมนู "AI Agent" ในแถบด้านซ้าย

   2.2 คลิกที่ปุ่ม "สร้าง AI Agent" ทางด้านขวามือ

   2.3 เลือกเทมเพลตสำหรับเจ้าหน้าที่บริการลูกค้า แล้วกด "ดำเนินการต่อ" ที่มุมบนขวามือ

   2.4 หลังจากนั้น คุณจะเข้าสู่หน้าของการแก้ไข AI Agent ที่เพิ่งถูกสร้างขึ้น โดยคุณสามารถทำแก้ไขข้อมูลต่างๆ แล้วกด "บันทึกแบบร่าง" เพื่อบันทึกข้อมูลเหล่านั้นไว้

3. การสร้าง AI Agent สามารถกรอกรายละเอียดลงในกล่องข้อความ โดยสามารถตั้งชื่อ AI Agent และเปลี่ยนรูปได้
