# (Beta) วิธีใช้ AI สร้าง AI Agent ง่ายๆ

> วิธีใช้ AI สร้าง AI Agent ง่ายๆ
>
> Source: https://docs.ingfah.ai/guides/ai-agent/ai-create-agent-with-skill/

:::caution[ฟีเจอร์นี้ยังอยู่ในช่วง Beta]
ฟีเจอร์นี้ยังอยู่ระหว่างการพัฒนา อาจมีการเปลี่ยนแปลงหรือข้อผิดพลาดเกิดขึ้นได้ หากพบปัญหาการใช้งาน สามารถแจ้งทีมงานอิงฟ้าได้ทันที
:::

ปกติแล้วการสร้าง AI Agent จำเป็นต้องเข้าใจวิธีการเขียน Prompt และตั้งค่าต่างๆ ในระบบอิงฟ้า แต่ตอนนี้คุณสามารถให้ **ChatGPT Desktop app** หรือ **Claude Desktop app** ช่วยสร้าง AI Agent ให้คุณได้โดยตรง แม้ไม่มีความรู้เรื่องการเขียนโค้ดหรือการเขียน Prompt มาก่อน

ทำได้โดยการติดตั้ง Skill ที่ชื่อว่า **ingfah** ซึ่งจะทำให้ AI รู้จักวิธีเชื่อมต่อและสร้าง AI Agent บนระบบอิงฟ้าให้คุณ

## ขั้นตอนที่ 1: ติดตั้ง Skill

Skill ของอิงฟ้าเผยแพร่อย่างเป็นทางการบน [skills.sh](https://skills.sh/100x-fi/ingfah-skill/ingfah) ซึ่งเป็นแหล่งรวม Skill สำหรับ AI วิธีติดตั้งจะต่างกันตามแอปที่คุณใช้

### สำหรับ Claude Desktop app

Claude Desktop app ติดตั้ง Skill ด้วยการอัปโหลดไฟล์ .zip

1. ดาวน์โหลดไฟล์ Skill ที่ [ingfah-skill v1.0.2 (.zip)](https://github.com/100x-fi/ingfah-skill/archive/refs/tags/v1.0.2.zip) **ไม่ต้องแตกไฟล์**
2. เปิด Claude Desktop app แล้วไปที่ **Settings → Capabilities**
3. ตรวจสอบว่าเปิด **Code execution and file creation** ไว้แล้ว เพราะ Skill ต้องใช้ความสามารถนี้
4. ในส่วน **Skills** กด **Upload skill** แล้วเลือกไฟล์ .zip ที่ดาวน์โหลดมา
5. เปิดใช้งาน Skill **ingfah** แล้ว **เริ่มแชทใหม่**

:::note
Skill ที่อัปโหลดจะผูกกับบัญชี Claude ของคุณ จึงใช้ได้ทั้งใน Claude Desktop app และ claude.ai บนเว็บ
:::

### สำหรับ ChatGPT Desktop app และ Claude Code

คุณไม่จำเป็นต้องเปิดโปรแกรมอื่นหรือพิมพ์คำสั่งเอง เพียงให้ AI ติดตั้งให้

1. เปิด ChatGPT Desktop app หรือ Claude Code
2. เริ่มแชทใหม่ แล้วคัดลอกข้อความด้านล่างไปวางในช่องแชท

:::tip[พิมพ์ข้อความนี้ให้ AI]
ช่วยติดตั้ง Skill ingfah จาก skills.sh ให้หน่อย โดยใช้คำสั่ง `npx skills add 100x-fi/ingfah-skill -g`
:::

3. หาก AI ขออนุญาตรันคำสั่ง ให้กด **อนุญาต** (Allow)
4. เมื่อ AI แจ้งว่าติดตั้งเสร็จแล้ว ให้ **ปิดแชทนี้แล้วเริ่มแชทใหม่** เพื่อให้ AI โหลด Skill ที่เพิ่งติดตั้ง

:::note[สำหรับผู้ที่คุ้นเคยกับ Terminal]
สามารถติดตั้งเองได้ด้วยคำสั่ง

```bash
npx skills add 100x-fi/ingfah-skill -g
```
:::

## ขั้นตอนที่ 2: สร้าง API Key และเชื่อมต่อกับอิงฟ้า

AI จะเชื่อมต่อกับระบบอิงฟ้าผ่าน **API Key** ของคุณ

1. ล็อกอินเข้าระบบที่ https://ingfah.ai/login
2. ที่เมนูด้านซ้ายมือ เลือก **API Keys**
3. กดปุ่ม **สร้าง API Key**
4. ตั้งชื่อ API Key ให้จำง่าย เช่น `Claude Desktop` แล้วกด **สร้าง**
5. ระบบจะแสดง API Key ขึ้นมา ให้กด **คัดลอก** แล้วเก็บไว้ในที่ปลอดภัย

:::danger[API Key จะแสดงเพียงครั้งเดียวเท่านั้น]
หลังจากปิดหน้าต่างนี้ไปแล้วจะไม่สามารถดู API Key เดิมได้อีก หากทำหาย ให้สร้าง API Key ใหม่แล้วลบอันเก่าทิ้ง

API Key เปรียบเสมือนรหัสผ่าน **ห้ามส่งต่อให้ผู้อื่น** และห้ามโพสต์ในที่สาธารณะ
:::

จากนั้นกลับไปที่แชทใหม่ใน AI แล้วพิมพ์:

:::tip[พิมพ์ข้อความนี้ให้ AI]
ช่วยเชื่อมต่อกับ ingfah ให้หน่อย
:::

AI จะขอ **API Key** ให้วาง API Key ที่คัดลอกไว้ลงในช่องแชท แล้วทำตามคำแนะนำบนหน้าจอจนเชื่อมต่อสำเร็จ

## ขั้นตอนที่ 3: บอก AI ว่าต้องการสร้าง AI Agent แบบไหน

เมื่อเชื่อมต่อสำเร็จแล้ว คุณสามารถบอก AI เป็นภาษาพูดธรรมดาได้เลยว่าต้องการ AI Agent ที่ทำหน้าที่อะไร ยิ่งให้รายละเอียดครบถ้วน AI Agent ที่ได้ก็จะยิ่งทำงานได้ตรงตามที่ต้องการมากขึ้น

ข้อมูลที่ควรระบุให้ AI ทราบ:

- **บทบาทของ Agent** เช่น เพศ บุคลิก น้ำเสียง (สุภาพ ดุ เป็นกันเอง ฯลฯ)
- **ชื่อบริษัท / แบรนด์** ที่ Agent เป็นตัวแทน
- **กลุ่มลูกค้าที่ Agent จะติดต่อด้วย** เช่น ลูกค้าที่ค้างชำระ ลูกค้าที่เพิ่งสั่งซื้อสินค้า
- **สิ่งที่ต้องแจ้งลูกค้าทุกครั้ง** เช่น การขอ consent บันทึกเสียง ข้อมูลที่ต้องแจ้ง
- **เป้าหมายของการสนทนา** เช่น ต้องการให้ลูกค้ารับปากอะไร หรือให้ข้อมูลอะไรกลับมา
- **กฎที่ Agent ห้ามทำ หรือต้องทำเสมอ** เช่น ห้ามลดราคา ห้ามวางสายก่อนลูกค้า
- **ข้อมูลที่ต้องสรุปหลังจบการสนทนา** เช่น ผลลัพธ์การสนทนา วันเวลาที่ลูกค้านัดหมาย

:::tip[ตัวอย่างการสั่งงาน]
ช่วยสร้าง AI Agent เพศหญิง บุคลิกจริงจังและน่าเชื่อถือ สำหรับทวงถามหนี้ค้างชำระ

บริษัทชื่อ "อิงฟ้าไฟแนนซ์"

ลูกค้าที่ Agent จะติดต่อคือลูกค้าที่ค้างชำระเกินกำหนดวันที่ต้องจ่ายแล้ว

ทุกครั้งที่โทร Agent ต้องแจ้งข้อมูลต่อไปนี้กับลูกค้า:
1. ขอ consent การบันทึกเสียงสนทนา
2. วันครบกำหนดชำระที่ผ่านมาแล้ว
3. ยอดค้างชำระทั้งหมด

เป้าหมายหลักคือให้ลูกค้ารับปากว่าจะชำระเงินภายในวันนี้ หากลูกค้าปฏิเสธ ให้ Agent โน้มน้าวอย่างจริงจังและหนักแน่นเพื่อให้ลูกค้าตระหนักถึงความสำคัญของการชำระโดยเร็ว โดยยึดหลักว่าต้องชำระเต็มจำนวนเท่านั้น ห้ามลดยอดหรือแบ่งผ่อนชำระ

ห้าม Agent วางสายก่อน ต้องให้ลูกค้าเป็นฝ่ายวางสายเท่านั้น และต้องพยายามทวงถามให้ได้ผลลัพธ์ที่ชัดเจนก่อนจบการสนทนา

เมื่อจบการสนทนาทุกครั้ง ให้สรุปผลลัพธ์ว่าลูกค้ารับปากจะจ่ายหรือไม่ หากรับปากให้ระบุวันและเวลาที่จะชำระ หากปฏิเสธหรือมีอาการงอแง/โวยวาย ให้บันทึกไว้ในสรุปด้วย

ถ้าข้อมูลตรงไหนไม่เพียงพอ ให้ถามผมเพิ่มเติมได้
:::

หลังจากนั้น AI จะช่วยตั้งค่า Flow บทสนทนา และสร้าง AI Agent ให้บนระบบอิงฟ้าโดยอัตโนมัติ คุณสามารถเข้าไปตรวจสอบและปรับแต่งเพิ่มเติมได้ที่หน้า [ปรับแต่ง AI Agent](./manage-ai-agent)
