# ดูประวัติเวอร์ชัน AI Agent

> ตรวจสอบแบบร่างและเวอร์ชันที่เผยแพร่ก่อนหน้า
>
> Source: https://docs.ingfah.ai/guides/ai-agent/version-history/

หน้า **ประวัติการแก้ไข** ใช้ตรวจสอบว่า AI Agent เปลี่ยนไปอย่างไร โดยไม่แก้ไขเวอร์ชันที่กำลังดู

## เหมาะกับงานแบบไหน

ใช้เมื่อต้องตรวจว่า Agent เคยตั้งค่าไว้อย่างไรก่อนแก้ไข ตัวอย่างเช่น หลังเปลี่ยนข้อความทักทาย คุณสามารถเปิดเวอร์ชันก่อนหน้าเทียบกับแบบร่างล่าสุด เพื่อดูว่าคำสั่งหรือ Flow ส่วนใดเปลี่ยนไป หน้านี้ใช้ตรวจสอบเท่านั้น ไม่ได้คืนค่าเวอร์ชันเก่า

1. เปิดรายละเอียด AI Agent
2. กดเมนู **⋯** แล้วเลือก **ประวัติการแก้ไข**
3. เลือกเวอร์ชันจากรายการด้านซ้ายเพื่อดูรายละเอียดด้านขวา

รายการแสดงวันสร้างและผู้สร้าง พร้อมป้ายระบุแบบร่างล่าสุดหรือเวอร์ชันเผยแพร่ล่าสุดเมื่อเกี่ยวข้อง รายละเอียดแสดงข้อมูล Agent และ Flow ของเวอร์ชันที่เลือก คุณสามารถเปิดโหนดใน Flow เพื่ออ่านข้อมูลได้ แต่แก้ไขจากหน้านี้ไม่ได้

กดลูกศรย้อนกลับเพื่อกลับไปหน้ารายละเอียด AI Agent หากต้องการเปลี่ยน Agent ที่ใช้งานอยู่ ให้กลับไป[แก้ไขแบบร่างและเผยแพร่](/guides/ai-agent/manage-ai-agent/)
