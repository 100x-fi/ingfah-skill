# เชื่อมต่อ LINE OA ให้ AI Agent ตอบแชท

> เพิ่มช่องทางติดต่อ LINE OA และเลือกทีม AI Agent ที่จะตอบแชทลูกค้าอัตโนมัติ
>
> Source: https://docs.ingfah.ai/guides/text-chat/connect-line-oa/

นอกจากรับสายและโทรออกแล้ว AI Agent ของ ingfah ยังตอบแชทลูกค้าผ่าน LINE Official Account (LINE OA) ได้ โดยเชื่อมต่อผ่านเมนู **"ช่องทางติดต่อ"**

:::note[แพลตฟอร์มที่รองรับ]
ตอนนี้รองรับ **LINE OA** ส่วน **FB Messenger** และ **Instagram** จะเปิดให้ใช้งานเร็วๆ นี้
:::

## ก่อนเริ่ม

เตรียมสิ่งเหล่านี้ให้พร้อม

1. **AI Agent แบบข้อความ** ที่หน้า AI Agent ให้เลือกแท็บ **"ข้อความ"** แล้วกด **"สร้าง AI Agent"** จากนั้นเลือกเทมเพลตหรือเริ่มสร้างใหม่ตั้งแต่ต้น ขั้นตอนที่เหลือเหมือนการ[สร้าง AI Agent ตัวแรก](/guides/ai-agent/getting-started)
2. **ทีม AI Agent แบบข้อความ** ที่มี AI Agent แบบข้อความอยู่ในทีม ดูวิธีได้ที่[สร้างทีม AI Agent](/guides/inbound-outbound/create-ai-agent-team)
3. **บัญชี LINE OA ที่เปิดใช้ Messaging API แล้ว** พร้อมค่า **Channel Secret** และ **Channel Access Token** จาก [LINE Developers Console](https://developers.line.biz/console/)

## 1. เพิ่มช่องทางติดต่อ

1. ไปที่เมนู **"ช่องทางติดต่อ"** แล้วเลือกแท็บ **"ข้อความ"**
2. กด **"เพิ่มช่องทางติดต่อ"**
3. กรอก **ข้อมูลช่องทาง**
   - **แพลตฟอร์ม** เลือก **LINE OA** (เปลี่ยนภายหลังไม่ได้)
   - **ชื่อช่องทาง** ชื่อที่ใช้เรียกช่องทางนี้ในระบบ ไม่เกิน 100 ตัวอักษร เช่น "LINE ฝ่ายบริการลูกค้า"
   - **Channel Secret** และ **Channel Access Token** คัดลอกมาจาก LINE Developers Console
   - **LINE ID** ของบัญชี LINE OA
4. ในส่วน **"ทีม AI Agent ที่รับผิดชอบ"** เลือกทีมที่จะตอบแชทจากช่องทางนี้
5. กด **"เพิ่มช่องทางติดต่อ"**

## 2. ตั้งค่า Webhook ใน LINE

ระบบจะสร้าง **Webhook URL** ให้หลังเพิ่มช่องทางแล้ว ต้องนำ URL นี้ไปใส่ใน LINE เพื่อให้ข้อความจากลูกค้าส่งเข้ามาที่ ingfah

1. ที่แท็บ **"ข้อความ"** กดช่องทางที่เพิ่งสร้าง แล้วกดคัดลอก **Webhook URL**
2. ไปที่ LINE Developers Console แล้วเปิด Channel ของ LINE OA
3. ที่แท็บ **Messaging API** วาง URL ในช่อง **Webhook URL** แล้วเปิด **Use webhook**

:::tip[ปิดข้อความตอบกลับอัตโนมัติของ LINE]
หากเปิดข้อความตอบกลับอัตโนมัติ (Auto-reply) ไว้ใน LINE Official Account Manager ลูกค้าจะได้รับทั้งข้อความของ LINE และคำตอบจาก AI Agent แนะนำให้ปิด Auto-reply ของ LINE
:::

เมื่อตั้งค่าเสร็จ ลองทักแชทไปที่ LINE OA แชทจะปรากฏที่เมนู **"แชท"** และ AI Agent จะเริ่มตอบทันที ดูวิธีติดตามและตอบแชทได้ที่[จัดการแชทกับลูกค้า](/guides/text-chat/chat-sessions)

## ดู แก้ไข และลบช่องทางติดต่อ

กดที่ช่องทางในแท็บ **"ข้อความ"** เพื่อดูรายละเอียด เช่น ทีม AI Agent ที่รับผิดชอบ ผู้สร้าง และผู้แก้ไขล่าสุด ค้นหาด้วยชื่อช่องทาง หรือกรองตามแพลตฟอร์มก็ได้

- **แก้ไข** กด **"แก้ไข"** ในหน้ารายละเอียด เพื่อเปลี่ยนชื่อช่องทาง ข้อมูลเชื่อมต่อ หรือทีม AI Agent ที่รับผิดชอบ แล้วกด **"บันทึกการแก้ไข"** ระบบซ่อนค่า Secret Key เดิมไว้ ต้องกรอกใหม่เฉพาะเมื่อต้องการเปลี่ยนค่า
- **ลบ** ในหน้าแก้ไข กด **"ลบช่องทางติดต่อ"** แล้วพิมพ์ `delete` เพื่อยืนยัน

:::caution[การลบช่องทางติดต่อ]
แชทที่กำลังคุยกับลูกค้าผ่านช่องทางนี้จะถูกยุติทันที และกู้คืนช่องทางไม่ได้
:::

:::note[ลบทีม AI Agent ที่ผูกกับช่องทางอยู่ไม่ได้]
หากต้องการลบทีม AI Agent ที่ตอบแชทอยู่ ให้เปลี่ยนทีมที่รับผิดชอบของช่องทางนั้นเป็นทีมอื่น หรือลบช่องทางก่อน ดูช่องทางที่ผูกกับทีมได้ในส่วน **"ช่องทางตอบแชทที่รองรับ"** ในหน้ารายละเอียดทีม
:::
