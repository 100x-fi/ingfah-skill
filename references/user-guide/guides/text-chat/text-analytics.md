# แดชบอร์ดแชทข้อความ

> ดูภาพรวมการตอบแชท จำนวนลูกค้า ผลลัพธ์ และช่วงเวลาที่มีข้อความมากที่สุด
>
> Source: https://docs.ingfah.ai/guides/text-chat/text-analytics/

ดูภาพรวมของแชททั้งหมดได้ที่เมนู **"แดชบอร์ด"** > **"ข้อความ"**

## ตัวกรอง

- **ช่วงวัน** เลือก **วันนี้** **เมื่อวาน** **สัปดาห์นี้** **เดือนนี้** หรือ **กำหนดเอง** เพื่อระบุวันและเวลาเริ่มต้น–สิ้นสุด
- **ช่องทางติดต่อ** และ **ทีม AI Agent** เลือกได้หลายรายการ
- กด **"รีเซ็ต"** เพื่อล้างตัวกรอง และกด **"รีเฟรชข้อมูล"** เพื่อโหลดข้อมูลล่าสุด เวลาที่อัปเดตล่าสุดแสดงไว้ด้านบน

## ข้อมูลสรุป

| ข้อมูล | รายละเอียด |
|--------|-----------|
| **จำนวนการตอบแชท** | จำนวนแชทที่ตอบ แยกเป็นสัดส่วนที่ตอบโดย AI Agent และโดยเจ้าหน้าที่ |
| **จำนวนห้องแชท** | จำนวนห้องแชททั้งหมดในช่วงที่เลือก |
| **ระยะเวลาเฉลี่ยในการปิดแชท** | เวลาเฉลี่ยตั้งแต่เริ่มแชทจนปิดการสนทนา |
| **จำนวนลูกค้าทั้งหมด** | จำนวนลูกค้า แยกเป็นลูกค้าใหม่และลูกค้าเก่า |
| **ผลลัพธ์** | สัดส่วนและจำนวนผลลัพธ์หลังจบการสนทนาของแต่ละทีม ตามที่ตั้งไว้ใน [ผลลัพธ์หลังจบการสนทนา](/guides/inbound-outbound/call-outcome-setup) |

## กราฟ

- **ปริมาณข้อความต่อชั่วโมง** ปริมาณข้อความในแต่ละชั่วโมง แยกตามช่องทางติดต่อ
- **Peak Hour Heat Map** ความหนาแน่นของข้อความในแต่ละชั่วโมง ยิ่งสีเข้มยิ่งมีข้อความมาก เลือกดูแบบ **เฉลี่ยวันในสัปดาห์** (จันทร์–อาทิตย์) หรือ **ทั้งหมด** (แยกตามวันที่) ใช้วางแผนจำนวนเจ้าหน้าที่ในช่วงที่มีแชทเยอะ

## ดาวน์โหลดรีพอร์ต

ปุ่ม **"ดาวน์โหลดรีพอร์ต"** ในแดชบอร์ดข้อความยังไม่สร้างไฟล์ หากต้องการส่งออกรายการแชทเป็น CSV ให้เปิดแท็บ **ข้อความ** ใน [สายและแชททั้งหมด](/guides/inbound-outbound/all-calls/)
