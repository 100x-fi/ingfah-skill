# จัดการแชทกับลูกค้า

> ติดตามแชทที่ AI Agent ตอบ รับช่วงตอบเอง มอบหมายผู้ดูแล และปิดการสนทนา
>
> Source: https://docs.ingfah.ai/guides/text-chat/chat-sessions/

แชทจากลูกค้าในทุกช่องทางติดต่อจะรวมอยู่ที่เมนู **"แชท"** คุณดูได้ว่า AI Agent ตอบอะไรไป และรับช่วงมาตอบเองได้ทุกเมื่อ

## เหมาะกับงานแบบไหน

ใช้เมื่อเจ้าหน้าที่ต้องดูแลแชทต่อจาก AI Agent หรือตรวจว่าคำตอบส่งถึงลูกค้าหรือไม่ ตัวอย่างเช่น ลูกค้าถามเรื่องที่ต้องตรวจข้อมูลเฉพาะบัญชี เจ้าหน้าที่สามารถปิดการตอบอัตโนมัติแล้วตอบเอง หากคำตอบของ AI Agent แสดง **ส่งข้อความไม่สำเร็จ** ให้ดูสาเหตุจากไอคอนข้อมูลก่อนติดต่อหรือส่งข้อความหาลูกค้าอีกครั้ง

## ส่วนต่างๆ ของหน้าแชท

หน้าแชทแบ่งเป็นสามส่วน

| ส่วน | รายละเอียด |
|------|-----------|
| **รายการแชท** (ซ้าย) | แชททั้งหมด พร้อมข้อความล่าสุด |
| **การสนทนา** (กลาง) | ข้อความในแชทที่เลือก และช่องพิมพ์ตอบ |
| **ข้อมูลการสนทนา** (ขวา) | ข้อมูลลูกค้าและประวัติแชท เปิดหรือปิดได้ที่ไอคอน **ⓘ** |

## ค้นหาและกรองแชท

- **แท็บ "ทั้งหมด"** แสดงทุกแชท ส่วน **แท็บ "ดูแลโดยฉัน"** แสดงเฉพาะแชทที่คุณเป็นผู้ดูแล
- **ค้นหา** ด้วยชื่อลูกค้า
- **ตัวกรอง** เลือกช่วงวัน สถานะ (**กำลังดำเนินการ** / **ปิดการสนทนา**) ช่องทางติดต่อ ทีม AI Agent และผลลัพธ์ แล้วกด **"ใช้งานตัวกรอง"**

รายการแชทอัปเดตอัตโนมัติเมื่อมีข้อความใหม่ ไม่ต้องรีเฟรชหน้า

## อ่านบทสนทนา

ในแชทที่เลือก จะเห็นว่าใครเป็นผู้ส่งแต่ละข้อความ

- **AI Agent (ชื่อ AI Agent)** ข้อความที่ AI Agent ตอบ
- **เจ้าหน้าที่ (อีเมล)** ข้อความที่เจ้าหน้าที่พิมพ์ตอบเอง
- รูปภาพและสติกเกอร์ที่ลูกค้าส่งมา
- การเรียกใช้ Tool ของ AI Agent กดดู **คำขอ** และ **การตอบกลับ** ของ Tool ได้
- บันทึกการกระทำของเจ้าหน้าที่ เช่น ใครปิดการตอบกลับอัตโนมัติ หรือมอบหมายแชทให้ใคร เมื่อไร
- **สรุปการสนทนา** ที่ระบบสร้างให้อัตโนมัติเมื่อจบแต่ละรอบการสนทนา

กด **"โหลดข้อความก่อนหน้า"** เพื่อดูข้อความเก่า

หากระบบส่งข้อความของ AI Agent ไม่ถึงลูกค้า บทสนทนาจะแสดง **ส่งข้อความไม่สำเร็จ** ใต้ข้อความนั้น วางเมาส์บนไอคอนข้อมูลเพื่อดูสาเหตุที่ระบบทราบ เช่น ช่องทางส่งข้อความถูกปิด โควตาข้อความหมด หรือช่องทางไม่ตอบสนอง รายการแชทด้านซ้ายจะแสดงสถานะส่งไม่สำเร็จสำหรับข้อความล่าสุดด้วย หากไม่มีไอคอนข้อมูล แปลว่าระบบไม่มีสาเหตุเพิ่มเติมให้แสดง

## รับช่วงตอบแชทเอง

ตามค่าเริ่มต้น AI Agent จะตอบแชทอัตโนมัติ และช่องพิมพ์ข้อความจะแสดงว่า *"AI กำลังตอบแชทนี้อยู่"*

1. ปิดสวิตช์ **"AI Agent ตอบกลับอัตโนมัติ"** เหนือช่องพิมพ์ข้อความ
2. พิมพ์ข้อความแล้วกด **"ส่ง"** ข้อความจะส่งถึงลูกค้าในนามของ LINE OA
3. เมื่อต้องการให้ AI Agent กลับมาตอบต่อ ให้เปิดสวิตช์อีกครั้ง

:::note
การเปิดหรือปิดสวิตช์ใช้กับแชทนั้นแชทเดียว และระบบจะบันทึกไว้ในบทสนทนาว่าใครเปลี่ยนเมื่อไร
:::

## ปิดการสนทนา

เมื่อดูแลลูกค้าเสร็จแล้ว กด **"ปิดการสนทนา"** ที่ด้านบนของการสนทนา แล้วยืนยัน

แชทที่ปิดแล้วจะแสดงเวลาที่ปิด หากลูกค้าทักมาอีกครั้ง แชทจะเปิดขึ้นใหม่โดยอัตโนมัติ

หากแชทตั้งเวลาให้ปิดเมื่อไม่มีการใช้งาน ระบบจะแสดงเวลานับถอยหลังก่อนปิดอัตโนมัติ

## ข้อมูลการสนทนา

แท็บ **"ข้อมูลการติดต่อ"** แสดง

| ข้อมูล | รายละเอียด |
|--------|-----------|
| **ชื่อลูกค้า** | แก้ไขชื่อที่แสดงได้ (ไม่เกิน 20 ตัวอักษร) ระบบยังเก็บชื่อเดิมไว้ พร้อมบันทึกว่าใครแก้ไขเมื่อไร |
| **ช่องทางติดต่อ** | ช่องทางที่ลูกค้าทักเข้ามา |
| **ทีม AI Agent** | ทีมที่รับผิดชอบช่องทางนี้ |
| **ดูแลโดย** | เจ้าหน้าที่ที่ดูแลแชท เลือกเจ้าหน้าที่คนอื่นเพื่อมอบหมายแชทให้ดูแลต่อได้ |
| **ผลลัพธ์** | ผลลัพธ์หลังจบการสนทนาตามที่ตั้งไว้ในทีม ดู [ผลลัพธ์หลังจบการสนทนา](/guides/inbound-outbound/call-outcome-setup) |

แท็บ **"ประวัติแชท"** แสดงการสนทนาครั้งก่อนๆ ของลูกค้าคนเดียวกัน กดเพื่อเปิดดูย้อนหลังได้

หากต้องการค้นหาและส่งออกรายการแชทหลายรายการ ให้ดู [สายและแชททั้งหมด](/guides/inbound-outbound/all-calls/)
