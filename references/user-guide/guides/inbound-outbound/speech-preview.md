# ฟังตัวอย่างเสียงจากข้อมูลลูกค้า

> ทดสอบว่า AI Agent อ่านค่าในไฟล์ CSV อย่างไรก่อนสร้างแคมเปญโทรออก
>
> Source: https://docs.ingfah.ai/guides/inbound-outbound/speech-preview/

ในขั้นตอนที่ 3 ของ[การสร้างแคมเปญโทรออก](/guides/inbound-outbound/outbound-batch/) คุณสามารถฟังตัวอย่างการอ่านข้อมูลลูกค้าจากตารางก่อนกดยืนยัน ระบบใช้เสียงของ AI Agent ที่เลือกสำหรับแคมเปญ

## เหมาะกับงานแบบไหน

ใช้ก่อนเริ่มโทรออกเมื่อไฟล์ลูกค้ามีชื่อ เบอร์ หรือรหัสที่ AI Agent ต้องอ่านออกเสียง ตัวอย่างเช่น แคมเปญแจ้งนัดมีคอลัมน์วันนัดและชื่อสาขา ลองฟังเซลล์ตัวอย่างหลายแถวเพื่อเช็กว่า Agent อ่านวันและชื่อสาขาได้ตามที่ต้องการก่อนยืนยัน Batch

## ฟังข้อมูลที่ต้องการตรวจ

- กด **ทดสอบฟังข้อมูล** เหนือตารางเพื่อฟังหลายแถวตามลำดับคอลัมน์
- ชี้หัวคอลัมน์แล้วกดปุ่มเล่นเพื่อฟังค่าของคอลัมน์นั้นหลายแถว
- ชี้หมายเลขแถวแล้วกดปุ่มเล่นเพื่อฟังค่าที่ไม่ว่างในแถวนั้น
- ชี้เซลล์แล้วกดปุ่มเล่นเพื่อฟังค่าเดียว

การทดสอบหลายแถวเล่นได้สูงสุด 100 แถวต่อครั้ง และข้ามเซลล์ว่าง กดปุ่มเดิมอีกครั้งเพื่อหยุดเสียง

## เลือก Agent และช่วงแถว

เปิดเมนูที่ **ทดสอบฟังข้อมูล** หรือหัวคอลัมน์ แล้วเลือก **เลือกฟัง** เลือก AI Agent ที่จะพูด ระบุแถวเริ่มต้นและแถวสิ้นสุด จากนั้นกด **เล่นเสียง** แถวสิ้นสุดต้องมากกว่าแถวเริ่มต้น และช่วงที่เลือกต้องไม่เกิน 100 แถว

หากไม่มี AI Agent ให้เลือก หรือระบบแจ้งว่าเล่นตัวอย่างเสียงไม่ได้ ให้ตรวจว่าทีมของแคมเปญมี Agent และเสียงที่ Agent ใช้รองรับการทดสอบฟัง
