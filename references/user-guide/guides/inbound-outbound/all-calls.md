# สายทั้งหมด (All Calls)

> ดูประวัติการโทรทั้งสายเข้าและสายออกรวมในหน้าเดียว พร้อมตัวกรองและดาวน์โหลดรีพอร์ต
>
> Source: https://docs.ingfah.ai/guides/inbound-outbound/all-calls/

หน้า **สายทั้งหมด** รวมประวัติการโทรของทุกทีม AI Agent ทั้งสายเข้าและสายออกไว้ในที่เดียว ต่างจากเมนูสายเข้า/สายออกที่แยกกันดูทีละฝั่ง

## ข้อมูลในตาราง

| คอลัมน์ | ความหมาย |
|---------|----------|
| วันที่ | วันและเวลาที่เกิดสาย |
| สายเข้า/สายออก | ทิศทางของสาย |
| เบอร์โทรลูกค้า | เบอร์ปลายทางหรือต้นทางของลูกค้า (กดเพื่อคัดลอกได้) |
| เบอร์โทรบริษัท | เบอร์ของคุณที่ใช้รับหรือโทรออก |
| ระยะเวลา | ความยาวของสาย |
| หัวข้อสนทนา | หัวข้อที่ระบบสรุปจากบทสนทนา |
| ทีม AI Agent | ทีมที่รับผิดชอบสายนั้น |
| ผลลัพธ์ | ผลลัพธ์หลังจบการสนทนา ดู [ผลลัพธ์หลังจบการสนทนา](/guides/inbound-outbound/call-outcome-setup/) |
| Metadata | ข้อมูลผลลัพธ์แบบละเอียด เปิดดูเป็น JSON ได้ |

สายที่ยังคุยอยู่จะแสดงสถานะ **กำลังสนทนา** และกดปุ่ม **รีเฟรช** เพื่ออัปเดตข้อมูลล่าสุดได้ พร้อมแสดงเวลาอัปเดตล่าสุดไว้ด้านบน

## ค้นหาและกรอง

- **ค้นหา** — ด้วยเบอร์โทรหรือหัวข้อสนทนา
- **วันที่แสดงผล** — เลือกช่วงวัน พร้อมกำหนดเวลาเริ่มต้น-สิ้นสุด และมีตัวกรองด่วน วันนี้ / เมื่อวาน / 7 วันล่าสุด / สัปดาห์นี้ / เดือนนี้
- **ประเภท** — สายเข้า หรือ สายออก
- **เบอร์โทรบริษัท** — เลือกได้หลายหมายเลข
- **ระยะเวลา** — กำหนดช่วงต่ำสุด-สูงสุด ในรูปแบบ ชั่วโมง:นาที:วินาที
- **ทีม AI Agent** — เลือกได้หลายทีม (ทีมที่ถูกลบไปแล้วจะมีป้ายกำกับไว้)
- **ผลลัพธ์** — กรองตามผลลัพธ์หลังจบการสนทนา
- **สถานะ** — กรองตามสถานะของสาย
- **รีเซ็ต** — ล้างตัวกรองทั้งหมด

## ดาวน์โหลดรีพอร์ต

กด **ดาวน์โหลดรีพอร์ต** เพื่อส่งออกข้อมูลตามตัวกรองที่เลือกอยู่ หากดาวน์โหลดไม่สำเร็จ ระบบจะแจ้งเตือนให้ลองใหม่อีกครั้ง

:::tip[เลือกช่วงข้อมูลก่อนดาวน์โหลด]
ตั้งตัวกรองวันที่และทีมให้ตรงกับที่ต้องการก่อนกดดาวน์โหลด จะได้ไฟล์ที่ตรงประเด็นและขนาดเล็กกว่า
:::
