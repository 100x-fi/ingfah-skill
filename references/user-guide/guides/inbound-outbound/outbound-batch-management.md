# การจัดการแคมเปญโทรออก (Batch)

> วิธีหยุดชั่วคราว ดำเนินการต่อ และยกเลิกแคมเปญโทรออก
>
> Source: https://docs.ingfah.ai/guides/inbound-outbound/outbound-batch-management/

“แคมเปญโทรออก” (Batch) สามารถจัดการได้ทั้ง **หยุดชั่วคราว**, **ดำเนินการต่อ** และ **ยกเลิก** ตามสถานะของ Batch

---

## หยุดชั่วคราวแคมเปญโทรออก

ใช้เมื่อต้องการหยุดการทำงานของ Batch ชั่วคราว โดยสามารถกลับมาเริ่มทำงานต่อได้ภายหลัง

เมื่อหยุดชั่วคราว:

- สายที่ยังไม่เริ่มจะถูกหยุดไว้
- สายที่กำลังสนทนาอยู่จะดำเนินการจนจบก่อนหยุด Batch

สามารถหยุดชั่วคราวได้ 2 วิธี

### วิธีที่ 1: หยุดจากหน้ารายละเอียด Batch

1. เปิด Batch ที่อยู่ในสถานะ **กำลังดำเนินการ**

2. คลิกเมนูบริเวณมุมขวาบน แล้วเลือก **หยุดชั่วคราว**

3. ระบบจะแสดงหน้าต่างยืนยัน พร้อมแจ้งผลของการหยุดชั่วคราว

4. คลิก **หยุดชั่วคราว** เพื่อยืนยัน

5. เมื่อหยุดสำเร็จ Batch จะย้ายไปอยู่ในแท็บ **หยุดชั่วคราว**

---

### วิธีที่ 2: หยุดจากหน้ารายการ Batch

สามารถหยุด Batch ได้จากหน้ารายการโดยไม่ต้องเปิดหน้ารายละเอียด

1. ไปที่แท็บ **กำลังดำเนินการ**

2. ค้นหา Batch ที่ต้องการหยุด แล้วคลิกไอคอน **หยุดชั่วคราว** ทางด้านขวาของรายการ

3. ระบบจะแสดงหน้าต่างยืนยันการหยุดชั่วคราว

4. คลิก **หยุดชั่วคราว** เพื่อยืนยัน

5. เมื่อหยุดสำเร็จ Batch จะย้ายไปอยู่ในแท็บ **หยุดชั่วคราว**

---

## ดำเนินการต่อแคมเปญโทรออก

ใช้สำหรับให้ Batch ที่อยู่ในสถานะ **หยุดชั่วคราว** กลับมาทำงานต่อ

เมื่อดำเนินการต่อ:

- สายที่ค้างไว้จะดำเนินการต่อ
- ระบบสามารถเริ่มสายใหม่ได้ตามช่วงเวลาที่กำหนดไว้

1. เปิด Batch ที่อยู่ในสถานะ **หยุดชั่วคราว**

2. คลิกเมนูบริเวณมุมขวาบน แล้วเลือก **ดำเนินการต่อ**

3. ระบบจะแสดงหน้าต่างยืนยันการเริ่มทำงานต่อ

4. คลิก **เริ่มทำงานต่อ** เพื่อยืนยัน

5. เมื่อเริ่มทำงานต่อสำเร็จ Batch จะกลับไปอยู่ในแท็บ **กำลังดำเนินการ**

---

## ยกเลิกแคมเปญโทรออก

ใช้เมื่อต้องการยกเลิก Batch และไม่ต้องการให้ระบบดำเนินการโทรต่อ

การยกเลิก Batch **ไม่สามารถย้อนกลับได้**

เมื่อยกเลิก:

- สายที่ยังไม่เริ่มจะถูกยกเลิก
- สายที่กำลังสนทนาอยู่จะดำเนินการจนจบ

### วิธียกเลิก Batch

1. เปิด Batch ที่ต้องการยกเลิก

2. คลิกเมนูบริเวณมุมขวาบน แล้วเลือก **ยกเลิก**

3. ระบบจะแสดงหน้าต่างยืนยันการยกเลิก และแจ้งผลที่จะเกิดขึ้นหลังยกเลิก Batch

4. คลิก **ยกเลิก Batch** เพื่อยืนยัน

5. เมื่อยกเลิกสำเร็จ สถานะของ Batch จะเปลี่ยนเป็น **ยกเลิกแล้ว**

6. Batch ที่ถูกยกเลิกจะย้ายไปอยู่ในแท็บ **สิ้นสุด**
