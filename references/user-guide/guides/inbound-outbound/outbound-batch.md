# สร้างแคมเปญโทรออก

> วิธีสร้างแคมเปญโทรออกแบบ Batch ด้วย AI Agent ทีละขั้นตอน
>
> Source: https://docs.ingfah.ai/guides/inbound-outbound/outbound-batch/

"แคมเปญโทรออก" (Batch) ใช้สำหรับให้ AI Agent โทรออกหาลูกค้าตามรายชื่อที่กำหนด เช่น แจ้งโปรโมชั่น ติดตามลูกค้า หรือแจ้งเตือนนัดหมาย โดยระบบจะโทรออกอัตโนมัติตามวันเวลาที่ตั้งไว้

ไปที่เมนู **"สายออก"** > **"สร้าง Batch"**

ในหน้านี้แบ่งการสร้างออกเป็น 3 ขั้นตอน คือ **อัปโหลด → ตั้งค่าคอลัมน์ → ตรวจสอบข้อมูล**

---

## ขั้นตอนที่ 1: อัปโหลด

1. กรอกข้อมูลต่างๆ ให้ครบถ้วน เริ่มจากกรอก **ชื่อ Batch**

2. เลือก **เบอร์ที่ใช้โทรออก** และ **เวลาสนทนาต่อสาย**

   :::note
   หากไม่เห็นเบอร์โทรศัพท์ในหน้านี้ ให้ดูรายละเอียดการเชื่อมต่อระบบโทรศัพท์ [ที่นี่](/telephony/overview) หรือติดต่อทีมงาน ingfah เพื่อขอใช้เบอร์ของ ingfah (มีค่าบริการเพิ่มเติม)
   :::

3. กำหนด **วันที่** (เริ่มต้น - สิ้นสุด), **วันทำงาน** และ **ช่วงเวลา** ที่ต้องการให้ระบบโทรออก

4. เปิด **"ตั้งค่าการโทรซ้ำ"** หากต้องการให้ระบบโทรซ้ำอัตโนมัติ ในกรณีที่โทรไม่ติดหรือลูกค้าไม่รับสาย

   หากต้องการให้ระบบโทรกลับตามเวลาที่ลูกค้านัด ให้ดู [ตั้งค่าโทรติดตามตามเวลาที่ลูกค้าขอ](/guides/inbound-outbound/follow-up-calls/)

5. เลือก **ทีม AI Agent**

   :::tip[ยังไม่มีทีม AI Agent?]
   สร้างทีม AI Agent ก่อนได้ [ที่นี่](/guides/inbound-outbound/create-ai-agent-team)
   :::

6. ถ้าทีม AI Agent มีการผูกเทมเพลตแล้ว ระบบจะแสดงตัวอย่างเทมเพลตให้อัตโนมัติ  
   หากยังไม่มี สามารถเลือก **"เทมเพลตข้อมูลลูกค้า"** จากเทมเพลตที่มีอยู่

   :::note
   รองรับเฉพาะไฟล์ `.csv` ที่มีขนาดไม่เกิน 25MB และชื่อคอลัมน์ในไฟล์ต้องตรงกับเทมเพลตที่เลือกไว้
   :::

7. กดปุ่ม **"+ เลือกไฟล์"** เพื่ออัปโหลดข้อมูลลูกค้า  
   หลังอัปโหลดไฟล์ ระบบจะคำนวณ **"ข้อมูลการดำเนินการโดยประมาณ"** ให้อัตโนมัติทางด้านขวา

8. ตรวจสอบข้อมูลให้ครบถ้วน แล้วกด **"ดำเนินการต่อ"** เพื่อไปยังขั้นตอนถัดไป

---

## ขั้นตอนที่ 2: ตั้งค่าคอลัมน์

1. จับคู่ **"ชื่อคอลัมน์บนไฟล์"** กับ **"ชื่อคอลัมน์บนระบบ"** ให้ตรงกัน  
   โดยคอลัมน์ที่มีเครื่องหมาย `*` (เช่น `phone_number`) เป็นคอลัมน์บังคับ  
   ตรวจสอบข้อมูลตัวอย่างในช่อง **"ตัวอย่าง"** แล้วกด **"ดำเนินการต่อ"**

---

## ขั้นตอนที่ 3: ตรวจสอบข้อมูล

1. ระบบจะแสดงสรุปข้อมูล Batch ทางซ้าย และตารางรายชื่อลูกค้าทางขวา  
   สามารถติ๊กเลือกหรือยกเลิกรายการที่ต้องการโทรออกได้

   หากต้องการตรวจว่า AI Agent อ่านข้อมูลลูกค้าอย่างไร ให้[ฟังตัวอย่างเสียงจากข้อมูลลูกค้า](/guides/inbound-outbound/speech-preview/) ก่อนยืนยัน

  
   :::note
   หากไม่สามารถกดยืนยันได้ เนื่องจากมีข้อมูลผิดพลาด ให้เปิด **"แสดงเฉพาะแถวที่มีข้อผิดพลาด"** เพื่อตรวจสอบแถวที่มีปัญหา และเลื่อนดูรายละเอียดข้อผิดพลาดได้ที่ด้านล่างซ้ายของหน้าจอ
   :::

   

3. ตรวจสอบข้อมูลครบถ้วนแล้ว กด **"ยืนยัน"** เป็นอันเสร็จสิ้นการสร้างแคมเปญโทรออก
