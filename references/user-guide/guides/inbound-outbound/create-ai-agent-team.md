# สร้างทีม AI Agent

> คู่มือการสร้างและจัดการทีม AI Agent สำหรับระบบโทรเข้าและโทรออก
>
> Source: https://docs.ingfah.ai/guides/inbound-outbound/create-ai-agent-team/

# ทีม AI Agent คืออะไร?

ระบบของ ingfah มองว่าการโทรเข้าและโทรออกจะถูกทำโดย **ทีม AI Agent** เสมอ โดยในหนึ่งทีมอาจมี AI Agent เพียงตัวเดียวหรือหลายตัวก็ได้

การออกแบบให้เป็น **ทีม** หมายความว่า:

- สามารถมี AI Agent ที่คุยกับลูกค้าได้หลายตัวในการโทรครั้งเดียว
- ต้องมี AI Agent หนึ่งตัวเป็นตัวแรกที่เริ่มต้นการสนทนากับลูกค้า
- AI Agent สามารถส่งต่อการสนทนาให้ Agent ตัวอื่นในทีม โดย Agent ที่รับต่อจะมีบริบทของการสนทนาเดิมด้วย

:::note
AI Agent หนึ่งตัวสามารถอยู่ได้หลายทีม
:::

---

## ตัวอย่าง Use Case

### 1. ทีม AI Agent รองรับหลายภาษา

ตั้งค่า AI Agent ตัวแรกให้สอบถามภาษาที่ลูกค้าต้องการ แล้วส่งต่อการสนทนาไปยัง AI Agent ของภาษานั้น ๆ

Agent แต่ละภาษาสามารถมี:

- เสียงและบุคลิกที่แตกต่างกัน
- Flow การสนทนาที่เหมาะสมกับวัฒนธรรมและภาษา

### 2. ทีม AI Agent รองรับหลายหน้าที่

สร้างทีมที่นำโดย AI Agent สำหรับตอบคำถามทั่วไป แล้วส่งต่อการสนทนาให้ Agent ผู้เชี่ยวชาญเฉพาะด้าน เช่น ฝ่ายขาย หรือฝ่ายเทคนิค

Agent แต่ละตัวสามารถมีคลังความรู้เฉพาะของตน วิธีนี้ช่วยลดโอกาสเกิดข้อผิดพลาดจากการให้ AI Agent ตัวเดียวรับผิดชอบหลายหน้าที่มากเกินไป

# วิธีสร้างทีม AI Agent

:::note[ก่อนเริ่มต้น]
ต้องสร้าง AI Agent อย่างน้อยหนึ่งตัวก่อน และ AI Agent ที่นำมาเพิ่มในทีมต้องเป็นประเภทเสียงที่มีสถานะ **เผยแพร่แล้ว**

ดูวิธีสร้าง AI Agent [ที่นี่](https://docs.ingfah.ai/guides/ai-agent/getting-started)
:::

## 1. ไปที่เมนูทีม AI Agent

ไปที่เมนู **ทีม AI Agent** ทางด้านซ้าย

---

## 2. สร้างทีม AI Agent

คลิกปุ่ม **+ สร้างทีม AI Agent** บริเวณมุมขวาบน

---

## 3. ระบุรายละเอียดทีม

ระบุข้อมูลของทีม ได้แก่:

- **ชื่อทีม**
- **คำอธิบายทีม**

จากนั้นเลือก **ประเภททีม** ที่ต้องการใช้งาน

- **รับสาย** สำหรับทีมที่ใช้รองรับสายโทรเข้า
- **โทรออก** สำหรับทีมที่ใช้โทรออกหาลูกค้า

:::caution
ประเภททีมจะไม่สามารถเปลี่ยนแปลงได้ภายหลัง กรุณาเลือกให้ถูกต้องว่าเป็นทีมสำหรับ **รับสาย** หรือ **โทรออก**
:::

---

## 4. เพิ่ม AI Agent ตัวแรก

คลิกปุ่ม **+ เพิ่ม AI Agent** ทางด้านขวาของหน้า

ระบบจะแสดงรายการ AI Agent ที่สามารถเลือกเข้าทีมได้

เลือก AI Agent ที่ต้องการ แล้วคลิก **ยืนยัน**

AI Agent ตัวแรกที่เพิ่มเข้ามาจะเป็น **จุดเริ่มต้น** ของทีม และเป็น Agent ตัวแรกที่เริ่มต้นการสนทนากับลูกค้า

---

## 5. เพิ่ม AI Agent ตัวอื่นในทีม

หากต้องการเพิ่ม AI Agent ตัวอื่น ให้คลิกจุดเชื่อมด้านล่างของ Agent ที่เพิ่มไว้ แล้วเลือก AI Agent ตัวถัดไป

สามารถกำหนดเส้นทางการส่งต่อการสนทนาไปยัง Agent ตัวอื่นในทีมได้ตาม Flow และเงื่อนไขที่ตั้งค่าไว้

---

## 6. บันทึกทีม AI Agent

เมื่อตั้งค่าทีมเรียบร้อยแล้ว คลิก **บันทึกทีม AI Agent** บริเวณมุมขวาบน

หลังจากบันทึก ทีม AI Agent จะพร้อมนำไปใช้กับการรับสายหรือโทรออกตามประเภททีมที่เลือกไว้
