# ตั้งค่า AI Agent ให้รับสายโทรเข้า

> เชื่อมต่อเบอร์โทรศัพท์กับทีม AI Agent เพื่อเริ่มรับสายโทรเข้าอัตโนมัติ
>
> Source: https://docs.ingfah.ai/guides/inbound-outbound/inbound-set-up/

1. ไปที่เมนู **"เบอร์โทรศัพท์"**

2. ในหน้านี้ คุณจะเห็นเบอร์โทรศัพท์ที่เชื่อมต่อกับบัญชี ingfah ของคุณสำหรับรับสายเข้า

   :::note
   หากไม่เห็นเบอร์โทรศัพท์ในหน้านี้ ให้ดูรายละเอียดการเชื่อมต่อระบบโทรศัพท์ [ที่นี่](/telephony/overview) หรือติดต่อทีมงาน ingfah เพื่อขอใช้เบอร์ของ ingfah (มีค่าบริการเพิ่มเติม)
   :::

3. กดปุ่มทางด้านขวาของเบอร์ที่ต้องการ แล้วเลือก **"แก้ไข"**
4. เลือก **"ทีมรับสายเข้า"** ที่ต้องการ

   :::tip[ยังไม่มีทีม AI Agent?]
   สร้างทีม AI Agent ก่อนได้ [ที่นี่](/guides/inbound-outbound/create-ai-agent-team)
   :::

หลังจากตั้งค่าเสร็จ คุณสามารถโทรเข้าที่เบอร์นี้เพื่อคุยกับ AI Agent ได้ทันที สายที่โทรเข้าจะปรากฏที่หน้า **"สายเข้า"** และ **"แดชบอร์ด"**
