# เทมเพลตข้อมูลลูกค้า

> ตั้งค่าคอลัมน์ข้อมูลลูกค้าที่ใช้ซ้ำในแคมเปญโทรออก
>
> Source: https://docs.ingfah.ai/guides/inbound-outbound/customer-template/

**เทมเพลตข้อมูลลูกค้า** คือชุดคอลัมน์ที่กำหนดไว้ล่วงหน้าว่าแคมเปญโทรออกต้องใช้ข้อมูลลูกค้าอะไรบ้าง เช่น เบอร์โทร ชื่อลูกค้า ยอดค้างชำระ เพื่อไม่ต้องตั้งค่าคอลัมน์ใหม่ทุกครั้งที่สร้างแคมเปญ

ข้อมูลในแต่ละคอลัมน์จะถูกนำไปเติมใน [{{ตัวแปร}}](/guides/ai-agent/flow-variables/) ที่ AI Agent ใช้พูดคุยกับลูกค้าขณะโทรออกจริง

## สร้างเทมเพลต

1. ไปที่ **สายออก** → **จัดการเทมเพลต**
2. กดสร้างเทมเพลตใหม่ แล้วตั้งชื่อเทมเพลต
3. เพิ่มคอลัมน์ที่ต้องการทีละรายการ
4. บันทึก

### การตั้งค่าแต่ละคอลัมน์

| ช่อง | รายละเอียด |
|------|-----------|
| **ชื่อคอลัมน์** | ชื่อที่ AI Agent จะอ้างถึง ควรใช้ภาษาอังกฤษ เช่น `customer_name` ใช้ได้เฉพาะ a-z, A-Z, 0-9, ก-ฮ, `_` และ `.` และห้ามซ้ำกับคอลัมน์อื่น |
| **ตัวอย่าง** | ค่าตัวอย่างของคอลัมน์นั้น เช่น `บุญรอด ปลอดภัย` ช่วยให้ AI เข้าใจรูปแบบข้อมูล |
| **จำเป็น** | ระบุว่าคอลัมน์นี้ต้องมีข้อมูลก่อน AI จะโทรออกหรือไม่ |

:::tip[นำเข้าคอลัมน์จากทีม AI Agent]
แทนที่จะพิมพ์เอง สามารถกด **นำเข้าคอลัมน์จากทีม AI Agent** เพื่อให้ระบบเติมคอลัมน์ตามข้อมูลที่ทีมนั้นใช้อยู่ให้อัตโนมัติ แล้วค่อยแก้ไขเพิ่มเติมภายหลังได้ คอลัมน์ที่เลือกจะถูกรวมเข้ากับคอลัมน์ที่ตั้งค่าไว้ก่อนหน้า
:::

## ดูรายละเอียดเทมเพลต

หน้ารายละเอียดจะแสดงชื่อเทมเพลต ผู้สร้าง ผู้แก้ไขล่าสุด และรายการคอลัมน์ทั้งหมดพร้อมตัวอย่าง และสามารถกด **ไฟล์ตัวอย่าง** เพื่อดาวน์โหลดไฟล์ตัวอย่างไปใช้เป็นแบบในการเตรียมรายชื่อลูกค้าได้

## ทำสำเนาเทมเพลต

เมนูจุดสามจุด → **ทำสำเนา** แล้วตั้งชื่อใหม่ ระบบจะคัดลอกคอลัมน์และตัวอย่างมาทั้งหมด **แต่จะไม่คัดลอกการเชื่อมต่อกับทีม AI Agent**

## ลบเทมเพลต

เมนูจุดสามจุด → **ลบเทมเพลต**

:::caution[ลบไม่ได้ถ้ายังมีทีมใช้อยู่]
หากมีทีม AI Agent กำลังใช้เทมเพลตนี้อยู่ ระบบจะไม่ยอมให้ลบและจะแสดงรายชื่อทีมที่ใช้งานอยู่ ต้องเปลี่ยนเทมเพลตของทีมเหล่านั้นก่อน การลบสำเร็จแล้วไม่สามารถกู้คืนได้
:::
