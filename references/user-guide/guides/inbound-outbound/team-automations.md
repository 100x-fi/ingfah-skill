# ตั้งค่าการทำงานอัตโนมัติของทีม AI Agent

> เลือกให้ทีมทำงานเมื่อเริ่ม ส่งต่อ หรือจบการสนทนา
>
> Source: https://docs.ingfah.ai/guides/inbound-outbound/team-automations/

ตั้งค่า Automation เพื่อให้ทีม AI Agent ทำงานเมื่อเริ่ม ส่งต่อ หรือจบการสนทนา ประเภท Automation ที่เลือกได้ขึ้นอยู่กับว่าเป็นทีมเสียงหรือทีมข้อความ

## เหมาะกับงานแบบไหน

ใช้เมื่อต้องส่งข้อมูลการสนทนาไปยังระบบขององค์กร หรือหยุดโทรออกไปยังเบอร์ที่ลูกค้าขอไม่ให้ติดต่ออีก

## เลือกประเภท Automation

### Webhook (http)

Webhook ส่งข้อมูลไปยัง URL ของระบบอื่นที่องค์กรใช้อยู่ เช่น ระบบ CRM เหมาะเมื่อทีมต้องแจ้งระบบนั้นว่าเริ่มสนทนา ส่งแชทให้เจ้าหน้าที่ หรือจบสนทนา ทีมเสียงเลือกใช้ได้เมื่อเริ่มหรือจบการสนทนา ส่วนทีมข้อความเลือกใช้ได้ทั้งเมื่อเริ่ม ส่งต่อให้เจ้าหน้าที่ และจบการสนทนา

ตัวอย่างเช่น ต้องการให้ CRM บันทึกผลการโทรหลังจบสาย ให้เพิ่ม Webhook ในส่วน **เมื่อจบการสนทนา** เลือกผลลัพธ์ที่ต้องการส่ง แล้วกรอก URL ปลายทางและข้อมูลที่ CRM ต้องการในช่องตั้งค่า ขอ URL และรูปแบบข้อมูลจากผู้ดูแล CRM ก่อนตั้งค่า หากไม่เลือกวิธีส่ง ระบบจะใช้ `POST`

### ห้ามโทรเบอร์นี้

ประเภทนี้ใช้ได้กับทีมเสียง ระบบจะนำเบอร์ของลูกค้าในสายไปใส่รายการ **ห้ามโทร** ขององค์กร เมื่อระบบจะโทรออกไปยังเบอร์นั้นในภายหลัง ระบบจะข้ามรายการดังกล่าว รวมถึงสายโทรกลับที่ยังรอโทรอยู่

ตัวอย่างเช่น ทีมโทรออกตั้งผลลัพธ์ **ไม่ต้องการให้ติดต่ออีก** ให้เพิ่ม Automation ประเภท **ห้ามโทรเบอร์นี้** ในส่วน **เมื่อจบการสนทนา** แล้วเลือกให้ทำงานเฉพาะผลลัพธ์นั้น วิธีนี้ช่วยให้ไม่ต้องจดเบอร์ไปจัดการเอง

ในช่อง `duration_days` ระบุจำนวนวันที่ต้องการห้ามโทร เช่น `30` สำหรับ 30 วัน โดยต้องเป็นอย่างน้อย 1 วัน หากเว้นว่าง ระบบจะห้ามโทรเบอร์นั้นโดยไม่กำหนดวันสิ้นสุด

## เพิ่ม Automation

1. เปิดเมนู **ทีม AI Agent** แล้วเลือกทีมที่ต้องการ
2. กดไอคอน **Automations** ข้างรายละเอียดทีม เพื่อดูรายการที่ตั้งค่าไว้ แต่ละส่วนแสดงช่วงที่ Automation จะทำงาน
3. กด **แก้ไข** แล้วกด **เพิ่ม Automation** ในส่วนที่ต้องการ เช่น **เมื่อจบการสนทนา**
4. เลือก **ประเภท Automation** แล้วกรอกค่าที่หน้าจอขอ หากมีช่องเงื่อนไข คุณสามารถเลือก **ทุกผลลัพธ์** หรือเลือกเฉพาะผลลัพธ์ที่ต้องการ
5. ตรวจสอบสถานะ **เปิดใช้งาน** แล้วกด **บันทึก** ที่หน้ารายละเอียดทีม

## ปิด แก้ไข หรือลบ

กด **แก้ไข** ก่อนเปลี่ยนรายการ ใช้สวิตช์เพื่อปิดหรือเปิด Automation ที่บันทึกไว้ จากนั้นกด **บันทึก** อีกครั้ง หากต้องเปลี่ยนประเภท ให้ลบรายการเดิมแล้วเพิ่มใหม่

หากรายการแสดงป้าย **เวอร์ชั่นเก่า** ให้ติดต่อทีมงานเพื่อแก้ไข หรือลบรายการนั้นแล้วตั้งค่าใหม่
