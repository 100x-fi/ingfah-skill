# ตั้งค่าโทรติดตามตามเวลาที่ลูกค้าขอ

> เปิดการโทรกลับในแคมเปญโทรออกและตรวจสอบสายที่รอโทรกลับ
>
> Source: https://docs.ingfah.ai/guides/inbound-outbound/follow-up-calls/

:::tip[ฟีเจอร์ใหม่: โทรกลับตามนัด]
เมื่อลูกค้าขอให้โทรกลับและระบุเวลา ระบบจะตรวจคำขอหลังจบสาย แล้วจัดคิวโทรตามเวลาที่ขอ คุณต้องเปิด **โทรกลับตามนัด** ใน Batch ก่อน
:::

## เหมาะกับงานแบบไหน

เหมาะกับแคมเปญโทรออกที่ลูกค้าอาจรับสายได้ แต่ยังไม่สะดวกคุย เช่น โทรเตือนนัดหมายแล้วลูกค้าขอให้โทรกลับพรุ่งนี้บ่ายสอง หากเปิดฟีเจอร์นี้และ Agent จับเวลานัดได้ ระบบจะจัดคิวโทรกลับตามเวลาที่ลูกค้าขอ

## เปิดการโทรกลับ

1. ไปที่ **สายออก** > **สร้าง Batch**
2. ในขั้นตอนอัปโหลด เปิด **โทรกลับตามนัด**
3. เลือกจำนวนครั้งที่จะโทรซ้ำหากลูกค้าไม่รับสายที่นัดไว้ เลือกได้ตั้งแต่ **ไม่โทรซ้ำ** ถึง 5 ครั้ง จำนวนนี้ไม่นับสายโทรกลับครั้งแรก
4. ในขั้นตอนตรวจสอบข้อมูล ดูว่าการตั้งค่าโทรกลับตรงตามที่ต้องการ แล้วกดยืนยันสร้าง Batch

เมื่อเปิดสวิตช์ ระบบเลือกให้โทรซ้ำอีก 1 ครั้งไว้ก่อน คุณเปลี่ยนเป็น **ไม่โทรซ้ำ** หรือจำนวนอื่นได้ก่อนยืนยัน Batch ตัวเลือกนี้ใช้กับลูกค้าแต่ละรายการใน Batch

## เมื่อใดระบบจะนัดโทรกลับ

ตั้งค่า AI Agent ให้ถามวันและเวลาที่ลูกค้าสะดวกให้โทรกลับ ระบบจะนัดเฉพาะเมื่อลูกค้าขอหรือยอมรับการโทรกลับ และมีเวลาที่ระบบอ่านได้ซึ่งอยู่ในอนาคต เช่น **“โทรกลับพรุ่งนี้บ่ายสอง”** หากลูกค้าพูดเพียง **“ไว้โทรมาใหม่”** โดยไม่บอกวันหรือเวลา ระบบจะไม่ได้นัดสายให้อัตโนมัติ

เวลาที่ขอต้องไม่เกิน 7 วันหลังสายที่ลูกค้าขอโทรกลับ และไม่เกิน 7 วันหลังวันสิ้นสุดช่วงโทรสุดท้ายของ Batch หากยกเลิก Batch ระบบจะไม่โทรสายที่ยังค้างอยู่

เวลาที่นัดคือเวลาที่สายพร้อมให้ระบบโทรออก การเริ่มโทรจริงอาจช้ากว่านั้นหากมีสายอื่นรออยู่

## การโทรซ้ำหลังสายที่นัด

**ไม่โทรซ้ำ** หมายถึงโทรตามนัด 1 ครั้ง หากเลือกโทรซ้ำ 2 ครั้ง ระบบโทรตามนัดได้รวมไม่เกิน 3 ครั้งต่อลูกค้าหนึ่งรายการ เมื่อสายโทรกลับไม่สำเร็จ ระบบรอ 5 นาทีก่อนลองใหม่ การโทรซ้ำนี้แยกจากการตั้งค่าโทรซ้ำทั่วไปของ Batch

หากลูกค้ารับสายโทรกลับและขอนัดใหม่ ระบบนัดได้อีกเมื่อยังเหลือจำนวนครั้งที่อนุญาต จำนวนครั้งที่เลือกจึงครอบคลุมทั้งการโทรซ้ำและการนัดโทรกลับครั้งถัดไปของลูกค้ารายเดียวกัน

## ดูรายการที่รอโทรกลับ

ไปที่ **สายออก** แล้วเลือกแท็บ **รอโทรกลับ** เพื่อดู Batch ที่เข้าสู่สถานะรอโทรกลับ หาก Batch ยังอยู่ระหว่างดำเนินการหรือหยุดชั่วคราว ให้เปิดจากแท็บสถานะนั้นแทน การเปิดฟีเจอร์ไว้เพียงอย่างเดียวไม่ได้ทำให้ Batch ย้ายมาแท็บ **รอโทรกลับ**

ในรายละเอียด Batch แถบความคืบหน้าแสดงจำนวนรายการที่รอโทรกลับ ตารางรายชื่อแสดงสถานะ **รอโทรกลับ** สำหรับลูกค้าที่ยังมีนัด วางเมาส์บนสถานะเพื่อดูเวลาที่จะโทรครั้งถัดไป หรือดูว่ารายการนั้นใช้สิทธิ์โทรกลับครบแล้ว ช่อง **ครั้งที่โทร** นับทั้งสายปกติและสายโทรกลับ และเปิดประวัติการโทรเพื่อดูแต่ละครั้งได้

หากดาวน์โหลดรีพอร์ต CSV ของ Batch ไฟล์จะแสดงจำนวนครั้งที่โทรกลับ และเวลาที่จะโทรครั้งถัดไปเมื่อรายการนั้นยังมีนัดรอโทร
