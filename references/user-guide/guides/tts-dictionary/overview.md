# ภาพรวม TTS Dictionary

> TTS Dictionary คือรายการคำศัพท์ที่บอก AI Agent ว่าต้องอ่านออกเสียงคำไหนอย่างไร
>
> Source: https://docs.ingfah.ai/guides/tts-dictionary/overview/

:::tip[ฟีเจอร์ใหม่: TTS Dictionary]
กำหนดคำอ่านของคำศัพท์ เช่น ชื่อแบรนด์ ชื่อสินค้า หรือคำย่อ แล้วเชื่อมกับทีม AI Agent เพื่อให้ AI Agent อ่านออกเสียงได้ถูกต้องตั้งแต่สายถัดไป
:::

**TTS Dictionary** (Text-to-Speech) คือรายการคำศัพท์ที่บอก AI Agent ว่าต้องอ่านออกเสียงคำไหนอย่างไร เช่น ให้อ่าน Ingfah ว่า “อิงฟ้า” เมื่อเชื่อม Dictionary กับทีม AI Agent แล้ว AI Agent ทุกตัวในทีมจะอ่านคำเหล่านั้นตามคำอ่านที่คุณกำหนดตั้งแต่สายถัดไป

## เหมาะกับงานแบบไหน

ใช้เมื่อ AI Agent ต้องอ่านชื่อเฉพาะหรือคำศัพท์ที่ต้องการการออกเสียงที่แม่นยำ เช่น ชื่อแบรนด์ ชื่อรุ่นสินค้า หรือคำย่อภาษาอังกฤษ หากทีมของคุณใช้คำเหล่านี้บ่อยครั้ง ให้เพิ่มคำศัพท์พร้อมคำอ่านไว้ใน Dictionary ชุดเดียว แล้วเชื่อมกับทีมเพียงครั้งเดียว AI Agent ทุกตัวในทีมจะใช้คำอ่านเดียวกัน โดยไม่ต้องแก้ Prompt ทีละตัว

## ทำงานอย่างไร

TTS Dictionary จะเปลี่ยนเฉพาะ**เสียงที่ลูกค้าได้ยิน** ส่วนข้อความที่ AI Agent ตอบและบันทึกการสนทนายังเป็นคำเดิม

ตัวอย่างด้านล่างแสดงการใช้คำอ่านจาก Dictionary สองชุดในคำตอบเดียว

| ขั้นตอน | ตัวอย่าง |
|---------|----------|
| AI Agent ตอบ | Ingfah เชื่อมกับ LINE OA และ CRM ได้ค่ะ |
| ใช้คำอ่านจาก Dictionary | Ingfah → อิงฟ้า (จาก “ชื่อแบรนด์และสินค้า”)<br>LINE OA → ไลน์โอเอ (จาก “ชื่อแบรนด์และสินค้า”)<br>CRM → ซีอาร์เอ็ม (จาก “คำย่อทั่วไป”) |
| ลูกค้าได้ยิน | **อิงฟ้า** เชื่อมกับ **ไลน์โอเอ** และ **ซีอาร์เอ็ม** ได้ค่ะ |
| บันทึกการสนทนา | Ingfah เชื่อมกับ LINE OA และ CRM ได้ค่ะ |

## ประเภทของ Dictionary

กรองดูได้จากตัวกรอง **ประเภท** ในหน้า TTS Dictionary โดยมี 2 ประเภท ได้แก่ **ของระบบ** และ **สร้างเอง**

| | ของระบบ | สร้างเอง |
|---|---------|----------|
| ใครสร้าง | ทีมงาน ingfah สร้างให้เมื่อคุณขอ | ผู้ใช้ในองค์กรของคุณ |
| เริ่มต้นใช้งาน | ยังไม่มีในบัญชี | สร้างได้ทันที |
| ตัวอย่าง | “คำย่อทั่วไป” | “ชื่อแบรนด์และสินค้า” |
| แก้ไขคำศัพท์ | ดูและส่งออก CSV ได้อย่างเดียว | เพิ่ม แก้ไข ลบ และนำเข้า CSV ได้ |
| เชื่อมกับทีม AI Agent | ✓ ได้ | ✓ ได้ |

:::note[ข้อควรรู้]
เมื่อเปิดหน้า TTS Dictionary ครั้งแรกจะยังไม่มี Dictionary ของระบบ ถ้าต้องการชุดคำที่ใช้กันทั่วไป เช่น คำย่อภาษาอังกฤษ ให้ติดต่อทีมงาน ingfah เพื่อขอเพิ่ม
:::

## เมื่อคำเดียวกันอยู่หลาย Dictionary

หากทีมเชื่อม Dictionary หลายชุดและมีคำศัพท์ซ้ำกัน ระบบใช้คำอ่านจากชุดที่เจอก่อนตามลำดับนี้

1. Dictionary ที่สร้างเอง โดยเริ่มจากชุดที่สร้างล่าสุด
2. Dictionary ของระบบ โดยเริ่มจากชุดที่สร้างล่าสุด
3. คำอ่านที่ทีมงาน ingfah ตั้งไว้ให้ทีมก่อนมีหน้า TTS Dictionary (ถ้ามี)

:::note[หมายเหตุ]
คุณเปลี่ยนลำดับนี้เองไม่ได้ หากต้องการให้ AI Agent อ่านต่างจาก Dictionary ของระบบ ให้เพิ่มคำนั้นใน Dictionary ที่สร้างเอง เช่น ถ้าชุด “คำย่อทั่วไป” อ่าน LINE OA ว่า “ไลน์ โอ เอ” แต่ชุด “ชื่อแบรนด์และสินค้า” ของคุณอ่านว่า “ไลน์โอเอ” ลูกค้าจะได้ยิน “ไลน์โอเอ”
:::

## ข้อจำกัด

| รายการ | สูงสุด |
|--------|--------|
| คำศัพท์ใน Dictionary หนึ่งชุด | 10,000 คำ |
| Dictionary ต่อทีม AI Agent <br>(นับรวม Dictionary ของระบบ) | 10 ชุด |
| ความยาวคำศัพท์และคำอ่าน | 1,000 ตัวอักษร |
| ความยาวชื่อ Dictionary | 100 ตัวอักษร |

หากเกินข้อจำกัดในตาราง ระบบจะระบุว่ารายการใดเกินกำหนด ผู้ใช้ต้องแก้ไขรายการนั้นก่อนจึงจะบันทึกได้

:::note[Dictionary กับ &lt;say-as&gt; ต่างกันอย่างไร]
Dictionary ใช้กับคำที่ต้องอ่านเหมือนเดิมทุกครั้งในทั้งทีม เช่น ชื่อแบรนด์ ส่วน [`<say-as>`](/guides/ai-agent/say-as-pronunciation/) ใช้กำหนดวิธีอ่านในข้อความแต่ละประโยคของ Prompt เช่น อ่านตัวเลขทีละหลัก
:::
