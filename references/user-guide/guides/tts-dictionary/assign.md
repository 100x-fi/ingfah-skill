# เชื่อม Dictionary กับทีม AI Agent

> เชื่อม Dictionary กับทีม AI Agent เพื่อให้ AI Agent ทุกตัวในทีมอ่านคำตามที่กำหนดตั้งแต่สายถัดไป
>
> Source: https://docs.ingfah.ai/guides/tts-dictionary/assign/

:::tip[ฟีเจอร์ใหม่: TTS Dictionary]
กำหนดคำอ่านของคำศัพท์ เช่น ชื่อแบรนด์ ชื่อสินค้า หรือคำย่อ แล้วเชื่อมกับทีม AI Agent เพื่อให้ AI Agent อ่านออกเสียงได้ถูกต้องตั้งแต่สายถัดไป
:::

เมื่อเชื่อม Dictionary กับทีม AI Agent แล้ว AI Agent ทุกตัวในทีมจะออกเสียงตามคำอ่านใน Dictionary ตั้งแต่สายถัดไป

Dictionary ชุดเดียวเชื่อมกับหลายทีมได้ เช่น เชื่อมชุด “ชื่อแบรนด์และสินค้า” กับทั้งทีมรับสายและทีมโทรออก แล้วเพิ่มชุด “คำเฉพาะของแคมเปญ” ให้เฉพาะทีมโทรออก

:::req[ก่อนเริ่ม]
- มี Dictionary อย่างน้อยหนึ่งชุด ดู[สร้าง Dictionary และเพิ่มคำศัพท์](/guides/tts-dictionary/create/)
- มี[ทีม AI Agent](/guides/inbound-outbound/create-ai-agent-team/)ที่จะใช้ Dictionary
:::

## เชื่อม Dictionary

การเชื่อม Dictionary กับทีม AI Agent ทำที่หน้าทีม AI Agent โดยเข้าได้ 2 ทาง

- **จากหน้า TTS Dictionary:** ในหัวข้อ **ทีม AI Agent ที่ใช้งาน** กดปุ่ม **ทีม AI Agent ↗** ระบบจะเปิดหน้าทีม AI Agent ให้

- **จากเมนู:** ไปที่ **ทีม AI Agent** แล้วเปิดทีมที่ต้องการ

จากนั้นทำตามขั้นตอนนี้

1. กด **แก้ไข** จากนั้นกดไอคอน **TTS Dictionary** (รูปหนังสือ) ที่แถบด้านขวา

2. เปิดสวิตช์ Dictionary ที่ต้องการ (เลือกได้สูงสุด 10 ชุด) จากนั้นกด **บันทึก**

ระบบจะแจ้งว่า “บันทึกทีมสำเร็จ” และแสดงชื่อทีมในส่วน **ทีม AI Agent ที่ใช้งาน** บนหน้าของ Dictionary ที่เลือก

:::note[ยังไม่มี Dictionary ให้เลือก]
หากหน้าต่างแสดงข้อความ “ไม่พบ Dictionary” ให้กด **ไปที่หน้า TTS Dictionary** เพื่อสร้าง Dictionary ชุดแรก จากนั้นกลับมาที่หน้าทีม AI Agent แล้วเลือกชุดที่สร้างไว้เพื่อเชื่อมกับทีม
:::

## ทดสอบหลังเชื่อม

- กด **ทดลอง** ในหน้าทีม AI Agent แล้วลองพูดให้ AI Agent ตอบด้วยประโยคที่มีคำศัพท์ใน Dictionary เพื่อตรวจสอบเสียงอ่าน

- สำหรับทีมโทรออก คุณสามารถใช้[ฟังตัวอย่างเสียงจากข้อมูลลูกค้า](/guides/inbound-outbound/speech-preview/)ในขั้นตอนที่ 3 ของการสร้างแคมเปญโทรออก ซึ่งจะใช้ Dictionary ของทีมเช่นกัน

:::note[สิ่งที่เกิดขึ้นหลังเชื่อม]
- AI Agent ทุกตัวในทีมใช้ Dictionary ที่เชื่อมกับทีมนั้น เพราะ AI Agent ตัวเดียวอาจอยู่ได้หลายทีม ระบบจึงกำหนด Dictionary แยกตามทีม
- การเชื่อมมีผลตั้งแต่สายถัดไป ส่วนสายที่กำลังสนทนาอยู่จะใช้การตั้งค่าเดิม
- บันทึกการสนทนาในหน้า [สาย/แชททั้งหมด](/guides/inbound-outbound/all-calls/) จะแสดงคำเดิมที่ AI Agent พิมพ์ เช่น “Ingfah”
- Dictionary ชุดเดียวเชื่อมได้หลายทีม เมื่อแก้ไขคำในชุดนั้น การแก้ไขจะมีผลกับทุกทีมที่เชื่อมอยู่
:::

## ถอด Dictionary ออกจากทีม

เปิดหน้าต่าง **TTS Dictionary** ในหน้าทีม AI Agent ปิดสวิตช์ของชุดที่ไม่ต้องการใช้ แล้วกด **บันทึก**<br>หากต้องการ[ลบ Dictionary](/guides/tts-dictionary/edit/) ให้ถอดชุดนั้นออกจากทุกทีมที่เชื่อมอยู่ก่อน
