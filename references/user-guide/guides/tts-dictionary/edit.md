# ค้นหา แก้ไขและลบ Dictionary

> ค้นหา แก้คำอ่าน ลบคำศัพท์ เปลี่ยนชื่อ หรือลบ Dictionary ทั้งชุด
>
> Source: https://docs.ingfah.ai/guides/tts-dictionary/edit/

:::tip[ฟีเจอร์ใหม่: TTS Dictionary]
กำหนดคำอ่านของคำศัพท์ เช่น ชื่อแบรนด์ ชื่อสินค้า หรือคำย่อ แล้วเชื่อมกับทีม AI Agent เพื่อให้ AI Agent อ่านออกเสียงได้ถูกต้องตั้งแต่สายถัดไป
:::

คุณสามารถแก้คำศัพท์และคำอ่านที่ยังไม่ถูกใจ รวมถึงลบคำที่ไม่ใช้แล้ว เปลี่ยนชื่อ Dictionary หรือลบ Dictionary ทั้งชุดได้ เช่น ลบชุด “คำเฉพาะของแคมเปญ” หลังแคมเปญจบ การแก้ไขมีผลกับทุกทีมที่เชื่อมกับ Dictionary นี้ตั้งแต่สายถัดไป

## ค้นหา Dictionary

ในหน้า **TTS Dictionary** ให้พิมพ์ชื่อ Dictionary คำศัพท์ หรือคำอ่านในช่องค้นหา และใช้ตัวกรองร่วมด้วยได้

- **ประเภท**: เลือก สร้างเอง, ของระบบ หรือเลือกทั้งสองประเภท
- **ทีม AI Agent**: เลือกทีมเพื่อดูเฉพาะ Dictionary ที่ทีมที่เลือกใช้

กด **รีเซ็ต** ข้างตัวกรองเพื่อล้างตัวกรองทั้งหมด

## แก้ไขคำศัพท์

1. เปิด Dictionary แล้วกดไอคอนดินสอท้ายแถวของคำที่ต้องการแก้ไข

2. แก้คำศัพท์หรือคำอ่าน แล้วกด **▶** เพื่อฟังและตรวจสอบว่าออกเสียงถูกต้อง จากนั้นกด **✓** เพื่อบันทึก

## ลบคำศัพท์

1. กดไอคอนถังขยะท้ายแถวของคำที่ต้องการลบ
2. ยืนยันการลบในหน้าต่างที่แสดงขึ้น

หลังลบแล้ว AI Agent จะใช้คำอ่านจาก Dictionary ชุดถัดไปที่มีคำนั้น หากไม่มีคำนั้นในชุดอื่น AI Agent จะออกเสียงตามปกติ

## เปลี่ยนชื่อ Dictionary

1. กดไอคอนดินสอข้างชื่อ Dictionary ด้านบน
2. แก้ไขชื่อตามต้องการ จากนั้นกด **✓**

## ลบ Dictionary

1. เปิด Dictionary แล้วกดเมนู **⋮** ที่มุมขวาบน จากนั้นเลือก **ลบ**

2. กด **ลบ Dictionary** ในหน้าต่างยืนยัน

:::caution[ลบแล้วกู้คืนไม่ได้]
เมื่อลบ Dictionary คำศัพท์ทั้งหมดในชุดจะถูกลบด้วย หากต้องการใช้คำศัพท์ชุดนี้อีก ให้[ส่งออก CSV](/guides/tts-dictionary/csv/) เก็บไว้ก่อนลบเสมอ
:::

### ถ้าลบไม่ได้เพราะมีทีมใช้อยู่

หาก Dictionary ยังเชื่อมกับทีม AI Agent ระบบจะแจ้งว่า ไม่สามารถลบได้ และแสดงรายชื่อทีมที่ใช้ Dictionary ชุดนั้น ให้[ถอด Dictionary ออกจากทีมเหล่านั้น](/guides/tts-dictionary/assign/)ก่อน แล้วกลับมาลบอีกครั้ง

:::note[Dictionary ของระบบแก้ไขไม่ได้]
Dictionary ของระบบแก้ไขไม่ได้ Dictionary ที่มีไอคอนสีฟ้าเป็นของระบบ จึงไม่มีปุ่มแก้ไข ลบ หรือนำเข้า หากต้องการเปลี่ยนคำอ่าน ให้เพิ่มคำศัพท์นั้นพร้อมคำอ่านที่ต้องการใน Dictionary ที่สร้างเอง เมื่อทั้งสองชุดมีคำเดียวกัน ระบบจะใช้คำอ่านจากชุดที่สร้างเองก่อนเสมอ
:::
