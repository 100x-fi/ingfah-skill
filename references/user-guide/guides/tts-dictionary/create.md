# สร้าง Dictionary และเพิ่มคำศัพท์

> สร้าง Dictionary ชุดใหม่ เพิ่มคำศัพท์และคำอ่าน พร้อมฟังเสียงที่ AI Agent อ่าน
>
> Source: https://docs.ingfah.ai/guides/tts-dictionary/create/

:::tip[ฟีเจอร์ใหม่: TTS Dictionary]
กำหนดคำอ่านของคำศัพท์ เช่น ชื่อแบรนด์ ชื่อสินค้า หรือคำย่อ แล้วเชื่อมกับทีม AI Agent เพื่อให้ AI Agent อ่านออกเสียงได้ถูกต้องตั้งแต่สายถัดไป
:::

สร้างและตั้งชื่อ Dictionary จากนั้นเพิ่มคำศัพท์พร้อมคำอ่านทีละคำ คุณสามารถกดฟังตัวอย่างเสียงของแต่ละคำเพื่อดูว่า AI Agent จะออกเสียงอย่างไร แล้วปรับคำอ่านได้ตามต้องการ วิธีนี้เหมาะกับการเพิ่มหรือแก้ไขคำศัพท์ไม่กี่คำ

หากต้องการเพิ่มคำศัพท์จำนวนมาก ให้ใช้วิธี [การนำเข้า CSV](/guides/tts-dictionary/csv/) เพื่อเพิ่มหลายคำพร้อมกัน

:::req[ก่อนเริ่ม]
- ผู้ใช้ในองค์กรของคุณสร้างและแก้ไข Dictionary ได้เอง โดยไม่ต้องติดต่อทีมงาน ingfah
- เตรียมรายการคำที่ต้องการให้ AI Agent ออกเสียงให้ถูกต้อง
- ตั้งชื่อ Dictionary ตามกลุ่มคำหรืองาน เช่น “ชื่อแบรนด์และสินค้า” หรือ “คำเฉพาะของแคมเปญ” เพื่อให้เลือกเชื่อมกับทีมได้ง่าย
:::

## สร้าง Dictionary

1. ไปที่ **ทีม AI Agent** > **TTS Dictionary**

2. กด **เพิ่ม Dictionary** ที่มุมขวาบน

3. ใส่ชื่อ Dictionary ที่ต้องการ เช่น `ชื่อแบรนด์และชื่อรุ่นสินค้า` (ไม่เกิน 100 ตัวอักษร และต้องไม่ซ้ำกับชุดที่มีอยู่) จากนั้นกด **บันทึก**

ระบบจะสร้าง Dictionary `ชื่อแบรนด์และชื่อรุ่นสินค้า` และเปิดส่วน **ทีม AI Agent ที่ใช้งาน** และ **ตั้งค่าการออกเสียง** ให้ใช้ต่อในหน้าเดิม ถ้าออกจากหน้านี้ก่อนกดบันทึก Dictionary นี้ จะไม่ถูกสร้าง

## เพิ่มคำศัพท์

1. ในส่วน **ตั้งค่าการออกเสียง** กด **+ เพิ่ม** ใต้ตาราง

2. ในช่อง **คำศัพท์** ให้ใส่คำที่ต้องการกำหนดคำอ่าน เช่น `Ingfah` ส่วนช่อง **คำอ่าน** ให้ใส่คำอ่านที่ต้องการให้ระบบออกเสียง เช่น `อิงฟ้า`

3. กดปุ่ม ▶ ท้ายคำเพื่อฟังเสียงอ่าน จากนั้นกด ✓ เพื่อบันทึก หรือกด ✕ เพื่อยกเลิก

คำที่บันทึกแล้วจะแสดงในตารางพร้อมเวลาในคอลัมน์ **แก้ไขล่าสุด** เมื่อชี้ที่ไอคอนข้างเวลา ระบบจะแสดงอีเมลของผู้ที่แก้ไขคำนั้นล่าสุด

:::caution[คำศัพท์ซ้ำในชุดเดียวกันไม่ได้]
ถ้าคำศัพท์มีอยู่ใน Dictionary นี้แล้ว ระบบจะแจ้ง “คำศัพท์ถูกใช้ไปแล้ว” ให้แก้คำเดิมแทนการเพิ่มใหม่
:::

## ฟังเสียงด้วยเสียงอื่น

คำอ่านเดียวกันอาจฟังต่างกันเล็กน้อยในแต่ละเสียง เลือกเสียงที่ทีมใช้จริงจากเมนู **ทดสอบเสียง** เหนือตาราง แล้วกดปุ่ม ▶ ในแถวคำศัพท์ที่ต้องการฟัง

:::tip[เขียนคำอ่านให้ได้เสียงที่ต้องการ]
- เขียนตามเสียงที่ได้ยินจริงเป็นภาษาไทย เช่น `Ingfah` → `อิงฟ้า`
- คำย่อที่อ่านทีละตัว ให้เขียนเสียงแต่ละตัวต่อกัน เช่น `CRM` → `ซีอาร์เอ็ม`
- กดฟังเสียงหลังแก้คำอ่านทุกครั้ง หากเสียงยังไม่เป็นธรรมชาติ ให้ลองปรับวรรณยุกต์หรือแยกพยางค์
:::
