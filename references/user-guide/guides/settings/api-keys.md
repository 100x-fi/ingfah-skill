# API Keys

> สร้างและจัดการ API Key สำหรับเชื่อมต่อระบบภายนอกเข้ากับแพลตฟอร์มอิงฟ้า
>
> Source: https://docs.ingfah.ai/guides/settings/api-keys/

**API Key** ใช้สำหรับให้ระบบภายนอกหรือเครื่องมือของคุณเรียกใช้งานแพลตฟอร์มอิงฟ้าผ่าน API เช่น ดึงข้อมูลแคมเปญโทรออก สร้าง AI Agent หรือเชื่อมกับผู้ช่วย AI อย่าง Claude / ChatGPT

## สร้าง API Key

1. ล็อกอินที่ https://ingfah.ai/login
2. เมนูด้านซ้าย → **การตั้งค่า** → **API Keys**
3. กด **สร้าง API Key**
4. ตั้งชื่อให้สื่อความหมายว่าใช้ที่ไหน เช่น `Production Key` หรือ `Claude Desktop`
5. กด **สร้าง**
6. ระบบจะแสดง API Key ขึ้นมา กด **คัดลอก** แล้วเก็บไว้ในที่ปลอดภัย

API Key ที่สร้างใหม่จะได้รับ **สิทธิ์การเข้าถึงเต็มรูปแบบ** ของบัญชีคุณ

:::danger[API Key แสดงเพียงครั้งเดียว]
หลังปิดหน้าต่างไปแล้วจะไม่สามารถดูค่าเดิมได้อีก หากทำหายต้องสร้างใหม่แล้วลบอันเก่าทิ้ง

API Key เปรียบเสมือนรหัสผ่าน **ห้ามส่งต่อให้ผู้อื่น** ห้ามฝังไว้ในโค้ดฝั่งหน้าเว็บ และห้ามโพสต์ในที่สาธารณะ
:::

## ตารางรายการ API Key

| คอลัมน์ | ความหมาย |
|---------|----------|
| ชื่อ API Key | ชื่อที่คุณตั้งไว้ |
| Prefix | ตัวอักษรขึ้นต้นของ Key ใช้ระบุว่าเป็น Key ตัวไหน โดยไม่ต้องเปิดเผยค่าเต็ม |
| สร้างเมื่อ | วันที่สร้าง |
| การดำเนินการ | แก้ไขชื่อ หรือ ลบ |

## แก้ไขชื่อ

กดไอคอนแก้ไขที่แถวนั้น เปลี่ยนชื่อแล้วกด **บันทึก** — การแก้ไขชื่อไม่กระทบค่า API Key เดิม ระบบที่เชื่อมต่ออยู่ยังทำงานต่อได้ตามปกติ

## ลบ API Key

กดไอคอนลบที่แถวนั้น แล้วยืนยัน

:::caution[ระบบที่ใช้ Key นี้จะใช้งานไม่ได้ทันที]
เมื่อลบแล้วจะไม่สามารถกู้คืนได้ และทุกระบบที่ใช้ Key นี้อยู่จะเรียก API ไม่ผ่านทันที ควรตรวจสอบก่อนว่าไม่มีระบบใดใช้งานอยู่
:::

## แนวปฏิบัติที่แนะนำ

- แยก Key ตามการใช้งาน เช่น หนึ่ง Key ต่อหนึ่งระบบ เพื่อให้เพิกถอนเฉพาะจุดได้
- ตั้งชื่อ Key ให้รู้ว่าใครหรือระบบไหนใช้
- หมุนเวียนเปลี่ยน Key เป็นระยะ โดยสร้างอันใหม่ก่อน เปลี่ยนที่ระบบปลายทาง แล้วค่อยลบอันเก่า
- ลบ Key ทันทีเมื่อเลิกใช้ หรือเมื่อสงสัยว่าหลุดออกไป
