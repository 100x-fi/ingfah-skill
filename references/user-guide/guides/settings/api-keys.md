# API Keys

> สร้างและจัดการ API Key สำหรับเชื่อมต่อระบบภายนอกเข้ากับแพลตฟอร์มอิงฟ้า พร้อมกำหนดสิทธิ์ (scopes) และวันหมดอายุ
>
> Source: https://docs.ingfah.ai/guides/settings/api-keys/

:::tip[ฟีเจอร์ใหม่: สิทธิ์และวันหมดอายุของ API Key]
ตอนสร้าง Key เลือกได้ว่าให้เข้าถึงอะไรบ้าง และจะหมดอายุเมื่อไหร่ รวมถึงค้นหาและกรอง Key ที่หมดอายุแล้วได้จากตาราง
:::

**API Key** ใช้สำหรับให้ระบบภายนอกหรือเครื่องมือของคุณเรียกใช้งานแพลตฟอร์มอิงฟ้าผ่าน API เช่น ดึงข้อมูลแคมเปญโทรออก สร้าง AI Agent หรือเชื่อมกับผู้ช่วย AI อย่าง Claude / ChatGPT

## สร้าง API Key

1. ล็อกอินที่ https://ingfah.ai/login
2. เมนูด้านซ้าย → **การตั้งค่า** → **API Keys**
3. กด **สร้าง API Key**
4. ตั้งชื่อให้สื่อความหมายว่าใช้ที่ไหน เช่น `Production Key` หรือ `Claude Desktop`
5. เลือก **Scopes** (สิทธิ์) อย่างน้อย 1 รายการ
   - เลือก `*` เมื่อต้องการสิทธิ์เต็มของบัญชี
   - หรือเลือกเฉพาะ scope ที่ระบบปลายทางต้องใช้ เช่น อ่านแชทหรืออ่านสาย
6. เลือก **วันหมดอายุ** — 30 วัน / 60 วัน / 90 วัน / 1 ปี / ไม่มีวันหมดอายุ (ค่าเริ่มต้น 90 วัน)
7. กด **สร้าง**
8. ระบบจะแสดง API Key ขึ้นมา กด **คัดลอก** แล้วเก็บไว้ในที่ปลอดภัย

ถ้าคุณเปิด [2FA](/guides/account-settings/two-factor/) ไว้ ระบบจะขอรหัส 6 หลักก่อนสร้าง Key

:::danger[API Key แสดงเพียงครั้งเดียว]
หลังปิดหน้าต่างไปแล้วจะไม่สามารถดูค่าเดิมได้อีก หากทำหายต้องสร้างใหม่แล้วลบอันเก่าทิ้ง

API Key เปรียบเสมือนรหัสผ่าน **ห้ามส่งต่อให้ผู้อื่น** ห้ามฝังไว้ในโค้ดฝั่งหน้าเว็บ และห้ามโพสต์ในที่สาธารณะ
:::

:::note[วันหมดอายุแก้ภายหลังไม่ได้]
เลือกวันหมดอายุตอนสร้างเท่านั้น หลังสร้างแล้วเปลี่ยนได้แค่ชื่อและ scopes
:::

## ตารางรายการ API Key

| คอลัมน์ | ความหมาย |
|---------|----------|
| ชื่อ API Key | ชื่อที่คุณตั้งไว้ |
| Prefix | ตัวอักษรขึ้นต้นของ Key ใช้ระบุว่าเป็น Key ตัวไหน โดยไม่ต้องเปิดเผยค่าเต็ม |
| สร้างโดย | บัญชีที่สร้าง Key (ถ้ามี) |
| สร้างเมื่อ | วันที่สร้าง |
| หมดอายุ | วันหมดอายุ หรือข้อความว่าไม่มีวันหมดอายุ Key ที่หมดแล้วมีป้าย **หมดอายุแล้ว** |
| การดำเนินการ | แก้ไข หรือ ลบ |

### ค้นหาและกรอง

- **ค้นหา** — ค้นหาจากชื่อหรือ prefix
- **สถานะ** — ใช้งานได้ / หมดอายุแล้ว / ทั้งหมด
- **รีเซ็ต** — ล้างตัวกรอง

## แก้ไขชื่อและ scopes

กดไอคอนแก้ไขที่แถวนั้น

- เปลี่ยน**ชื่อ**ได้เสมอ — ไม่กระทบค่า API Key เดิม ระบบที่เชื่อมต่ออยู่ยังทำงานต่อได้
- เปลี่ยน**Scopes** ได้ — เลือกสิทธิ์ใหม่แล้วบันทึก ถ้าเปิด 2FA ไว้ระบบจะขอรหัสก่อนอัปเดต scopes

## ลบ API Key

กดไอคอนลบที่แถวนั้น แล้วพิมพ์ `delete` เพื่อยืนยัน

:::caution[ระบบที่ใช้ Key นี้จะใช้งานไม่ได้ทันที]
เมื่อลบแล้วจะไม่สามารถกู้คืนได้ และทุกระบบที่ใช้ Key นี้อยู่จะเรียก API ไม่ผ่านทันที ควรตรวจสอบก่อนว่าไม่มีระบบใดใช้งานอยู่
:::

## แนวปฏิบัติที่แนะนำ

- แยก Key ตามการใช้งาน เช่น หนึ่ง Key ต่อหนึ่งระบบ เพื่อให้เพิกถอนเฉพาะจุดได้
- ให้ scopes แคบที่สุดที่ระบบปลายทางยังทำงานได้ อย่าเลือก `*` นอกจากจำเป็น
- ตั้งวันหมดอายุสำหรับ Key ที่ใช้กับผู้ช่วย AI หรืองานทดลอง แล้วหมุนเวียนก่อนหมดอายุ
- ตั้งชื่อ Key ให้รู้ว่าใครหรือระบบไหนใช้
- ลบ Key ทันทีเมื่อเลิกใช้ หรือเมื่อสงสัยว่าหลุดออกไป

## นำ API Key ไปใช้ต่อ

ดูวิธีให้ผู้ช่วย AI อย่าง Claude หรือ ChatGPT ใช้งานอิงฟ้าผ่าน API Key ได้ที่ [(Beta) Skill ingfah](/guides/ingfah-skill/overview/) และเอกสารสำหรับนักพัฒนาที่ [developers.ingfah.ai](https://developers.ingfah.ai)
