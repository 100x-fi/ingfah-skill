# ประวัติการใช้งาน (Activity Logs)

> ตรวจสอบว่าใครทำอะไรในระบบเมื่อไหร่ สำหรับงานตรวจสอบภายใน
>
> Source: https://docs.ingfah.ai/guides/settings/activity-logs/

หน้า **ประวัติการใช้งาน** บันทึกการกระทำสำคัญของผู้ใช้ในบัญชีของคุณ ใช้ตรวจสอบย้อนหลังว่าใครเป็นคนแก้ไขอะไร เมื่อไหร่ เหมาะกับงานตรวจสอบภายในและการสอบทานตามข้อกำหนด

:::note[เฉพาะสิทธิ์ Owner]
เฉพาะผู้ใช้สิทธิ์ **Owner** เท่านั้นที่เห็นและเข้าใช้งานเมนูนี้ได้
:::

## ข้อมูลในตาราง

| คอลัมน์ | ความหมาย |
|---------|----------|
| วันที่ | วันและเวลาที่เกิดการกระทำ |
| ผู้ใช้งาน | บัญชีผู้ใช้ที่ทำรายการ |
| ประเภทการใช้งาน | การกระทำที่เกิดขึ้น เช่น การสร้าง แก้ไข หรือลบข้อมูล |
| ข้อมูลที่เกี่ยวข้อง | รายการหรือข้อมูลที่ถูกกระทำในครั้งนั้น |

## การกรองข้อมูล

- **วันที่แสดงผล** — เลือกช่วงวันที่ พร้อมระบุเวลาเริ่มต้นและเวลาสิ้นสุดได้
- **ตัวกรองด่วน** — วันนี้ / เมื่อวาน / 7 วันล่าสุด / สัปดาห์นี้ / เดือนนี้
- **ค้นหา** — ค้นหาจากข้อมูลในตาราง
- **รีเซ็ต** — ล้างตัวกรองทั้งหมด

:::tip
หากต้องการหลักฐานการตรวจสอบเป็นทางการ หรือต้องการดึงประวัติย้อนหลังเป็นไฟล์ กรุณาติดต่อทีมงานอิงฟ้า
:::
