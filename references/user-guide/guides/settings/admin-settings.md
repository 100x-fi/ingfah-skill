# การตั้งค่าแอดมิน

> หน้า ตั้งค่าแอดมิน ใช้ดูแลรายชื่อแอดมินขององค์กร สิทธิ์ Owner เพิ่ม แก้ไข และลบแอดมินได้เอง ไม่ต้องรอทีม ingfah เหมาะเมื่อมีคนเข้ามาทำงาน...
>
> Source: https://docs.ingfah.ai/guides/settings/admin-settings/

:::tip[ฟีเจอร์ใหม่: การตั้งค่าแอดมิน]
ดูแลรายชื่อแอดมินขององค์กรได้ในหน้าเดียว ทั้งเพิ่ม แก้ไข และลบแอดมิน
:::

หน้า **ตั้งค่าแอดมิน** ใช้ดูแลรายชื่อแอดมินขององค์กร สิทธิ์ **Owner** เพิ่ม แก้ไข และลบแอดมินได้เอง ไม่ต้องรอทีม ingfah เหมาะเมื่อมีคนเข้ามาทำงานใหม่ ย้ายทีม หรือต้องการให้คนนอกทีมเข้ามาดูข้อมูลชั่วคราวด้วยสิทธิ์ **Guest** ส่วนสิทธิ์ **Operator** และ **Security** เปิดดูรายชื่อได้อย่างเดียว

## ใครทำอะไรได้ {#ad-roles}

| สิทธิ์ | ดูรายชื่อแอดมิน | เพิ่ม แก้ไข และลบแอดมิน |
| --- | --- | --- |
| Owner | ✓ ได้ | ✓ ได้ |
| Operator | ✓ ได้ | ✕ ไม่ได้ ไม่มีปุ่ม **เพิ่มแอดมิน** |
| Security | ✓ ได้ | ✕ ไม่ได้ ไม่มีปุ่ม **เพิ่มแอดมิน** |

ดูว่าแต่ละสิทธิ์เข้าถึงอะไรได้บ้างที่[สิทธิ์ผู้ใช้งาน](/guides/settings/user-roles/)

## อ่านตารางรายชื่อ {#ad-list}

| คอลัมน์ | แสดงอะไร |
| --- | --- |
| อีเมล | อีเมลที่ใช้เข้าสู่ระบบ แถวของคุณมีป้าย **คุณ** กำกับ |
| ชื่อ | ชื่อแอดมินที่ตั้งตอนเพิ่ม |
| สิทธิ์ | Owner, Operator หรือ Security และมีป้าย **Guest** เพิ่มถ้าเป็นผู้ใช้ชั่วคราว |
| 2FA | เครื่องหมายถูกสีเขียว ✓ เมื่อเปิดใช้งาน 2FA แล้ว |
| Passkey | จำนวน Passkey ที่เพิ่มไว้ |
| เข้าสู่ระบบล่าสุด | วันและเวลาที่เข้าสู่ระบบครั้งล่าสุด |

พิมพ์ชื่อหรืออีเมลที่ช่องค้นหา หรือเลือกตัวกรอง **สิทธิ์** และ **2FA** เพื่อหาแอดมินที่ต้องการ กด **รีเซ็ต** เพื่อล้างตัวกรองทั้งหมด ถ้าไม่พบรายการ ระบบแสดง “ไม่พบแอดมินที่ตรงกับ” คำที่ค้นหา หรือ “ไม่พบแอดมินที่ตรงกับตัวกรอง”

## วิธีการเพิ่มแอดมิน {#ad-add}

1. ไปที่ **การตั้งค่า** > **ตั้งค่าแอดมิน** ที่แถบเมนูด้านซ้าย
2. กด **+ เพิ่มแอดมิน** มุมขวาบนของตาราง ระบบแสดงจำนวนแอดมินปัจจุบันเทียบกับจำนวนสูงสุดของบัญชี เช่น `บัญชีแอดมิน 3/10`
3. ช่อง **อีเมล** กรอกอีเมลของแอดมินใหม่ อีเมลแก้ไขภายหลังไม่ได้ ตรวจให้ถูกต้องก่อนบันทึก
4. ช่อง **ชื่อแอดมิน** กรอกชื่อที่ต้องการให้แสดงในตาราง เช่น ชื่อทีมหรือชื่อคน
5. ช่อง **สิทธิ์** เลือกสิทธิ์ที่ให้ ถ้าไม่แน่ใจ กดไอคอน ? ข้างคำว่าสิทธิ์เพื่อดูคำอธิบายแต่ละสิทธิ์
6. กด **+ เพิ่มแอดมิน** ปุ่มจะกดได้เมื่อกรอกอีเมลและชื่อครบ
7. ถ้าคุณเปิด [2FA](/guides/account-settings/two-factor/) ไว้ กรอกรหัส 6 หลักจากแอปในหน้าต่าง **ยืนยันตัวตนด้วย 2FA** แล้วกด **ยืนยัน**

:::note[ครบจำนวนแอดมินสูงสุด]
เมื่อถึงจำนวนสูงสุดของบัญชี ปุ่มเพิ่มจะกดไม่ได้และระบบบอกว่าสูงสุดกี่คน หากต้องการเพิ่มโควตา ติดต่อทีมงานอิงฟ้า
:::

ระบบแจ้ง “เพิ่มแอดมินเรียบร้อย” แอดมินใหม่ขึ้นในตารางทันที และแผงด้านขวาแสดงรายละเอียดของแอดมินคนนั้น

<!-- TODO ภาพ: แอดมินใหม่หลังเพิ่มสำเร็จ — แถวใหม่ในตาราง แผงรายละเอียดแอดมิน และข้อความ เพิ่มแอดมินเรียบร้อย มุมขวาล่าง -->

แอดมินใหม่ได้รับอีเมลที่มีรหัสผ่านสำหรับเข้าสู่ระบบครั้งแรก และต้องตั้งรหัสผ่านใหม่เองตอนเข้าสู่ระบบ ภาษาของอีเมลเป็นภาษาเดียวกับหน้าจอที่คุณใช้ตอนกดเพิ่ม

:::note[เพิ่มแอดมินไม่ได้ในบางกรณี]
- ระบบไม่เพิ่มอีเมลที่เป็นแอดมินของ client ใด ๆ อยู่แล้ว
- ระบบไม่เพิ่มอีเมลที่ยังมีสิทธิ์ Guest ที่ยังไม่หมดอายุ ให้ยกเลิกสิทธิ์ Guest ก่อนแล้วลองใหม่
- อีเมลที่เป็น Guest ที่หมดอายุแล้วเพิ่มเป็นแอดมินได้
:::

## เพิ่มเป็น Guest (ผู้ใช้งานชั่วคราว) {#ad-guest}

ใช้เมื่อต้องการให้คนนอกทีมเข้ามาดูข้อมูลเป็นช่วงเวลาสั้น ๆ เช่น ผู้ตรวจสอบหรือที่ปรึกษา ระบบส่งลิงก์เข้าสู่ระบบชั่วคราวไปที่อีเมลของ Guest และตัดการเข้าสู่ระบบเมื่อครบเวลา

1. ในแผง **เพิ่มแอดมิน** กรอกอีเมล ชื่อ และสิทธิ์ตามปกติ
2. กด **การตั้งค่าเพิ่มเติม** แล้วเปิดสวิตช์ **กำหนดสิทธิ์เป็น Guest**
3. ช่อง **ระยะเวลา** พิมพ์จำนวนนาที ค่าเริ่มต้นคือ 60 นาที หรือกดปุ่มลัด 1, 2, 6, 12 หรือ 24 ชั่วโมง
4. ตรวจวันและเวลาที่สิทธิ์หมดอายุในกล่องสีฟ้าใต้ช่องระยะเวลา
5. กด **+ เพิ่มแอดมิน** แล้วยืนยันด้วยรหัส [2FA](/guides/account-settings/two-factor/) ถ้าเปิดไว้

<!-- TODO ภาพ: ตั้งค่า Guest ในแผงเพิ่มแอดมิน — สวิตช์ กำหนดสิทธิ์เป็น Guest ช่องระยะเวลา ปุ่มลัดเลือกชั่วโมง และข้อความบอกเวลาที่หมดอายุ -->

:::note[ลิงก์ Guest ใช้ได้นานสุด 24 ชั่วโมง]
ถ้าต้องการให้ Guest คนเดิมเข้าได้อีกหลังหมดเวลา ให้เพิ่มสิทธิ์ใหม่อีกครั้งหลังสิทธิ์เดิมหมดอายุหรือถูกลบ
:::

## วิธีการแก้ไขแอดมิน {#ad-edit}

1. กดแถวของแอดมินที่ต้องการ แผงรายละเอียดจะเปิดทางขวา
2. กด **แก้ไข** มุมขวาบนของแผง
3. แก้ **ชื่อแอดมิน** หรือ **สิทธิ์** ช่องอีเมลแก้ไม่ได้
4. กด **บันทึกการแก้ไข** แล้วยืนยันด้วยรหัส [2FA](/guides/account-settings/two-factor/) ถ้าเปิดไว้

<!-- TODO ภาพ: แผงแก้ไขแอดมิน — ช่องอีเมลที่แก้ไม่ได้ ช่องชื่อแอดมินและสิทธิ์ พร้อมปุ่ม ลบแอดมิน และ บันทึกการแก้ไข -->

ระบบบันทึกการแก้ไข และแผงรายละเอียดแสดงข้อมูลล่าสุดของแอดมินคนนั้น

## วิธีการลบแอดมิน {#ad-delete}

1. เปิดแผงแก้ไขของแอดมินที่ต้องการลบ ตามขั้นตอนใน[วิธีการแก้ไขแอดมิน](/guides/settings/admin-settings/)
2. กด **ลบแอดมิน** มุมซ้ายล่างของแผง
3. อ่านข้อความเตือน แล้วกด **ลบแอดมิน** สีแดง
4. พิมพ์คำว่า `delete` ในช่องยืนยัน แล้วกด **ลบแอดมิน** อีกครั้ง
5. กรอกรหัส 6 หลักในหน้าต่าง **ยืนยันตัวตนด้วย 2FA** แล้วกด **ยืนยัน** ถ้าเปิด [2FA](/guides/account-settings/two-factor/) ไว้

<!-- TODO ภาพ: หน้าต่างพิมพ์ delete เพื่อยืนยัน — ช่องให้พิมพ์คำว่า delete ปุ่ม ลบแอดมิน จะกดได้เมื่อพิมพ์ครบ -->

ระบบแจ้ง “ลบแอดมินเรียบร้อย” และแอดมินคนนั้นหายจากตารางทันที

:::caution[ลบแล้วกู้คืนไม่ได้]
ถ้าต้องการให้คนนั้นกลับมาใช้งาน ให้เพิ่มแอดมินใหม่ตามขั้นตอนด้านบน
:::

## Guest ที่หมดอายุ {#ad-expired}

เมื่อครบเวลา แถวของ Guest จะมีป้ายเหลือง **บัญชีหมดอายุ** ข้างอีเมล และข้อความในแถวเป็นสีจาง Guest เข้าสู่ระบบอีกไม่ได้ แต่รายชื่อยังอยู่ในตารางจนกว่าคุณจะลบ

<!-- TODO ภาพ: แถวของ Guest ที่หมดอายุ — แถวที่มีป้าย บัญชีหมดอายุ สีเหลือง และป้าย Guest ในคอลัมน์สิทธิ์ -->

ลบแถวนี้ได้โดยกดแถว แล้วกด **ลบแอดมิน** มุมขวาบนของแผงรายละเอียด และกด **ลบแอดมิน** ในหน้าต่างยืนยัน

## มุมมองของ Operator และ Security {#ad-view}

สองสิทธิ์นี้เห็นรายชื่อแอดมินทั้งหมด ค้นหาและกรองได้เหมือนกัน แต่ไม่มีปุ่ม **+ เพิ่มแอดมิน** จึงเพิ่ม แก้ไข และลบแอดมินไม่ได้ ถ้าต้องการเปลี่ยนแปลง ให้ขอ Owner ขององค์กร

<!-- TODO ภาพ: หน้าตั้งค่าแอดมินของ Operator และ Security — ตารางรายชื่อที่ไม่มีปุ่ม เพิ่มแอดมิน มุมขวาบน -->

:::note[ข้อจำกัด]
- องค์กรหนึ่งเพิ่มแอดมินเองได้สูงสุด 20 คน ไม่นับ Guest
- อีเมลหนึ่งเป็นแอดมินได้ในองค์กรเดียว ตัวพิมพ์เล็กใหญ่นับเป็นอีเมลเดียวกัน
- ทุกครั้งที่เพิ่ม แก้ไข หรือลบ ระบบขอรหัส [2FA](/guides/account-settings/two-factor/) ถ้า Owner ที่ทำรายการเปิดไว้ ผิดครบ 5 ครั้งติดกันจะถูกล็อก 15 นาที
:::
