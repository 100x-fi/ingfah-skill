# Secrets

> เก็บคีย์และรหัสของระบบภายนอกแบบเข้ารหัส แล้วนำไปใส่ใน Tool หรือ Automation โดยไม่ฝังค่าจริงในหน้าจอ
>
> Source: https://docs.ingfah.ai/guides/settings/secrets/

:::tip[ฟีเจอร์ใหม่: Secrets]
เก็บค่าความลับของระบบภายนอกไว้ที่อิงฟ้า แล้วอ้างอิงด้วย `{{ secrets.NAME }}` ใน Tool และ Automation
:::

หน้า **Secrets** ใช้เก็บค่าที่เป็นความลับ เช่น API Key ของระบบ CRM หรือโทเคนของบริการภายนอก ค่าจะถูกเข้ารหัสไว้ที่ระบบของอิงฟ้า และมีเฉพาะบัญชีประเภท **Owner** ภายใต้บริษัทของคุณที่เข้าถึงและแก้ไขได้

## เหมาะกับงานแบบไหน

ใช้เมื่อ Tool หรือ Automation ต้องเรียกระบบภายนอกที่ต้องการคีย์หรือรหัสผ่าน แต่คุณไม่ต้องการพิมพ์ค่าจริงลงในช่องพารามิเตอร์ทุกครั้ง หรือไม่ต้องการให้ค่าไปโผล่ในหน้าจอของคนที่ไม่มีสิทธิ์ Owner

## เปิดหน้า Secrets

1. ล็อกอินที่ https://ingfah.ai/login
2. เมนูด้านซ้าย → **การตั้งค่า** → **Secrets**

## อ่านตาราง Secrets

| คอลัมน์ | ความหมาย |
|---------|----------|
| ชื่อตัวแปร | ชื่อที่ใช้ในสูตร `{{ secrets.NAME }}` |
| ค่าตัวแปร | ค่าที่ซ่อนไว้เป็นจุดไข่ปลา กดไอคอนตาเพื่อแสดง หรือกดคัดลอกได้ |
| แก้ไขล่าสุด | วันและเวลาที่แก้ค่าล่าสุด |

สร้างได้สูงสุด **1,000** Secrets

## เพิ่ม Secret

1. กด **เพิ่ม Secret**
2. ช่อง **ชื่อตัวแปร** ตั้งชื่อ เช่น `CRM_API_KEY` — ใช้ได้เฉพาะ A–Z, a–z, 0–9 และ `_` ต้องขึ้นต้นด้วยตัวอักษร และยาวไม่เกิน 100 ตัวอักษร
3. ช่อง **ค่าตัวแปร** ใส่ค่าจริง ความยาวไม่เกิน 8,192 bytes
4. กด **เพิ่ม Secret**

ชื่อต้องไม่ซ้ำกับ Secret ที่มีอยู่แล้ว

## แก้ไขและลบ

- **แก้ไข** — เปลี่ยนค่าได้ ชื่อแก้ไม่ได้ ระบบใช้ค่าใหม่ตั้งแต่การเรียกครั้งถัดไป
- **ลบ** — ต้องพิมพ์ `delete` เพื่อยืนยัน การลบย้อนกลับไม่ได้ และ Automation หรือ Tool ที่อ้างอิง Secret นี้อาจใช้งานไม่ได้

## นำไปใช้ใน Tool และ Automation

Secret ใช้ได้กับ **Automation** และ **Tool (MCP)** แบบ **http** และ **wasm** เท่านั้น โดยใส่ในช่องที่ต้องการในรูปแบบ

```text
{{ secrets.CRM_API_KEY }}
```

แทน `CRM_API_KEY` ด้วยชื่อตัวแปรที่คุณตั้งไว้

เมื่อเขียน Tool แบบโค้ด (JavaScript หรือ Python) สามารถอ่านค่าผ่านอ็อบเจ็กต์ `secrets` ในฟังก์ชัน `run` ได้ เช่น `secrets.CRM_API_KEY` ดูรายละเอียดที่ [สร้างและจัดการ Tools](/guides/ai-agent/manage-tools/)

:::caution[ใครเห็นค่าได้บ้าง]
เฉพาะ **Owner** ที่เปิดและแก้ Secrets ได้ แอดมินสิทธิ์อื่นไม่เห็นเมนูนี้ อย่าแชร์ค่าที่คัดลอกออกไปในที่สาธารณะ
:::
