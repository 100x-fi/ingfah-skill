# บิลและการใช้งาน

> ดูโควต้าตามแพ็กเกจ ปริมาณการใช้งานในรอบบิล และดาวน์โหลดใบแจ้งหนี้/ใบเสร็จ
>
> Source: https://docs.ingfah.ai/guides/settings/billing/

หน้า **บิลและการใช้งาน** แสดงแพ็กเกจที่คุณใช้อยู่ ปริมาณการใช้งานในรอบบิลปัจจุบัน และประวัติการเรียกเก็บย้อนหลัง

:::note[เฉพาะสิทธิ์ Owner]
เฉพาะผู้ใช้สิทธิ์ **Owner** เท่านั้นที่เห็นและเข้าใช้งานเมนูนี้ได้
:::

## ข้อมูลแพ็กเกจ

ด้านบนของหน้าจะแสดงระยะสัญญา (วันเริ่มต้น - วันสิ้นสุด) พร้อมรายละเอียด

| กลุ่ม | รายการ |
|-------|--------|
| **โควต้าการโทร** | จำนวนสายพร้อมกันสูงสุด และจำนวนนาทีรวมต่อเดือน |
| **ราคา** | ราคาต่อนาที และค่าบริการรายเดือน |
| **คลังความรู้** | โควต้า tokens สำหรับการสร้างและใช้งาน และพื้นที่จัดเก็บข้อมูล (GB) |

:::note[รอบการรีเซ็ตโควต้า]
โควต้าทั้งหมดจะรีเซ็ตทุกสิ้นเดือน **ยกเว้นพื้นที่จัดเก็บข้อมูลคลังความรู้** ซึ่งคิดจากปริมาณเอกสารที่เก็บอยู่จริง
:::

## การใช้งานในรอบบิล

ส่วน **การใช้งาน** แสดงปริมาณที่ใช้ไปเทียบกับโควต้าของรอบบิลปัจจุบัน พร้อมเวลาอัปเดตล่าสุด และปุ่ม **รีเฟรช**

- **โทรศัพท์** — จำนวนนาทีที่ใช้ไป พร้อมวันที่โควต้าจะรีเซ็ต
- **คลังความรู้ — การสร้างและใช้งาน** — จำนวน tokens ที่ใช้ไป
- **คลังความรู้ — พื้นที่จัดเก็บข้อมูล** — พื้นที่ที่ใช้ไป คิดจากไฟล์ต้นฉบับที่อัปโหลด การลบเอกสารจะได้พื้นที่คืน
- **แชท** — อยู่ระหว่างการพัฒนา

:::caution[การใช้งานเกินโควต้า]
หากใช้นาทีเกินโควต้า ระบบจะแสดงจำนวนนาทีส่วนเกินและค่าบริการเพิ่มเติม ซึ่งจะถูกนำไปรวมในใบแจ้งหนี้รอบถัดไป

หากพื้นที่คลังความรู้ใกล้เต็ม สามารถลบเอกสารที่ไม่ใช้แล้วเพื่อคืนพื้นที่ หรืออัปเกรดแพ็กเกจ
:::

## ประวัติการเรียกเก็บ

ตารางด้านล่างแสดงใบแจ้งหนี้และใบเสร็จย้อนหลัง ค้นหาด้วยเลขที่ใบแจ้งหนี้หรือชื่อแพ็กเกจได้ และกรองตามวันที่ได้

| คอลัมน์ | ความหมาย |
|---------|----------|
| รอบบิล | ช่วงเวลาของรอบบิลนั้น |
| แพ็กเกจ | แพ็กเกจที่ใช้ในรอบนั้น |
| การใช้งาน (นาที) | จำนวนนาทีที่ใช้ไป |
| ส่วนเกิน (นาที) | นาทีที่เกินโควต้า |
| ยอดรวมก่อนภาษี | ค่าแพ็กเกจ |
| ค่าส่วนเกิน | ค่าบริการจากนาทีส่วนเกิน |
| ส่วนลด | ส่วนลดที่ได้รับ |
| VAT 7% / WHT 3% | ภาษีมูลค่าเพิ่ม และภาษีหัก ณ ที่จ่าย |
| รวมทั้งสิ้น | ยอดสุทธิ |
| สถานะ | ชำระแล้ว / ยังไม่ชำระ / ล้มเหลว |
| การจัดการ | ดาวน์โหลด **ใบแจ้งหนี้** และ **ใบเสร็จ** |

## ไม่พบแพ็กเกจที่พร้อมใช้งาน

หากหน้านี้แจ้งว่าไม่พบแพ็กเกจที่พร้อมใช้งาน แปลว่าบัญชีของคุณยังไม่มี License ที่ใช้งานอยู่ หรือ License หมดอายุแล้ว กรุณาติดต่อทีมงานอิงฟ้า
