# ดูประกาศและฟีเจอร์ใหม่

> อ่านประกาศที่แสดงบนแดชบอร์ดและเลือกไม่ให้แสดงซ้ำ
>
> Source: https://docs.ingfah.ai/guides/website-announcements/

เมื่อมีประกาศใหม่ ระบบจะแสดงหน้าต่างประกาศบนแดชบอร์ด กด **ต่อไป** และ **ย้อนกลับ** เพื่ออ่านแต่ละหน้า กด **เริ่มต้นใช้งาน** ที่หน้าสุดท้ายเพื่อปิดและบันทึกว่าอ่านประกาศแล้ว

## เหมาะกับงานแบบไหน

ใช้ติดตามฟีเจอร์หรือประกาศที่เกี่ยวกับงานของคุณ ตัวอย่างเช่น เมื่อเปิดแดชบอร์ดแล้วเห็นประกาศฟีเจอร์ใหม่ ให้กด **ต่อไป** เพื่ออ่านทุกหน้า หากอ่านจบแล้วกด **เริ่มต้นใช้งาน** ระบบจะไม่แสดงประกาศเดิมซ้ำในครั้งถัดไป

หากต้องการปิดก่อนอ่านครบ กด **X** หรือคลิกนอกหน้าต่าง หากเลือก **ไม่แสดงอีก** ก่อนปิด ระบบจะบันทึกว่าอ่านประกาศเหล่านั้นแล้ว มิฉะนั้นประกาศที่ยังไม่ได้อ่านอาจแสดงอีกเมื่อเข้าระบบครั้งถัดไป
