# อัปโหลดและทดสอบการค้นหา

> อัปโหลดไฟล์เข้าคลังความรู้ และทดสอบว่าระบบค้นหาเนื้อหาที่ต้องการได้ก่อนนำไปใช้กับ AI Agent
>
> Source: https://docs.ingfah.ai/guides/knowledge-base/upload-documents/

## อัปโหลดไฟล์เข้าคลังความรู้

:::note

ไฟล์ที่รองรับในขณะนี้: `.pdf` `.docx` `.txt` `.md`

:::

1. ไปที่เมนู **คลังความรู้** ทางด้านซ้าย

2. คลิก **อัปโหลด** ทางด้านขวาบน

3. ลากไฟล์มาวางในพื้นที่อัปโหลด หรือคลิก **เลือกเอกสาร** เพื่อเลือกไฟล์จากเครื่อง

4. เมื่อเลือกไฟล์เรียบร้อยแล้ว คลิก **ยืนยันการอัปโหลด**

5. รอจนกว่าสถานะของไฟล์จะเปลี่ยนเป็น **พร้อมใช้งาน**

:::note
ควรรอให้เอกสารอยู่ในสถานะ **พร้อมใช้งาน** ก่อนนำไปทดสอบการค้นหาหรือเชื่อมกับ AI Agent
:::

:::tip[เลือกประเภทไฟล์ให้เหมาะกับเนื้อหา]
สำหรับเอกสารคำถามที่พบบ่อย (FAQ) แนะนำให้ใช้ไฟล์ `.md` หรือ `.txt` เพราะควบคุมรูปแบบข้อความได้ตรงตามที่เขียนไว้ ไฟล์ `.pdf` ที่จัดหน้าหลายคอลัมน์ หรือมีตารางและรูปภาพจำนวนมาก อาจทำให้ข้อความถูกอ่านสลับลำดับได้
:::

## ทดสอบการค้นหา

หลังจากเอกสารอยู่ในสถานะ **พร้อมใช้งาน** สามารถทดสอบได้ว่าระบบค้นหาข้อมูลภายในเอกสารได้ตรงตามที่ต้องการหรือไม่

1. คลิก **ทดสอบการค้นหา** ที่เอกสารที่ต้องการ

2. เลือกแท็บ **ทดสอบการค้นหา**

3. พิมพ์คำหรือคำถามที่ต้องการค้นหา เช่น `ประกันชีวิต`, `มีประกันอะไรบ้าง`

4. คลิก **ค้นหา** ระบบจะแสดงเนื้อหาที่ใกล้เคียงกับคำค้น พร้อมค่าความใกล้เคียงของแต่ละผลลัพธ์

:::note
การทดสอบส่วนนี้ช่วยตรวจสอบว่าเอกสารมีข้อมูลที่ต้องการ และระบบสามารถค้นหาเนื้อหาที่เกี่ยวข้องได้ก่อนนำไปใช้งานกับ AI Agent
:::

### อ่านผลการทดสอบอย่างไร

- **ค้นด้วยคำพูดของลูกค้า** ไม่ใช่ชื่อหัวข้อในเอกสาร เช่น ค้นว่า `ผูกบัญชีไม่ได้` แทน `การผูกบัญชีธนาคาร`
- **ดูว่าคำตอบกลับมาด้วยหรือไม่** ไม่ใช่แค่หัวข้อคำถาม ถ้าผลลัพธ์อันดับต้น ๆ มีแต่หัวข้อแต่ไม่มีเนื้อหาคำตอบ AI Agent จะตอบลูกค้าไม่ได้
- **ดูว่าเนื้อหาที่ถูกต้องอยู่อันดับต้น ๆ** หากหัวข้ออื่นที่คล้ายกันขึ้นมาก่อนเสมอ AI Agent อาจหยิบคำตอบผิดไปใช้
- **ลองค้นหัวข้อที่ไม่มีในเอกสาร** เพื่อดูว่าระบบไม่ได้ส่งเนื้อหาที่ไม่เกี่ยวข้องกลับมา

หากผลลัพธ์ยังไม่ดี ดูวิธีแก้ไขได้ที่ [ทดสอบและปรับปรุงคลังความรู้](/guides/knowledge-base/test-and-improve)

## อัปเดตเอกสารเป็นเวอร์ชันใหม่

เมื่อแก้ไขเนื้อหาในไฟล์ต้นฉบับแล้ว การแก้ไขจะยังไม่มีผลจนกว่าจะอัปโหลดไฟล์ใหม่เข้าระบบ

1. อัปโหลดไฟล์เวอร์ชันใหม่ และรอจนสถานะเป็น **พร้อมใช้งาน**
2. ทดสอบการค้นหากับไฟล์ใหม่
3. เปลี่ยน AI Agent ให้ใช้ไฟล์ใหม่ และปิดไฟล์เดิม ตามขั้นตอนใน [เชื่อมคลังความรู้กับ AI Agent](/guides/knowledge-base/connect-to-ai-agent)
4. เมื่อมั่นใจว่าไฟล์ใหม่ใช้งานได้ดีแล้ว ลบไฟล์เดิมที่ไม่ใช้เพื่อคืนพื้นที่จัดเก็บ

:::caution
อย่าเปิดใช้ไฟล์เวอร์ชันเก่าและเวอร์ชันใหม่พร้อมกันใน AI Agent ตัวเดียว เพราะ AI Agent อาจได้ข้อมูลสองชุดที่ขัดแย้งกันและตอบลูกค้าผิด
:::
