# เขียนเอกสาร FAQ ให้ AI Agent ค้นเจอ

> รูปแบบและเทคนิคการเขียนเอกสารคำถามที่พบบ่อย ให้ AI Agent ค้นหาเจอและตอบลูกค้าได้ถูกต้อง
>
> Source: https://docs.ingfah.ai/guides/knowledge-base/writing-faq-documents/

เอกสารที่อ่านง่ายสำหรับคน ไม่ได้แปลว่าจะค้นหาง่ายสำหรับ AI Agent หน้านี้รวมรูปแบบและเทคนิคการเขียนเอกสาร FAQ ที่ช่วยให้ AI Agent หาคำตอบที่ถูกต้องเจอและนำไปตอบลูกค้าได้ทันที

:::note
ตัวอย่างทั้งหมดในหน้านี้ใช้ข้อมูลสมมติ ชื่อสินค้า ช่องทาง เบอร์โทร และตัวเลขเป็นค่าตัวอย่างเท่านั้น
:::

---

## หลักสำคัญ: ทุกช่วงของเอกสารต้องเข้าใจได้ในตัวเอง

ระบบแบ่งเอกสารเป็นช่วงสั้น ๆ และส่งเฉพาะช่วงที่ใกล้เคียงกับคำถามให้ AI Agent (ดู [ภาพรวมคลังความรู้](/guides/knowledge-base/overview)) จุดที่แบ่งอาจอยู่ตรงไหนก็ได้ รวมถึง**ระหว่างหัวข้อคำถามกับเนื้อหาคำตอบ**

ตัวอย่าง หัวข้อนี้อ่านเข้าใจได้สำหรับคน

```
### Q: ผูกบัญชีไม่สำเร็จ ทำยังไง

- ชื่อบัญชีต้องตรงกับบัตรประชาชน
- ใช้บัญชีร่วมไม่ได้
- ต้องยืนยันตัวตนให้เสร็จก่อน
```

แต่ถ้าหัวข้อถูกแบ่งไปอยู่คนละช่วงกับคำตอบ ช่วงที่มีคำตอบจะไม่มีคำว่า "ผูกบัญชี" อยู่เลย ระบบจึงค้นไม่เจอเมื่อลูกค้าถามว่า "ผูกบัญชีไม่ได้" และลูกค้าจะได้ยินว่าไม่มีข้อมูล ทั้งที่เอกสารมีคำตอบอยู่

**ทุกเทคนิคในหน้านี้มาจากคำถามเดียว: ถ้าช่วงนี้ถูกหยิบไปอ่านเพียงลำพัง จะยังตอบลูกค้าได้หรือไม่**

---

## โครงสร้างไฟล์ที่แนะนำ

```
## หมวด 1: การสมัครบริการ

### Q: <คำถามแบบที่ลูกค้าพูด> / <อีกแบบหนึ่ง> / <อีกแบบหนึ่ง>

**คำถามที่เข้าข่ายหัวข้อนี้:** <คำพูดอื่น>, <คำพูดอื่น>    (ไม่บังคับ)

<บรรทัดแรก: ทวนคำถาม + คำตอบหลัก>

<รายละเอียดเพิ่มเติม>

---

### Q: ...
```

- `## หมวด` ใช้จัดกลุ่มให้คนอ่านง่าย ไม่ควรหวังให้ช่วยการค้นหา เพราะมักอยู่ห่างจากหัวข้อส่วนใหญ่
- `### Q:` ขึ้นต้นแต่ละหัวข้อ และใช้ ` / ` คั่นคำถามที่ถามเรื่องเดียวกัน
- `---` ปิดท้ายแต่ละหัวข้อ

:::caution[ไฟล์ต้องมีแต่ความรู้เท่านั้น]
ทุกข้อความในไฟล์จะถูกค้นหาและอาจถูกอ่านให้ลูกค้าฟัง ห้ามใส่หมายเหตุผู้เขียน วิธีใช้เทมเพลต ประวัติการแก้ไข TODO หรือข้อความอย่าง "ดูในเอกสารอีกฉบับ" ให้เก็บข้อความเหล่านี้ไว้ในไฟล์แยกที่ไม่อัปโหลด

```
<!-- TODO: ยืนยันตัวเลขกับทีมการตลาดก่อนขึ้นระบบ -->
หมายเหตุผู้เขียน: หัวข้อนี้แก้ไขล่าสุดตามเอกสารฉบับ 3
```
:::

## กฎการเขียนแต่ละหัวข้อ

### 1. หนึ่งหัวข้อต่อหนึ่งคำถาม และทุกหัวข้อต้องสมบูรณ์ในตัวเอง

อย่าแบ่งเรื่องเดียวไว้สองหัวข้อ และอย่าให้หัวข้อหนึ่งต้องพึ่งหัวข้ออื่น **การเขียนข้อมูลซ้ำในหลายหัวข้อเป็นเรื่องที่ถูกต้อง** เพราะแต่ละหัวข้อถูกค้นเจอแยกกัน

```
### Q: สมัครบริการได้ที่ไหน / สมัครยังไง

สมัครบริการตัวอย่างได้ที่ไหน: สมัครได้ 2 ช่องทาง คือ เมนู "สมัครบริการ" ในไลน์ @example และที่เว็บไซต์ของบริษัท

---

### Q: อยากรู้ผลการสมัคร / ผลอนุมัติออกหรือยัง

เช็กผลการสมัครบริการตัวอย่าง: ตรวจสอบได้เองที่เมนู "ตรวจสอบผล" ในไลน์ @example หรือที่เว็บไซต์ของบริษัท ทราบผลภายใน 3 วันทำการ
```

❌ อย่าเขียนว่า "ช่องทางเดียวกับหัวข้อการสมัครด้านบน" เพราะเมื่อหัวข้อนี้ถูกค้นเจอ จะไม่มี "ด้านบน" ให้ AI Agent อ่าน

### 2. เขียนหัวข้อเป็นคำถามแบบที่ลูกค้าพูดจริง

หัวข้อที่เป็นคำพูดของลูกค้าจะค้นเจอง่ายกว่าหัวข้อแบบชื่อหมวด ใส่หลายรูปแบบคั่นด้วย ` / ` และถ้าเป็นไปได้ให้ใช้ประโยคจริงจากประวัติการสนทนา

❌ `### Q: สถานะสินเชื่อ`

✅ `### Q: ผลการสมัครสินเชื่อ / อยากรู้ผลสมัคร / ผลอนุมัติออกหรือยัง / รู้ผลกี่วัน / จะมีใครโทรแจ้งผลไหม`

**หนึ่งหัวข้อควรมีเพียงหนึ่งเรื่อง** หัวข้อที่รวมสองเรื่องไม่เกี่ยวกัน เช่น "สมัครหลายวันไม่คืบหน้า และยอดค่างวดไม่ตรง" จะแย่งผลการค้นหากับหัวข้อที่เป็นเจ้าของเรื่องที่สอง ให้แยกเป็นสองหัวข้อ

### 3. เริ่มเนื้อหาด้วยบรรทัด "ทวนคำถาม + คำตอบหลัก"

นี่คือเทคนิคที่ได้ผลที่สุด บรรทัดแรกของเนื้อหาให้**ทวนคำถามด้วยคำพูดของลูกค้า แล้วตามด้วยคำตอบหลัก** ไม่ว่าเนื้อหาจะถูกแบ่งตรงไหน ช่วงที่มีบรรทัดนี้ก็ยังบอกได้ว่าตอบคำถามอะไร

```
### Q: ยังไม่อนุมัติ อยากเปลี่ยนผู้ค้ำ / เปลี่ยนผู้ค้ำทำยังไง

ยังไม่อนุมัติ อยากเปลี่ยนผู้ค้ำ เปลี่ยนผู้ค้ำทำยังไง: ผู้กู้เปลี่ยนผู้ค้ำได้ด้วยตนเองที่เมนู "เปลี่ยนผู้ค้ำประกัน" ในไลน์ @example ทำได้เฉพาะตอนที่ยังไม่อนุมัติ

สามารถเปลี่ยนผู้ค้ำประกันได้ด้วยตนเอง โดยเลือกเมนู "เปลี่ยนผู้ค้ำประกัน" ได้ 2 ช่องทาง:
1. ไลน์ @example เลือกเมนู "สมัครสินเชื่อ"
2. เว็บไซต์ของบริษัท เลือกเมนู "สมัครสินเชื่อ"
```

ถ้าหัวข้อมีข้อมูลที่ต้องแจ้งลูกค้าทุกครั้ง ใช้ป้ายกำกับให้ชัดว่าบรรทัดนี้สำคัญ

```
**คำตอบหลัก (ต้องแจ้งเสมอ): ไม่จำเป็นต้องไปรับเครื่องทันที แสดงสิทธิ์รับเครื่องได้ภายใน 15 วันนับจากวันสมัคร โดยแสดงบัตรประชาชนที่ร้าน**
```

กฎของบรรทัดนี้:

- ใช้เฉพาะข้อมูลที่มีอยู่ในหัวข้อนั้นแล้ว ห้ามเพิ่มข้อมูลใหม่
- เขียนเป็นประโยคเดียว และวางไว้บรรทัดแรก
- ใช้คำที่ลูกค้าพูดจริง แม้เนื้อหาด้านล่างจะใช้คำทางการ เช่น เขียนว่า "แอปล็อก" คู่กับ "บัญชีถูกระงับการใช้งาน"
- ถ้าลูกค้าพูดคำที่ต่างจากในเอกสาร ให้เพิ่มคำนั้นลงไปด้วย เช่น "ไลน์" คู่กับ "LINE" หรือ "หมื่นบาท" คู่กับ "10,000 บาท"

### 4. เขียนเนื้อหาให้สั้น และแยกหัวข้อที่ยาวเกินไป

เนื้อหายาวทำให้ค้นหาแม่นยำน้อยลง ถูกแบ่งเป็นหลายช่วง และทำให้ AI Agent พูดยาวเกินจำเป็น หากหัวข้อใดยาวเกินประมาณ 700 ตัวอักษร มักแปลว่ามีสองคำถามอยู่ในหัวข้อเดียว ให้แยกออก

สำหรับคำตอบที่ยาวจริง ๆ ให้แบ่งเป็นสองระดับ:

- **หัวข้อหลัก** ตอบคำถามกว้าง ๆ ในไม่กี่ประโยค และลงท้ายด้วย `[มีรายละเอียดเพิ่ม]`
- **หัวข้อรายละเอียด** ขึ้นต้นด้วย `[รายละเอียด]` มีคำถามเฉพาะกรณีของตัวเอง และเก็บข้อมูลที่หัวข้อหลักไม่ได้พูดถึง

```
### Q: เคลมประกันต้องใช้เอกสารอะไรบ้าง

เอกสารที่ใช้เคลมประกันตัวอย่าง: ใช้สำเนาบัตรประชาชน ใบเสร็จค่ารักษา และใบรับรองแพทย์ ส่งทางไลน์ @example ได้เลย [มีรายละเอียดเพิ่ม]

---

### Q: [รายละเอียด] เอกสารเคลมประกัน กรณีผู้เอาประกันเสียชีวิต

เอกสารเคลมประกันตัวอย่างกรณีผู้เอาประกันเสียชีวิต: ใช้ใบมรณบัตร สำเนาทะเบียนบ้าน และบัตรประชาชนของผู้รับผลประโยชน์ ...
```

แล้วเขียน Prompt ให้ AI Agent ตอบคำถามกว้าง ๆ จากหัวข้อหลักก่อน และให้รายละเอียดเมื่อลูกค้าถามต่อเท่านั้น

:::tip
หัวข้อรายละเอียดต้องใช้คำถาม**เฉพาะกรณี** ถ้าใช้คำถามกว้างเหมือนหัวข้อหลัก หัวข้อรายละเอียดอาจถูกค้นเจอก่อน แล้ว AI Agent จะอ่านรายละเอียดทั้งหมดให้ลูกค้าฟัง
:::

### 5. ไม่ใช้ตาราง

ตารางถูกแบ่งได้ไม่ดี แถวหัวตารางกับแถวข้อมูลอาจอยู่คนละช่วง และ AI Agent แบบเสียงอ่านตารางออกมาได้ไม่เป็นธรรมชาติ ให้เขียนเป็นบรรทัดสั้น ๆ และให้ทุกบรรทัดบอกว่าเป็นข้อมูลของอะไร

❌

```
| อายุ | เบี้ยประกันต่อปี |
|---|---|
| 20 ถึง 40 ปี | 1.2% |
| 41 ถึง 60 ปี | 1.8% |
```

✅

```
เบี้ยประกันคุ้มครองวงเงินสินเชื่อตัวอย่าง ผู้กู้อายุ 20 ถึง 40 ปี: ร้อยละ 1.2 ของวงเงินต่อปี
เบี้ยประกันคุ้มครองวงเงินสินเชื่อตัวอย่าง ผู้กู้อายุ 41 ถึง 60 ปี: ร้อยละ 1.8 ของวงเงินต่อปี
```

### 6. ใช้รายการเลขข้อสำหรับช่องทางและขั้นตอน และตัวหนาสำหรับข้อห้าม

รายการเลขข้อฟังง่ายเมื่ออ่านออกเสียง ขอเพียงประโยคนำบอกว่ารายการนี้คืออะไร และใช้ตัวหนากับข้อความปฏิเสธที่ห้ามตกหล่น

```
หากได้รับการอนุมัติวงเงินแล้ว **จะไม่สามารถเปลี่ยนผู้ค้ำประกันได้** ให้ผู้ค้ำแจ้งชื่อและเบอร์โทรมาทางไลน์ @example เพื่อให้เจ้าหน้าที่แนะนำการทำรายการ
```

### 7. เขียนตัวเลขแบบที่จะพูดออกเสียง (สำหรับ AI Agent แบบเสียง)

เนื้อหาที่ค้นเจอจะถูกนำไปพูดกับลูกค้าแทบทันที เขียนช่วงตัวเลขว่า "X ถึง Y" แทน "X-Y" เพราะระบบเสียงอาจอ่าน "61-65 ปี" เป็น "หกหนึ่ง หกห้า" ส่วนเบอร์โทรศัพท์ใช้ขีดคั่นได้ตามปกติ

❌ `ผู้กู้อายุ 61-65 ปี ผ่อนได้ 6-12 งวด`

✅ `ผู้กู้อายุ 61 ถึง 65 ปี ผ่อนได้ 6 ถึง 12 งวด`

หลีกเลี่ยงตัวย่อที่อ่านออกเสียงไม่ได้ และพิจารณาเขียนเว็บไซต์เป็นคำอ่าน เช่น `www ดอท example ดอท co ดอท th` หรือกำหนดวิธีอ่านไว้ใน Prompt ดูเพิ่มเติมที่ [การกำหนดการออกเสียงด้วย &lt;say-as&gt;](/guides/ai-agent/say-as-pronunciation)

## เทคนิคเพิ่มเติม

เลือกใช้ตามลักษณะของเนื้อหา บรรทัด "ทวนคำถาม + คำตอบหลัก" ใช้กับทุกหัวข้อ ส่วนเทคนิคอื่นเพิ่มเมื่อจำเป็น

### บรรทัด "คำถามที่เข้าข่ายหัวข้อนี้"

รวมคำพูดอื่น ๆ ที่ลูกค้าใช้ถามเรื่องนี้ ประมาณ 5 ถึง 10 แบบ คั่นด้วยจุลภาค วางไว้ใต้หัวข้อ ใช้เมื่อทดสอบแล้วพบว่าหัวข้อนี้แพ้หัวข้ออื่นที่คล้ายกัน หรือเมื่อลูกค้าใช้คำที่หัวข้อไม่มี

```
### Q: ผูกบัญชีธนาคารไม่สำเร็จ

**คำถามที่เข้าข่ายหัวข้อนี้:** ผูกบัญชีไม่ได้, เชื่อมบัญชีไม่ผ่าน, ระบบไม่รับบัญชี, ใส่เลขบัญชีแล้วขึ้นเออเร่อ, ผูกบัญชีค้าง
```

### บรรทัดแยกเรื่องที่คล้ายกัน

AI Agent อาจได้หลายหัวข้อที่คล้ายกันพร้อมกันแล้วนำมาปนกัน เมื่อสองหัวข้อใช้คำคล้ายกันแต่ต้องตอบหรือทำต่างกัน ให้เขียนบอกความต่างไว้**ในทั้งสองหัวข้อ**

```
กรณีนี้ต่างจากกรณี "ทำรายการแล้วระบบขึ้นว่าไม่สำเร็จ" ซึ่งเป็นข้อผิดพลาดของระบบและต้องแคปหน้าจอส่งไลน์ @example ห้ามสับสนกัน
```

หรือเขียนสั้น ๆ ในวงเล็บต่อท้ายบรรทัดคำถามที่เข้าข่าย

```
**คำถามที่เข้าข่ายหัวข้อนี้:** ยกเลิกบริการ, ขอคืนเงิน, ไม่อยากใช้ต่อ (คนละเรื่องกับการเปลี่ยนแพ็กเกจ ซึ่งเป็นการปรับระดับบริการ ไม่ใช่การยกเลิก)
```

### หัวข้อแบบ "ข้อเท็จจริงที่ต้องสื่อ"

สำหรับสถานการณ์ที่ลูกค้ากังวลหรือต้องการความมั่นใจ สคริปต์ตายตัวจะฟังแข็ง และมักถูกนำไปพูดในสถานการณ์ที่ไม่เหมาะ ให้ใส่ข้อเท็จจริงแล้วให้ AI Agent เรียบเรียงเอง

```
### Q: สมัครแล้วเช็กไม่เจอใบสมัคร กลัวใบสมัครหาย

สมัครแล้วเช็กไม่เจอใบสมัคร: ใบสมัครไม่ได้หาย ระบบกำลังจัดคิวเอกสาร

ข้อเท็จจริงที่ต้องสื่อ (เรียบเรียงคำพูดเองอย่างเป็นธรรมชาติ ห้ามท่องเป็นสคริปต์ตายตัว):
- ปลอบลูกค้าว่าไม่ต้องกังวล ใบสมัครไม่ได้หายไปไหน
- ระบบใช้เวลาประมาณ 1 ถึง 2 ชั่วโมงหลังกดสมัคร [ตัวเลขคงที่]
- แนะนำให้รอสักพักแล้วลองเช็กใหม่ที่เมนู "ตรวจสอบผล"
```

### ป้าย `[คงที่]` สำหรับข้อมูลที่ห้ามเปลี่ยน

ติดป้ายไว้หลังค่าที่ AI Agent ห้ามปัดเศษ ห้ามคำนวณใหม่ หรือห้ามเรียบเรียงใหม่ เช่น จำนวนเงิน อัตรา ระยะเวลา วันตัดรอบ เบอร์โทร และรายการที่ตายตัว

```
หากกรอกข้อมูลครบถ้วน จะทราบผลอนุมัติภายใน 3 วันทำการ [ระยะเวลาคงที่]
ระบบตัดเงินค่างวดทุกวันที่ 5 ของเดือน [ตัวเลขคงที่]
ช่องทางติดต่อเจ้าหน้าที่: โทร 02-000-0000 ทุกวัน เวลา 08:00 ถึง 20:00 น. [เบอร์และเวลาทำการคงที่]
```

ข้อมูลเหล่านี้คือจุดที่ตอบผิดแล้วเสียหายมากที่สุด เช่น เบอร์โทรหรืออัตราดอกเบี้ยผิด

### ระบุว่าเรื่องไหนต้องให้เจ้าหน้าที่ดูแล

ถ้าเรื่องใดต้องให้เจ้าหน้าที่จัดการ ให้เขียนเป็นข้อเท็จจริงในหัวข้อนั้น ส่วนวิธีโอนสายหรือส่งต่อให้เขียนไว้ใน Prompt ครั้งเดียว

```
ยอดที่ถูกตัดไม่ตรงกับค่าบริการ: กรณีนี้ไม่ใช่เรื่องที่ตอบได้จากข้อมูลทั่วไป ต้องให้เจ้าหน้าที่ตรวจสอบบัญชีของลูกค้าโดยตรง
```

:::caution[อย่าใส่ประโยคชวนคุยในเอกสาร]
ประโยคอย่าง "หากต้องการรายละเอียดเพิ่มเติม สอบถามได้เลยนะคะ" จะถูกพูดซ้ำเกือบทุกครั้งที่หัวข้อนั้นถูกค้นเจอ ให้กำหนดวิธีพูดคุยไว้ใน Prompt แทน
:::

## หมวด 1: การชำระเงิน

### Q: ระบบตัดเงินวันไหน / ตัดยอดวันที่เท่าไหร่ / เงินไม่พอตัดทำยังไง

**คำถามที่เข้าข่ายหัวข้อนี้:** ตัดเงินวันไหน, ตัดยอดวันที่เท่าไหร่, เงินไม่พอตัด, ตัดเงินไม่สำเร็จ

ระบบตัดเงินค่าบริการตัวอย่างวันไหน: ตัดอัตโนมัติจากบัญชีที่ผูกไว้ทุกวันที่ 5 ของเดือน [ตัวเลขคงที่] หากวันที่ 5 ตรงกับวันหยุด ระบบจะตัดในวันทำการถัดไป

เงินในบัญชีไม่พอตอนตัดค่าบริการ: ระบบจะตัดไม่สำเร็จและเกิดยอดค้างชำระ ให้เติมเงินเข้าบัญชีแล้วชำระยอดที่ขาดผ่าน QR Code ในแอปพลิเคชัน

**คำถามที่เข้าข่ายหัวข้อนี้:** ตัดเงินเกิน, ยอดตัดไม่ตรง, โดนหักเงินสองรอบ

ยอดที่ถูกตัดไม่ตรงกับค่าบริการตัวอย่าง: กรณีนี้ต้องให้เจ้าหน้าที่ตรวจสอบบัญชีของลูกค้าโดยตรง

2. ติดต่อเจ้าหน้าที่ตัวอย่างทางไลน์: ไลน์ @example ตอบกลับภายใน 1 วันทำการ
