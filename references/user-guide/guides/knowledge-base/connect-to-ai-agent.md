# เชื่อมคลังความรู้กับ AI Agent

> เลือกเอกสารในคลังความรู้ให้ AI Agent ใช้ค้นหาข้อมูลระหว่างสนทนากับลูกค้า
>
> Source: https://docs.ingfah.ai/guides/knowledge-base/connect-to-ai-agent/

เมื่อเอกสารอยู่ในสถานะ **พร้อมใช้งาน** แล้ว สามารถเลือกให้ AI Agent เข้าถึงเอกสารนั้นได้

## เลือกเอกสารให้ AI Agent

1. ไปที่ AI Agent ที่ต้องการใช้งานคลังความรู้

2. เปิด AI Agent แล้วคลิก **แก้ไขแบบร่าง**

3. คลิกไอคอน **คลังความรู้** ทางด้านขวาของหน้า AI Agent

4. เลือกเอกสารในคลังความรู้ที่ต้องการให้ AI Agent ใช้งาน โดยสามารถเปิดหรือปิดเอกสารแต่ละไฟล์ได้ตามต้องการ

5. เมื่อตั้งค่าเรียบร้อยแล้ว คลิก **บันทึกแบบร่าง**

:::note
หลังจากเลือกเอกสารแล้ว AI Agent จะสามารถเข้าถึงข้อมูลในเอกสารเหล่านั้นขณะสนทนากับลูกค้าได้
:::

## ก่อนใช้งานจริง

การเปลี่ยนเอกสารจะบันทึกอยู่ใน**แบบร่าง**ก่อน ยังไม่มีผลกับ AI Agent ที่กำลังใช้งานจริง

1. ทดลองคุยกับ AI Agent เวอร์ชันแบบร่าง ด้วยคำถามที่ลูกค้าถามบ่อย ดู [ทดลองคุยกับ AI Agent ก่อนใช้งานจริง](/guides/ai-agent/try-call)
2. เมื่อผลลัพธ์เป็นที่พอใจ ให้เผยแพร่แบบร่าง ดู [ปรับแต่ง AI Agent](/guides/ai-agent/manage-ai-agent)

## ข้อแนะนำในการเลือกเอกสาร

- **เปิดเฉพาะเอกสารที่เกี่ยวข้องกับหน้าที่ของ AI Agent ตัวนั้น** เอกสารที่ไม่เกี่ยวข้องทำให้ผลการค้นหามีเนื้อหาที่ไม่จำเป็นปะปนมา
- **แยก AI Agent ตามหน้าที่ แทนการให้ตัวเดียวรู้ทุกเรื่อง** เช่น AI Agent ฝ่ายขายใช้เอกสารสินค้า และ AI Agent ฝ่ายบริการใช้เอกสาร FAQ ดู [สร้างทีม AI Agent](/guides/inbound-outbound/create-ai-agent-team)
- **ใช้เอกสารเวอร์ชันล่าสุดเพียงไฟล์เดียวต่อหนึ่งเรื่อง** ปิดไฟล์เวอร์ชันเก่าทุกครั้งที่เปิดไฟล์ใหม่
- **ระบุชื่อไฟล์ใน Prompt** เพื่อบอก AI Agent ว่าเรื่องไหนต้องค้นหาจากไฟล์ใด ดู [เขียน Prompt ให้ AI Agent ใช้คลังความรู้](/guides/knowledge-base/prompting)
