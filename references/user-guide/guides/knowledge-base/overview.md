# ภาพรวมคลังความรู้

> คลังความรู้คืออะไร ทำงานอย่างไร และช่วยให้ AI Agent ตอบคำถามลูกค้าได้แม่นยำขึ้นอย่างไร
>
> Source: https://docs.ingfah.ai/guides/knowledge-base/overview/

**คลังความรู้ (Knowledge Base)** คือโซลูชันสำหรับการจัดการและค้นหาข้อมูลเชิงความหมาย ที่นำเทคโนโลยี **Retrieval-Augmented Generation (RAG)** มาใช้เพื่อเพิ่มประสิทธิภาพการทำงานของ AI Agent

ระบบจะช่วยให้ AI Agent สามารถเข้าถึงข้อมูลจากไฟล์ประเภทต่าง ๆ เช่น บทความ คู่มือการใช้งาน และ FAQs ได้อย่างแม่นยำ

ต่างจาก Keyword Search แบบเดิม การค้นหาด้วย RAG สามารถเข้าใจความหมายของคำถาม ทำให้ค้นหาข้อมูลที่เกี่ยวข้องได้แม้คำที่ใช้ค้นหาจะไม่ตรงกับข้อความในเอกสารทั้งหมด

---

## ประโยชน์

เมื่อ AI Agent เข้าถึงคลังความรู้ได้ จะสามารถ:

- **ดึงข้อมูลและทำความเข้าใจ** เนื้อหาที่มีความเฉพาะเจาะจงได้อย่างแม่นยำ
- **ตอบกลับคำถามของผู้ใช้** ได้อย่างถูกต้อง ตรงตามบริบท และมีประสิทธิภาพมากยิ่งขึ้น
- **อัปเดตข้อมูลได้ง่าย** เมื่อข้อมูลสินค้าหรือเงื่อนไขเปลี่ยน แก้ที่เอกสารแล้วอัปโหลดใหม่ ไม่ต้องแก้ Prompt

---

## คลังความรู้ทำงานอย่างไร

1. **แบ่งเอกสารเป็นส่วนย่อย** เมื่ออัปโหลดไฟล์ ระบบจะแบ่งเนื้อหาออกเป็นช่วงสั้น ๆ หลายช่วง แล้วจัดเก็บไว้ให้ค้นหาตามความหมายได้
2. **ค้นหาเมื่อลูกค้าถาม** ระหว่างสนทนา AI Agent จะนำคำถามของลูกค้าไปค้นหาในเอกสารที่เชื่อมไว้
3. **ตอบจากผลการค้นหา** ระบบส่งเฉพาะช่วงเนื้อหาที่ใกล้เคียงกับคำถามที่สุดกลับมา แล้ว AI Agent ใช้เนื้อหาเหล่านั้นตอบลูกค้า

:::tip[สิ่งที่ควรรู้]
AI Agent ไม่ได้อ่านเอกสารทั้งไฟล์ในการตอบแต่ละครั้ง แต่อ่านเฉพาะช่วงเนื้อหาที่ค้นเจอ ดังนั้น**แต่ละช่วงของเอกสารควรเข้าใจได้ในตัวเอง** แม้ถูกหยิบมาอ่านแยกจากส่วนอื่น ดูวิธีเขียนได้ที่ [เขียนเอกสาร FAQ ให้ AI Agent ค้นเจอ](/guides/knowledge-base/writing-faq-documents)
:::

## ตัวอย่างการใช้งาน

:::tip[AI Telesales Agent - ระบบเสนอขายสินค้าทางโทรศัพท์]
**การใช้งาน:** ค้นหาข้อมูลผลิตภัณฑ์เชิงลึก (สรรพคุณ ส่วนประกอบ และราคา) ได้แบบเรียลไทม์ขณะสนทนา

**ผลลัพธ์:** ช่วยให้ AI Agent ให้ข้อมูลได้แม่นยำ โน้มน้าวใจได้ตรงจุด และปิดการขายภายในสายได้ทันที
:::

:::tip[AI Customer Support - ระบบบริการและตอบคำถามลูกค้า]
**การใช้งาน:** ดึงข้อมูลจากคลังคู่มือการใช้งานและ FAQ เพื่อตอบข้อสงสัยของลูกค้า

**ผลลัพธ์:** ลูกค้าได้รับคำตอบที่ถูกต้อง ครบถ้วน ตามบริบท โดยไม่ต้องรอสายเจ้าหน้าที่
:::

:::tip[AI Real Estate Agent - ระบบแนะนำและซื้อขายอสังหาริมทรัพย์]
**การใช้งาน:** เข้าถึงฐานข้อมูลโครงการบ้านและคอนโด ทั้งเรื่องทำเล สิ่งอำนวยความสะดวก และเงื่อนไขสัญญา

**ผลลัพธ์:** คัดเลือกและนำเสนอโครงการที่ตรงกับความต้องการของลูกค้าได้อย่างมืออาชีพ คล่องตัว และรวดเร็ว
:::
