# เขียน Prompt ให้ AI Agent ใช้คลังความรู้

> เขียน Prompt บอก AI Agent ว่าเมื่อไรต้องค้นหาในคลังความรู้ ค้นหาอย่างไร และนำผลลัพธ์ไปตอบลูกค้าอย่างไร
>
> Source: https://docs.ingfah.ai/guides/knowledge-base/prompting/

AI Agent เห็นไฟล์คลังความรู้ที่เชื่อมไว้ได้ทันที แต่เอกสารที่ดีจะไม่มีประโยชน์เลยหาก AI Agent ไม่ค้นหา ปัญหาที่พบบ่อยที่สุดคือ AI Agent **ตอบจากความจำหรือจากข้อมูลใน Prompt แทนการค้นหา** ทำให้ตอบผิดหรือตอบว่าไม่มีข้อมูลทั้งที่เอกสารมีคำตอบอยู่

Prompt จึงต้องบอกให้ชัดว่าแต่ละไฟล์ควรถูกค้นหาเมื่อไร ค้นหาอย่างไร และนำเสนอผลลัพธ์อย่างไร

---

## ตัวอย่าง Prompt ที่ผ่านการทดสอบจริง

```
# คำถามเกี่ยวกับสินค้าหรือผลิตภัณฑ์

* ในระหว่างการสนทนากับลูกค้า ลูกค้าอาจจะทำการถามเกี่ยวกับสินค้าที่ร่วมรายการ ให้ทำการค้นหาในไฟล์ชื่อ `xxxx` ใหม่ทุกครั้งเสมอ ห้ามใช้ข้อมูลจากการค้นหาครั้งก่อน เพราะลูกค้าอาจเปลี่ยนคำถาม
* ใช้ชื่อรุ่น หรือ ชื่อแบรนด์ ในการค้นหา
* ตอบคำถามของลูกค้าให้ตรงประเด็นและหยุดเพียงแค่นั้น ห้ามถามว่า "มีคำถามอื่นเพิ่มเติมไหม" หรือประโยคลักษณะนั้นหลังจากตอบทุกครั้ง รอให้ลูกค้าถามต่อเองตามธรรมชาติ
* ห้ามใช้ numbered list ให้พูดแบบธรรมชาติเวลานำเสนอหลายตัวเลือกให้กับลูกค้า
* ใช้ข้อมูลจาก ชื่อสินค้า Brand Model Price Color ในการตอบเท่านั้น ข้อมูลนอกจากนั้นไม่สำคัญ
* ถ้าผลการค้นหาได้สินค้าหลายรุ่น ให้เลือกเสนอแค่อันแรกเท่านั้น และแนะนำแค่ชื่อรุ่น และราคา ยังไม่ต้องบอกเรื่องสี ยกเว้นลูกค้าจะถามเรื่องสีเพิ่มเติม
* ปรับแต่งคำพูดในการนำเสนอสินค้าได้ตามความเหมาะสม และฟังดูเป็นธรรมชาติ
```

Prompt ตัวอย่างนี้ช่วย AI Agent ใน 5 เรื่อง:

1. **บังคับค้นหาใหม่ทุกครั้ง** - แก้ปัญหา AI Agent ค้นหาแค่ครั้งแรกแล้วใช้ข้อมูลเดิมซ้ำ
2. **กำหนด Query ที่ใช้ค้นหา** - บอกว่าอะไรคือ keyword ที่เหมาะสม
3. **ป้องกันการนำเสนอข้อมูลดิบ** - ให้พูดแบบธรรมชาติ ไม่ไล่เป็นข้อๆ
4. **ระบุข้อมูลที่สำคัญ** - บอก AI Agent ว่าต้องสนใจข้อมูลอะไร
5. **จำกัดผลการค้นหา** - ควบคุมเมื่อเจอผลลัพธ์หลายรายการ

---

## หลักการเขียน Prompt สำหรับคลังความรู้

### 1. บอกให้ชัดว่าเรื่องไหนต้องค้นหาก่อนตอบเสมอ

ระบุหมวดคำถามที่ต้องค้นหา และบอกตรง ๆ ว่าห้ามตอบจากความจำ

```
# คำถามที่ต้องค้นหาในคลังความรู้ก่อนตอบเสมอ

หมวดที่ต้องค้นหาในไฟล์ `faq-บริการ`: การสมัคร ค่าบริการ การชำระเงิน การยกเลิก ช่องทางติดต่อ

* ต้องค้นหาในไฟล์ `faq-บริการ` ก่อนเสมอ แล้วจึงตอบจากผลการค้นหาเท่านั้น ห้ามตอบจากความจำ
* ห้ามนำข้อมูลจากส่วนอื่นของ Prompt มาตอบแทนการค้นหา
* ปัญหาหรือความต้องการที่ลูกค้าเล่ามา ให้ถือว่าเป็นคำถาม และค้นหาทันที ไม่ต้องถามย้อนว่าเรื่องอะไร
```

### 2. ยกตัวอย่างที่ถูกและผิดด้วยคำพูดจริงของลูกค้า

ตัวอย่างที่ใช้ประโยคจริงช่วยให้ AI Agent เข้าใจได้ดีกว่าคำอธิบายกว้าง ๆ

```
ลูกค้า: "แอปมันล็อกค่ะ เข้าไม่ได้เลย"
❌ ผิด: ถามกลับว่า "ล็อกแบบไหนคะ" โดยยังไม่ได้ค้นหา
✅ ถูก: ค้นหาด้วยคำว่า "แอปล็อก เข้าไม่ได้" ก่อน แล้วตอบจากผลการค้นหา
```

:::caution[อย่าเขียนคำค้นที่ผิดไว้ในตัวอย่าง]
AI Agent อาจลอกคำค้นในตัวอย่าง ❌ ไปใช้ค้นหาจริง ให้**อธิบาย**ข้อผิดพลาดแทน เช่น "อย่าเปลี่ยนคำถามของลูกค้าเป็นคำกว้าง ๆ" แทนการเขียนคำค้นที่ผิดออกมาเป็นตัวอย่าง
:::

### 3. ตอบว่า "ไม่มีข้อมูล" ได้เฉพาะเมื่อค้นหาแล้วจริง ๆ

กำหนดว่า AI Agent จะบอกลูกค้าว่าไม่มีข้อมูลได้ก็ต่อเมื่อค้นหาในรอบนั้นแล้วไม่พบ และบอกว่าเมื่อไม่พบข้อมูลต้องทำอะไรต่อ เช่น แนะนำช่องทางติดต่อเจ้าหน้าที่ หรือโอนสาย

```
* จะตอบว่า "ยังไม่มีข้อมูลเรื่องนี้" ได้เฉพาะเมื่อค้นหาในรอบนี้แล้ว และลองค้นด้วยคำอื่นอีกครั้งแล้วยังไม่พบ
* ถ้าค้นหาแล้วไม่พบ ห้ามเดาคำตอบ ให้แจ้งลูกค้าว่าจะให้เจ้าหน้าที่ติดต่อกลับ
```

### 4. เก็บ "ข้อเท็จจริง" ไว้ในเอกสาร และเก็บ "วิธีปฏิบัติ" ไว้ใน Prompt

ข้อมูลใดที่เขียนไว้ใน Prompt แล้ว AI Agent มักตอบจาก Prompt ทันทีโดยไม่ค้นหา แม้ในเอกสารจะมีข้อมูลที่ครบและใหม่กว่า

| ควรอยู่ใน Prompt | ควรอยู่ในคลังความรู้ |
|-----------------|-------------------|
| เมื่อไรต้องค้นหา ค้นหาจากไฟล์ไหน | ราคา ค่าธรรมเนียม อัตราดอกเบี้ย |
| วิธีพูดตัวเลข เว็บไซต์ และชื่อเฉพาะ | ช่องทางติดต่อ เบอร์โทร เวลาทำการ |
| ลำดับขั้นการสนทนา และเงื่อนไขการโอนสาย | เงื่อนไข ขั้นตอน และเอกสารที่ต้องใช้ |
| น้ำเสียงและบุคลิกของ AI Agent | คำถามที่พบบ่อยและคำตอบ |

:::tip
หากมีตารางราคา เบอร์ติดต่อ หรือ FAQ ฝังอยู่ใน Prompt ให้ย้ายไปไว้ในเอกสารคลังความรู้ แล้วให้ Prompt บอกเพียงว่าเรื่องนั้นต้องค้นหา
:::

### 5. แยกคลังความรู้ออกจากแหล่งข้อมูลอื่นให้ชัด

หาก AI Agent มีทั้งคลังความรู้และ [Tools](/guides/ai-agent/ai-agent-tools) ที่ดึงข้อมูลเฉพาะของลูกค้า ให้บอกขอบเขตให้ชัด เช่น

```
* ข้อมูลทั่วไปที่เหมือนกันสำหรับลูกค้าทุกคน (เงื่อนไข ขั้นตอน ค่าบริการ) → ค้นหาในไฟล์ `faq-บริการ`
* ข้อมูลของลูกค้ารายนี้ (สถานะใบสมัคร ยอดค้างชำระ) → ใช้ Tool ตรวจสอบข้อมูลลูกค้า ห้ามค้นหาในคลังความรู้
```

### 6. อย่าให้สคริปต์อื่นแย่งจังหวะการค้นหา

สคริปต์ที่เขียนไว้ใน Prompt เช่น ประโยคปลอบใจ หรือการถามว่า "แอดไลน์ไว้หรือยังคะ" อาจถูกใช้ตอบแทนการค้นหาเมื่อคำพูดของลูกค้าคล้ายกับสคริปต์นั้น ให้กำหนดเงื่อนไขของสคริปต์ให้แคบและเฉพาะเจาะจง

### 7. เพิ่มข้อความตรวจสอบก่อนตอบ

ข้อความสั้น ๆ ที่ให้ AI Agent ทบทวนตัวเองก่อนตอบ ช่วยให้ค้นหาสม่ำเสมอขึ้น

```
# ก่อนตอบคำถามข้อมูลทุกครั้ง
* ในรอบนี้ได้ค้นหาในคลังความรู้แล้วหรือยัง ถ้ายัง ให้ค้นหาก่อน
* คำตอบที่จะพูดมาจากผลการค้นหาหรือไม่ ถ้าไม่ใช่ ห้ามพูด
```

---

## ข้อควรระวัง

- **ทุกการแก้ไข Prompt อาจเปลี่ยนพฤติกรรมการค้นหา** ทดสอบซ้ำทุกครั้งหลังแก้ไข ดู [ทดสอบและปรับปรุงคลังความรู้](/guides/knowledge-base/test-and-improve)
- **ถ้าเปลี่ยนชื่อไฟล์ ให้แก้ชื่อไฟล์ใน Prompt ด้วย** และทดสอบใหม่ทั้งหมด
- **อย่าให้ AI Agent พูดชวนถามต่อหลังตอบทุกครั้ง** เช่น "มีอะไรสอบถามเพิ่มเติมไหมคะ" เพราะจะฟังซ้ำซากเมื่อลูกค้าถามหลายเรื่องติดกัน
