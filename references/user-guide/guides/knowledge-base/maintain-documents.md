# เตรียมข้อมูลและอัปเดตเอกสาร

> แปลงเอกสาร FAQ ที่มีอยู่ให้เป็นเอกสารคลังความรู้ จัดการข้อมูลที่ขัดแย้งหรือยังไม่ยืนยัน และอัปเดตเอกสารโดยไม่เสียคุณภาพเดิม
>
> Source: https://docs.ingfah.ai/guides/knowledge-base/maintain-documents/

ข้อมูลตั้งต้นของคลังความรู้มักมาจากเอกสารที่มีอยู่แล้ว เช่น ไฟล์ FAQ ของฝ่ายบริการลูกค้า คู่มือสินค้า หรือตารางเงื่อนไข และจะมีฉบับปรับปรุงส่งมาเรื่อย ๆ หน้านี้อธิบายวิธีเตรียมข้อมูลเหล่านั้น และวิธีอัปเดตโดยไม่ทำให้คุณภาพการค้นหาที่ปรับไว้หายไป

---

## แปลงเอกสารต้นฉบับเป็นเอกสารคลังความรู้

ให้มองเอกสารต้นฉบับเป็น**แหล่งข้อมูล** และเอกสารคลังความรู้เป็น**ข้อมูลต้นฉบับ + การปรับแต่งให้ค้นหาง่าย**

1. **เก็บคำถามเดิมไว้ให้จำได้** ใช้คำถามจากเอกสารต้นฉบับเป็นหัวข้อ `### Q:` แล้วเพิ่มรูปแบบคำถามอื่นต่อท้าย
2. **เพิ่มการปรับแต่งทับลงไป** ได้แก่ บรรทัด "ทวนคำถาม + คำตอบหลัก" บรรทัด "คำถามที่เข้าข่ายหัวข้อนี้" บรรทัดแยกเรื่องที่คล้ายกัน และป้าย `[คงที่]`
3. **แยกคำตอบที่ยาว** เป็นหัวข้อหลักและหัวข้อ `[รายละเอียด]` โดยไม่ตัดข้อมูลทิ้ง แค่ย้ายไปไว้ในที่ที่จะถูกพูดเมื่อลูกค้าถาม
4. **แปลงตารางเป็นบรรทัดข้อความ** ที่แต่ละบรรทัดบอกว่าเป็นข้อมูลของอะไร

ดูรายละเอียดแต่ละเทคนิคที่ [เขียนเอกสาร FAQ ให้ AI Agent ค้นเจอ](/guides/knowledge-base/writing-faq-documents)

## จัดการข้อมูลที่ขัดแย้งหรือยังไม่ยืนยัน

### เก็บบันทึกประเด็นไว้ในไฟล์แยก

เอกสารต้นฉบับมักมีข้อมูลที่ขัดแย้งกันเอง เช่น วงเงินสูงสุดสองตัวเลขในหมวดต่างกัน หรือไม่ตรงกับฉบับก่อน **อย่าเลือกเองเงียบ ๆ และอย่าใส่ทั้งสองค่า** ให้จดไว้ในไฟล์บันทึกที่ไม่อัปโหลด แล้วยืนยันกับผู้รับผิดชอบก่อนเปิดใช้งาน

```
### วงเงินสูงสุด: สองชุดที่ไม่ตรงกัน

- หมวด 2 ระบุ กลุ่ม ก กู้ได้ 10,000 ถึง 20,000 บาท
- หมวด 3 ระบุ ทุกกลุ่มกู้ได้ 5,000 ถึง 50,000 บาท

ต้องยืนยัน: ตัวเลขชุดไหนใช้ตอบลูกค้า
ผู้ยืนยัน: ฝ่ายผลิตภัณฑ์
```

:::caution
ไฟล์บันทึกนี้ห้ามอัปโหลดเข้าคลังความรู้ เพราะทุกข้อความในคลังความรู้อาจถูกอ่านให้ลูกค้าฟัง
:::

### ข้อมูลที่ยังไม่ประกาศ

ถ้ายังไม่มีค่าที่ยืนยันแล้ว ให้เขียนว่า `ยังไม่ประกาศ` พร้อมทางเลือกให้ลูกค้า **อย่าใส่ค่าที่เว้นไว้ในต้นฉบับ** เช่น `XXXX` หรือ `[เบอร์]` เพราะ AI Agent อาจอ่านออกมาหรือเดาตัวเลขเอง

❌ `สายด่วนเคลม โทร XXXX`

✅ `สายด่วนเคลมประกันตัวอย่าง: ยังไม่ประกาศ ระหว่างนี้แจ้งเคลมทางไลน์ @example ได้`

และเขียน Prompt บอก AI Agent ว่าถ้าข้อมูลใดยังไม่ประกาศ ให้แจ้งลูกค้าตามนั้นโดยไม่เดาค่าเอง

### สินค้าหรือบริการที่ยังไม่ยืนยัน

ถ้าเอกสารฉบับใหม่มีสินค้าหรือหมวดที่ไม่เคยมีมาก่อน ให้ยืนยันก่อนว่าเปิดขายจริงแล้ว **เมื่อข้อมูลอยู่ในคลังความรู้ AI Agent จะนำไปเสนอลูกค้าทันที**

### คำถามซ้ำ

ถ้าเอกสารต้นฉบับมีสองหัวข้อที่ตอบคำถามเดียวกัน ให้รวมเป็นหัวข้อเดียว หรือตรวจให้แน่ใจว่าทั้งสองหัวข้อตอบเหมือนกัน เพราะการค้นหามักได้เพียงหัวข้อเดียว

## อัปเดตเอกสารเมื่อมีฉบับใหม่

### ใส่การปรับแต่งกลับทุกครั้ง

ถ้าแปลงเอกสารต้นฉบับฉบับใหม่ตรง ๆ การปรับแต่งที่เคยทำไว้ (บรรทัดทวนคำถาม คำถามที่เข้าข่าย ป้าย `[คงที่]`) จะหายไปทั้งหมด และผลการค้นหาจะแย่ลงโดยไม่รู้ตัว

ก่อนอัปโหลดฉบับใหม่ ให้เทียบกับฉบับเดิมว่า

- จำนวนบรรทัด "คำถามที่เข้าข่ายหัวข้อนี้" ยังใกล้เคียงเดิม
- จำนวนป้าย `[คงที่]` ยังใกล้เคียงเดิม
- ทุกหัวข้อยังเริ่มด้วยบรรทัด "ทวนคำถาม + คำตอบหลัก"

ถ้าจำนวนใดลดลงมาก แปลว่าการปรับแต่งหายไป ไม่ใช่เอกสารกระชับขึ้น

### ขั้นตอนอัปเดต

1. แก้ไขไฟล์ต้นฉบับ และใส่การปรับแต่งกลับตามด้านบน
2. อัปโหลดไฟล์ใหม่ และรอจนสถานะเป็น **พร้อมใช้งาน**
3. เปลี่ยน AI Agent ให้ใช้ไฟล์ใหม่ ปิดไฟล์เดิม แล้วบันทึกแบบร่าง
4. ทดสอบทั้งไฟล์ตาม [ทดสอบและปรับปรุงคลังความรู้](/guides/knowledge-base/test-and-improve)
5. เผยแพร่แบบร่างเมื่อผลการทดสอบเป็นที่พอใจ
6. ลบไฟล์เดิมที่ไม่ใช้แล้วเพื่อคืนพื้นที่จัดเก็บ

:::tip[เก็บฉบับก่อนหน้าไว้ในเครื่อง]
เก็บไฟล์ต้นฉบับทุกฉบับที่อัปโหลดไว้ในเครื่องหรือระบบจัดเก็บเอกสารขององค์กร เพื่อเปรียบเทียบการเปลี่ยนแปลงและย้อนกลับได้เมื่อฉบับใหม่มีปัญหา
:::
